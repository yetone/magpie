ドキュメント · ガイド

Paseo で magpie の全モデルを

Paseo（getpaseo/paseo）は Claude Code や Codex などを代わりに動かすアプリです。起動するのは同じ Claude Code なので、magpie に接続した Claude Code は Paseo でも magpie を通ります。ただし Paseo はモデル一覧を自分で作るため、magpie が提供するモデルの多くが選択肢に出ません。magpie はそれらを Paseo 自身の additionalModels に書くので、Paseo の Claude モデル一覧で DeepSeek、GLM、Kimi、Qwen、GPT、ChatGPT サブスクリプションなど magpie のすべてのモデルを選べます。

Paseo の設定

  1. 先に Claude Code を magpie に接続magpie の エージェント ページで Claude Code に magpie のモデルを選びます。Paseo が並べる id は magpie に接続した Claude Code が処理します。
  2. Paseo の行をオンにする~/.paseo フォルダーがあれば magpie に Paseo の行があります。magpie を選ぶと、magpie の全モデルが Paseo の Claude モデル一覧に入ります。
  3. Paseo のデーモンを再起動Paseo はデーモンの起動時にモデル一覧を読みます。再起動すると magpie のモデルが出ます。
ターミナル
magpie claude deepseek/deepseek-v4-pro   # Claude Code on magpie first
magpie paseo magpie                      # every magpie model in Paseo's picker

別に接続が要る理由

Claude Code 自身の /model は ~/.claude/settings.json の modelPicker を読み、magpie は Claude Code を接続するときそこに全モデルを書きます。Paseo は modelPicker を読みません。一覧は自前の公式モデルに、settings.json の model と数個の ANTHROPIC_*_MODEL 階層変数を足したものです。そのため Claude Code だけを接続すると、メインと階層のモデル以外は Paseo の一覧に出ません。Paseo は自分の設定の agents.providers.claude.additionalModels も一覧に追加し、各 id をそのまま Claude Code に渡すので、magpie はここに書きます。

書かれる内容

Paseo のフォルダーは PASEO_HOME、なければ ~/.paseo です。magpie は config.json の agents.providers.claude.additionalModels にモデルごとに {id, label, description} を加えます。id、[1m] の印、名前は Claude Code の /model と同じで、description は via magpie で終わり、magpie はこれで自分の項目を見分けます。

ターミナル
// ~/.paseo/config.json
{"agents": {"providers": {"claude": {"additionalModels": [
  {"id": "my-own-model", "label": "…", "description": "…"},
  {"id": "…", "label": "…", "description": "via magpie"},
  {"id": "…", "label": "…", "description": "1M context · via magpie"}
]}}}}

自分の項目は先頭で位置もそのままです。自分で並べた id は自分のもので、magpie は重ねて追加しません。一覧が読めないときはそのままにします。magpie のモデルが変わると magpie が自分の項目を更新します。

反映されるタイミング

Paseo はデーモンの起動時にモデル一覧を読むので、magpie のモデルを見るには Paseo のデーモンを再起動してください。Paseo が動いている間は magpie がそう知らせます。また、これらの id を処理するには Claude Code 自体も magpie に接続している必要があります。

元に戻す

magpie で Paseo の行を既定に戻すと、description が via magpie で終わる項目だけを消し、自分の項目は残します。何も残らなければ additionalModels ごと消します。

ターミナル
magpie paseo default

よくある質問

Paseo のモデル一覧に magpie のモデルが出ないのはなぜですか？

Paseo は Claude Code の modelPicker を読まず、自前のモデル、settings.json の model、数個の ANTHROPIC_*_MODEL 変数だけを並べます。magpie で Paseo の行をオンにすると、全モデルを Paseo の additionalModels に書きます。

先に Claude Code を接続する必要がありますか？

あります。Paseo はこれらの id をそのまま起動した Claude Code に渡し、Claude Code が magpie に接続していれば magpie が処理します。

オンにしても出てきません。

Paseo はデーモンの起動時にモデル一覧を読みます。Paseo のデーモンを再起動してください。

自分の additionalModels は書き換えられますか？

いいえ。magpie が増減するのは description が via magpie で終わる項目だけで、自分の項目は先頭で位置もそのままです。

同じモデルを他のエージェントでも：Claude Code で他のモデル、T3 Code を任意のモデルで、Craft Agents を任意のモデルで。エラーが出るときは よくあるエラーの直し方、または Discord で質問してください。
