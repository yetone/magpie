ドキュメント · ガイド

Pencil を任意のモデルで

Pencil（pen.dev）はデザインキャンバスで、そのエージェントがモデルを呼び出します。~/.pencil/models.json に Pi と同じ形式で自分のプロバイダーを設定できます。magpie はここに magpie という名前のプロバイダーを加えるので、Pencil のモデルピッカーに DeepSeek・GLM・Kimi・Qwen・Claude・ChatGPT サブスクリプションなど magpie のモデルが並びます。

Pencil の設定

  1. magpie でプロバイダーを追加プロバイダー ページで API キーを追加するか、サブスクリプションにサインインします。
  2. エージェント ページで Pencil のプロバイダーを magpie にするPencil のモデルピッカーに magpie が選んだモデルが並びます。
  3. Pencil を再起動し、エージェントの入力欄でモデルを選ぶPencil はカスタムモデルを起動時に読むので、一度再起動します。モデルは Pencil のエージェントの入力欄で選び、magpie が読むファイルにはありません。

magpie が Pencil を見つける方法：~/.pencil フォルダー（アプリか pen.dev の CLI を一度実行するとできます）。Mac では、インストールしただけで開いていないアプリも Pencil.app または pen.dev.app で見つけます。

models.json

Pencil の設定では、カスタムプロバイダーに OpenAI Completions・OpenAI Responses・Anthropic Messages のいずれかをプロバイダー全体に設定できます。magpie のプロバイダーは OpenAI Completions（Pi の openai-completions）でゲートウェイの /v1 を指し、ゲートウェイはどのモデルでもこれを受け付けます：

ターミナル
// ~/.pencil/models.json
{
  "providers": {
    "magpie": {
      "name": "magpie",
      "baseUrl": "http://127.0.0.1:3425/v1",
      "api": "openai-completions",
      "apiKey": "",
      "models": [
        {
          "id": "deepseek/deepseek-v4-pro",
          "name": "…",
          "reasoning": …,
          "input": ["text", …],
          "cost": { "input": 0, "output": 0, "cacheRead": 0, "cacheWrite": 0 },
          "contextWindow": …,
          "maxTokens": …,
          "compat": {}
        }
      ]
    }
  }
}

Pencil のリクエストには Pencil 用の magpie のキーが付き、Pencil の User-Agent では見分けられないので、magpie はこのキーで見分けます。

モデルのフィールド

各モデルには、Pencil がモデルに書くフィールドがすべて入ります。magpie が知らない値は Pi の既定値で、コンテキスト 128K、返答 16K です。費用はすべて 0 で、使った分は magpie が自分で数えます。モデルごとの api と baseUrl は書きません。Pi は読みますが、Pencil 自身のエディターは書かないからです。

自分のプロバイダーはそのまま

Pencil で設定したほかのプロバイダーはそのままです。magpie のプロバイダーにある、magpie が書かないキー（ほかのツールが加えた設定など）も残ります。モデルのリストは magpie だけが管理するので、カタログからなくなったモデルはリストから消えます。

元に戻す

magpie で Pencil をオフにすると、magpie は models.json から magpie プロバイダーを削除し、ほかのプロバイダーはそのまま残します。

よくある質問

Pencil で DeepSeek や GLM を使えますか？

使えます。magpie が ~/.pencil/models.json に magpie プロバイダーを加えるので、Pencil を再起動してエージェントの入力欄でモデルを選んでください。

Pencil に magpie のモデルが出てこないのはなぜですか？

Pencil はカスタムモデルを起動時に読みます。Pencil を再起動してください。

magpie のプロバイダーはどのプロトコルを使いますか？

OpenAI Completions で、ゲートウェイの /v1 を指し、すべてのモデルで使います。

magpie は Pencil のほかのプロバイダーを変えますか？

変えません。magpie が書くのは自分の magpie プロバイダーだけです。

同じモデルを他のエージェントでも：OpenPencil を任意のモデルで、WorkBuddy を任意のモデルで、Pi を任意のモデルで、Mistral Vibe を任意のモデルで。エラーが出るときは よくあるエラーの直し方、または Discord で質問してください。
