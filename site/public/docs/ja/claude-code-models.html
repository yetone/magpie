ドキュメント · ガイド

Claude Code で DeepSeek・Kimi・GLM・Qwen など好きなモデルを使う

Claude Code が話す API は Anthropic Messages だけです。magpie はあなたのコンピューター上に、追加したすべてのプロバイダについてこの API を話すゲートウェイを置き、Claude Code をそこへ向けます。モデルは magpie でも、Claude Code の /model でも選べます。

ゲートウェイは 127.0.0.1:3425 で動き、Anthropic、OpenAI、Gemini の API を話します。DeepSeek、Kimi、Zhipu GLM、MiniMax、Qwen のようにプロバイダ自身が Anthropic Messages を話す場合、Claude Code のリクエストはそのまま渡されます。ChatGPT プランの GPT モデルのように話さない場合は、magpie がリクエストと応答を変換します。ストリーミングとツール呼び出しも含みます。

中国のモデル

DeepSeek、Kimi と Kimi Code、Zhipu GLM（従量課金または Coding Plan）、Z.ai、MiniMax、Qwen。中国向けエンドポイントがあるものはそれも使えます。

サブスクリプション

magpie でサインインした ChatGPT、Copilot、Antigravity アカウントのモデル。

その他

OpenAI 互換または Anthropic 互換の任意の URL とキー、Ollama、LM Studio。

セットアップ

  1. プロバイダを追加するmagpie の Providers タブで ＋ Add provider を押し、DeepSeek、Kimi、Zhipu GLM、MiniMax、Qwen のいずれかを選んで API キーを貼り付け、保存します。magpie がベンダーに提供モデルを問い合わせます。
  2. Claude Code のモデルを選ぶAgents タブで Claude Code の行のモデルをクリックし、deepseek/deepseek-v4-pro などを選びます。magpie がそれを ~/.claude/settings.json に書き込みます。
  3. 新しいセッションを始めるClaude Code は起動時に設定を読みます。すでに開いているセッションは、起動時のモデルのままです。

ターミナルからも同じことができます：

ターミナル
magpie provider add deepseek sk-…
magpie models                       # すべてのモデルを provider/model で表示
magpie claude deepseek/deepseek-v4-pro

モデル ID は magpie のもので、provider/model の形です。Claude Code の中の /model にも magpie のモデルが「via magpie」付きで並ぶので、そこで切り替えることもできます。

Zhipu GLM の Coding Plan。 Zhipu GLM または Z.ai を追加するときは、キーに合ったプランを選んでください。Coding Plan のキーには専用のエンドポイントがあり、従量課金のエンドポイントに送ると残高がないと返されます。
claude は自分のアカウントのままにする。 magpie では Claude Code を接続せずにおき、他のモデルで使いたいときだけ claude-magpie を実行します。同じ claude をそのセッションだけ magpie の設定で起動するので、settings.json は書き換えられません。はじめにを参照してください。

Opus・Sonnet・Haiku の割り当て

Claude Code はモデルをティアで指定します：opus、sonnet、haiku、fable。セッションのタイトルや Explore サブエージェントといった Claude Code 自身の小さな処理は haiku ティアに送られます。magpie は各ティアの変数にモデルを書き込みます：

ティアenv の変数デフォルト
opusANTHROPIC_DEFAULT_OPUS_MODELメインのモデル
sonnetANTHROPIC_DEFAULT_SONNET_MODELメインのモデル
haikuANTHROPIC_DEFAULT_HAIKU_MODEL、ANTHROPIC_SMALL_FAST_MODELメインのモデル。Claude モデルの場合は、そのプロバイダが提供する Haiku
fableANTHROPIC_DEFAULT_FABLE_MODELメインのモデルが Fable モデルでない限り未設定

つまり DeepSeek をメインのモデルにすると、すべてのティアが DeepSeek で動きます。haiku に安いモデルを使うなど、ティアごとにモデルを分けたい場合は、magpie の Claude Code の行で設定するか、ターミナルから指定します：

ターミナル
magpie claude haiku deepseek/deepseek-v4-flash   # 1 つのティアだけ別のモデルに
magpie claude haiku ""                           # メインのモデルに戻す

ティアに magpie 経由のモデルを設定できるのは、メインのモデルが magpie 経由のときだけです。

settings.json で変わること

Claude Code は接続先を ~/.claude/settings.json の env ブロックから読みます。magpie はそこで必要なキーだけを変更します。コメントや他の設定はそのまま残ります。

キー設定される値
env.ANTHROPIC_BASE_URLゲートウェイのアドレス
env.ANTHROPIC_AUTH_TOKENゲートウェイのキー（ベンダーのキーではありません。それは magpie の中に残ります）
modelメインのモデル
env.ANTHROPIC_DEFAULT_*_MODEL、env.ANTHROPIC_SMALL_FAST_MODEL上記のティア
env.CLAUDE_CODE_MAX_OUTPUT_TOKENSモデルが書ける最長の応答。Claude Code は知らないモデルには最大 32000 しか求めません
env.CLAUDE_CODE_MAX_CONTEXT_TOKENS、env.CLAUDE_CODE_AUTO_COMPACT_WINDOW必要な場合に、モデルのウィンドウと圧縮を始める位置。Claude Code は知らないモデルを 200K とみなします。1M のモデルには [1m] が付きます
modelPicker/model 用の magpie のモデル。自分で書いたピッカーには手を触れません

自分で設定した出力上限のように、自分で設定した値はそのまま残ります。ANTHROPIC_MODEL は /model での選択より優先されてしまうため取り除かれます。CLAUDE_CODE_USE_BEDROCK のようなクラウドの切り替えがこのファイルにある場合は、Claude Code が magpie 経由で動いている間だけ外され、後で戻されます。

Claude 自身のモデルに戻す

Claude Code の行で Claude Code 自身のモデルを選ぶか、magpie claude default を実行します。magpie は自分が書いたものを取り除き、最初に置き換えたもの（自分のベース URL、トークン、ティアのモデル）を元に戻します。ファイルを手で編集する必要はありません。

ChatGPT や Copilot のサブスクリプションの GPT モデル

magpie でサブスクリプションにサインインします：＋ Add provider から ChatGPT または Copilot のタイルを選ぶと、magpie がベンダー自身のサインインページを開きます。するとそのアカウントのモデルが、Claude Code のピッカーに codex/… または copilot/… として表示されます。

ターミナル
magpie accounts add codex      # ChatGPT アカウントにサインイン
magpie claude codex/gpt-5.5

Claude Code が話すのはあくまで Anthropic Messages です。magpie が各リクエストを GPT モデル向けに変換し、応答を戻します。ツール呼び出しも含みます。Antigravity アカウントも同じように antigravity/… として使えます。

複数のキーでルーティング

キーやアカウントが複数あれば、magpie は Claude Code のリクエストをそれらに分散し、1 つが使い切られたら次へ移れます。

  • 1 つのベンダーに複数のキー。 すべてをプロバイダに追加し、それぞれにチェックを入れます。プロバイダの Routing でリクエストの分散方法を決め、Fallback にはクォータ切れや障害のときに使うモデルを並べます。
  • 複数のプロバイダから同じモデル。 DeepSeek 自身の API とリレーのように、2 つのプロバイダが同じモデルを提供すると、magpie はグループ auto/<model> を自動で作ります。それを Claude Code に選びます。
  • 自分のグループ。 Routing タブの New group で、任意のモデルを 1 つの名前 group/<id> にまとめられます。

ルーティングモードははじめにで説明しています。

プロバイダ別：DeepSeek · Kimi と Kimi Code · GLM Coding Plan

よくある質問

ANTHROPIC_BASE_URL は自分で設定しますか？

いいえ。magpie が Claude Code の settings.json に書き込みます。シェルの環境変数に CLAUDE_CODE_USE_BEDROCK、CLAUDE_CODE_USE_VERTEX などのクラウドの切り替えが設定されていると、Claude Code は magpie ではなくそのクラウドにリクエストを送ります。その場合は magpie が知らせるので、シェルのプロファイルから取り除いてください。

Claude Code の中でモデルを切り替えられますか？

はい。Claude Code が magpie 経由で動いている間、/model には magpie のモデルとルーティンググループが並び、そこで選んだものは保持されます。

Claude Code で使える中国のモデルは？

追加したプロバイダが提供するものなら何でも使えます。magpie には DeepSeek、Kimi、Kimi Code、Zhipu GLM、Z.ai、MiniMax、Qwen のプリセットがあり、Kimi、Kimi Code、MiniMax、Qwen には中国向けエンドポイントもあります。それ以外はカスタム URL として追加できます。

magpie を起動しておく必要がありますか？

はい。Claude Code が magpie 経由のモデルを使っている間は必要です。ゲートウェイはアプリと一緒に動きます。magpie daemon install を使うと、ウィンドウなしのサービスとして動き続けます。

claude.ai のサインインはそのままにできますか？

Claude Code の行にサインインの設定があります。デフォルトの magpie’s key では、Claude Code が magpie 経由で動いている間は claude.ai からサインアウトされるため、/usage のプラン上限、コネクタ、音声、/teleport は使えません。claude.ai にするとサインインは保たれ、magpie がそれを外に渡すことはありません。Remote Control と ultrareview はどちらの場合も使えません。

Claude のサブスクリプションと DeepSeek を併用できますか？

はい。magpie で Claude にサインインすると、そのモデルが同じピッカーに claude/… として並びます。Claude サブスクリプションでのリクエストは、コンピューターにインストールされた Claude Code を通じて送られます。

元に戻すには？

magpie で Claude Code 自身のモデルを選ぶか、magpie claude default を実行します。magpie が書いたものが取り除かれ、置き換えたものが戻ります。

Codex も使っていますか？ Codex で好きなモデルを使うを参照してください。困ったときは Discord で質問してください。
