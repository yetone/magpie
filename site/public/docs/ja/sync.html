ドキュメント · ガイド

複数のコンピュータで magpie を同期：WebDAV・S3・GitHub

職場と自宅にコンピュータがあるときや新しいコンピュータにしたとき、プロバイダー・キー・各エージェントのモデルを設定し直す必要はありません。magpie はそれらを 1 つの暗号化ファイルとして自分の WebDAV・S3・非公開 GitHub リポジトリに置き、どのコンピュータもそれに合わせます。

同期されるもの

  • プロバイダー（キーも）と、それに選んだ画像。
  • 設定・プロファイル・各エージェントのモデル。
  • ライブラリ：指示セット、MCP サーバー、スキルとそのファイル。
  • npm や git から追加したプラグイン。ほかのコンピュータにもインストールされますが、プラグインのサインインは引き継がれません。
  • ゲートウェイのキー。設定と一緒に暗号化されます。

サブスクリプション（Claude・ChatGPT などのアカウント）は含まれないので、コンピュータごとにサインインします。モデルの選択と設定は同期され、サインインすると表示されます。同期の状態に、まだサインインしていないものが出ます。

同期をオンにする

  1. 同期をオンにする。設定 → 同期とバックアップ → WebDAV / S3 / GitHub 同期 でストレージを選ぶか、CLI で：
ターミナル
magpie webdav on https://dav.jianguoyun.com/dav/ user=me@example.com
magpie s3 on s3://my-bucket/magpie endpoint=https://.r2.cloudflarestorage.com access-key-id=…
magpie github on github://owner/private-backups/settings branch=main
magpie github                   # where it syncs to and how the last sync went
  1. どのコンピュータでも同じパスフレーズを使う。ファイルは手元でパスフレーズで暗号化してから送るので、サーバーには暗号文しかありません。
  2. 同期を待つ。ゲートウェイが動いている間、3 分ごとに同期します。各コンピュータは読んだ版の上にだけ書くので、2 台の変更はマージされ、失われません。

3 種類のストレージ

  • WebDAV：坚果云・Nextcloud・Synology などの WebDAV サーバー上のフォルダ。
  • S3：AWS S3・Cloudflare R2・Backblaze B2・MinIO・Garage・NAS などの S3 互換サーバー。バケットは先に作っておきます。MinIO や自前のサーバーの多くは path-style=yes が必要です。条件付き書き込みのないサーバー（Aliyun OSS）も使えます。2 台が同時に書いたときは、後の 1 台が次の同期で自分の変更をマージし直します。
  • GitHub：既存の非公開リポジトリと、Contents の読み書き権限だけを持つ fine-grained トークン。公開リポジトリは断ります。その履歴から誰でも暗号化された全版を取れてしまうからです。更新ごとに 1 コミットなので、履歴が暗号化バックアップの履歴になります。
ターミナル
magpie s3 on s3://backups endpoint=http://nas.local:9000 path-style=yes access-key-id=…

3 種類を切り替えても、ほかの設定と認証情報は戻すときのために残ります。同期するのは一度に 1 つです。

1 台だけ自分の値を保つ

あるコンピュータでエージェントのモデルを変えると、ほかのコンピュータにも届きます。同期で変わった値をそのコンピュータで元に戻すと、そのコンピュータは自分の値を保ちます。ほかの選択でもう変わらず、その選択もそこだけに残り、ほかのものは同期を続けます。このコンピュータだけで保持 にそのフィールドが並び、ほかのコンピュータに合わせる で同期の値に戻ります。

同期するものを選ぶ・プレビュー・取り消し

同期フォームの 同期するもの で、コンピュータごとに自分の値を保ちたいもののチェックを外します：プロバイダー、設定、エージェントのモデル、ライブラリ、メモリ（プロファイル・使用量・サインインは 詳細設定 にあります）。チェックのないものは送りも受け取りもしません。このコンピュータは自分の値を、サーバーはほかのコンピュータの値を保ちます。あとでチェックし直すと初回の同期のように加わり、このコンピュータの値は先に同期フォルダに保存されます。同期をプレビュー は、何も変えずに、こちらに来るものとサーバーへ行くものを項目ごとに示します。そこでの 今すぐ同期 は、その間に何も変わっていないときだけ同期します。前回の同期を取り消す は、前回の同期で入ってきたものをこのコンピュータでだけ元に戻します。

ターミナル
magpie webdav set providers=no settings=no agents=no   # ライブラリとメモリだけ同期
magpie webdav preview                                 # いま同期すると何が変わるか
magpie webdav undo-sync                               # 前回の同期で入ったものを戻す

一度きりのバックアップと復元

同期せず新しいコンピュータに移るだけなら、暗号化バックアップファイルを使います。

ターミナル
magpie backup                               # writes magpie.magpie-backup, asks for a passphrase twice
magpie backup --no-keys ~/b.magpie-backup   # no API keys in it
magpie restore magpie.magpie-backup         # on the other machine
magpie restore --no-agents b.magpie-backup  # agents left as they are

手元で AES-256-GCM で暗号化し、鍵はパスフレーズから PBKDF2-SHA256 で作るので、パスフレーズなしでは読めません。復元すると同じ ID のプロバイダーは置き換え、ほかは追加します。エージェントのモデルは、そのコンピュータに入っているエージェントにだけ設定します。

よくある質問

magpie は坚果云（Nutstore）で同期できますか？

できます。設定 → 同期とバックアップで WebDAV を選び、坚果云の WebDAV アドレスとアカウントを入れるか、magpie webdav on https://dav.jianguoyun.com/dav/ user=<アカウント> を実行します。どのコンピュータでも同じパスフレーズを使います。

クラウドへの同期は安全ですか？

ファイルは手元でパスフレーズで暗号化してから送るので、サーバーには暗号文しかありません。GitHub 同期は非公開リポジトリだけを受け付けます。

Claude や ChatGPT のサブスクも同期されますか？

されません。コンピュータごとにサインインします。モデルの選択と設定は同期され、サインインすると表示されます。

新しいコンピュータに移るだけなら？

magpie backup で暗号化バックアップを書き出し、移った先で magpie restore で戻します。--no-keys で API キーを含めずに書き出せます。
