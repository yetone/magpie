magpie・CC Switch・Claude Code Router の比較

magpie、CC Switch、Claude Code Router（CCR）は、どれも AI コーディングツールを好きなプロバイダとモデルで動かすためのものです。重なる部分もあり、それぞれに得意なことがあります。このページでは 3 つを並べて比べます。ほかの 2 つについてはそれぞれの README だけを、magpie についてはそのソースを根拠にしています。

CC Switch

Tauri 2 製のデスクトップアプリで、Claude Code、Codex、Gemini CLI から OpenCode、OpenClaw、Hermes、Pi、Kimi Code まで 12 のツールを管理します。プロバイダの切り替えでは設定の主要なフィールドだけを書き換え、最初の書き込みの前にバックアップを取ります。各ツールの MCP、Skills、プロンプトも 1 か所で管理できます。オプションのローカルルーティングモードは API 形式を変換し、キューでフェイルオーバーします。90 以上のプロバイダプリセットがあります。

Claude Code Router

127.0.0.1:3456 で動くローカルのモデルゲートウェイ兼コントロールプレーンです。Claude Code、Codex、Kimi CLI、Kilo Code、OpenCode、Pi などはエージェントプロファイルで 1 つの安定したエンドポイントにつながり、ルーティングルールが各リクエストの行き先を決めます：ヘッダーと本文の条件、書き換え、リトライ、認証情報プール、順序付きのフォールバック。モデルにビジョン、Web 検索、MCP、ブラウザ自動化を加え、すべてのリクエストを費用付きで記録します。デスクトップアプリ、Web UI 付きの npm CLI、Docker があります。

magpie

メニューバー（トレイ）アプリで、ウィンドウ、TUI、CLI があります。各ツールを 127.0.0.1:3425 のローカルゲートウェイにつなぎます。ゲートウェイは OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Gemini を話し、相互に変換するので、どのツールでもどのモデルでも使えます。Claude、ChatGPT、GitHub Copilot、Gemini のサインインも使えます。1 つのモデルの後ろに複数のキーやサインインを置け、ツールがエラーを見る前にフェイルオーバーします。

CC Switch と Claude Code Router の列は、2026 年 11 月時点の README に書かれていることだけです。README に書かれていないものは「記載なし」としています。どちらも更新が速いので、最新の情報はそれぞれのページで確認してください。

どれを選ぶか

  • CC Switch は、ツールごとにプロバイダを手で切り替えることが多く、設定を自分で書いた形に近いまま保ちたい人や、すべてのツールの MCP、Skills、プロンプトを 1 つのアプリで管理したい人に向いています。プロバイダプリセットは 3 つの中で最も多く、ほかの 2 つが挙げていない Claude Desktop、OpenClaw、Oh My Pi にも対応しています。
  • Claude Code Router は、プログラムできるゲートウェイがほしい人に向いています：ヘッダーと本文によるルール、リクエストの書き換え、認証情報プール、独自のクォータを持つクライアントキー、費用付きのリクエストログ。Web 検索やブラウザ自動化などのツールをモデルに加えられ、npm や Docker で GUI なしでも動きます。
  • magpie は、複数のツールを使い、それぞれを別のモデルで動かしたい人に向いています。たとえば Codex は DeepSeek、Claude Code は Kimi、あるいはほかのツールで Claude や ChatGPT のサブスクを使う、といった使い方です。すべてのツールが変換を行う 1 つのゲートウェイを通り、1 つのモデルを複数のアカウントが交代で受け持ち、フェイルオーバーします。

併用もできます。magpie のゲートウェイは OpenAI・Anthropic・Gemini 互換のエンドポイントなので、カスタムのベース URL を設定できるツールならプロバイダとして使えます。

よくある質問

CC Switch の代わりになるものは？

magpie と Claude Code Router が、それぞれ CC Switch の一部をカバーします。magpie はツールごとのモデルを切り替え、すべてのツールを変換ゲートウェイに通し、サブスクのサインインとフェイルオーバーに対応します。Claude Code Router はルーティングルールとリクエストログを持つ、プログラム可能なローカルゲートウェイです。

claude-code-router の代わりになるものは？

主にツールごとのプロバイダを切り替え、設定を書いたまま保ちたいなら CC Switch。多くのツールで使える変換ゲートウェイに、Claude・ChatGPT・Copilot・Gemini のサインインとフェイルオーバーするアカウントがほしいなら magpie です。

CC Switch と claude-code-router の違いは？

それぞれの README によると、CC Switch は各ツールの設定を書き換えるデスクトップの管理アプリで、オプションのローカルルーティングプロキシがあります。Claude Code Router は 127.0.0.1:3456 のローカルゲートウェイで、ツールはプロファイルでつながり、各リクエストはルールでルーティングされます。

magpie は CC Switch のようにツールの設定を書き換えますか？

各ツールの設定ファイルで変える 1 項目だけを、コメントと順序を保ったまま書き換え、127.0.0.1:3425 のゲートウェイに向けます。ツール自身のモデルを選び直すと元の値に戻ります。

magpie は claude-code-router のようなプロキシですか？

はい、magpie もローカルゲートウェイを動かします。OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Gemini を話して相互に変換するので、Responses しか話さない Codex も、Messages しか話さない Claude Code も、どのプロバイダのモデルでも使えます。

3 つとも無料のオープンソースですか？

はい。magpie、CC Switch、Claude Code Router はいずれも MIT ライセンスで公開されています。

ガイド：Claude Code でほかのモデルを使う、Codex でほかのモデルを使う、どのツールでもサブスクを使う。困ったときは Discord で質問してください。
