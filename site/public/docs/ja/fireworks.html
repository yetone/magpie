Fireworks

概要 Fireworks（従量課金） Fireworks Nexus Nexus で Claude と GPT を使う 補足

ドキュメント · ガイド

Fireworks と Fireworks Nexus を Claude Code・Codex などのエージェントで使う

Fireworks はオープンモデルを従量課金で提供しています。Fireworks Nexus は nexus.fireworks.ai にある独立したアカウントとプランで、Nexus Auto がモデルを選びます。magpie にはそれぞれのプリセット、fireworks と fireworks-nexus があります。

Fireworks（従量課金）

  1. キーを作る。app.fireworks.ai の Settings → Users → API Keys で作成します。
  2. 追加する。アプリで Fireworks を選び、APIキー にキーを貼り付けるか、CLI で追加します。
ターミナル
magpie provider add fireworks fw_…
magpie provider test fireworks
magpie claude fireworks/

プリセットは Chat Completions だけを https://api.fireworks.ai/inference/v1 で使い、一覧と価格は models.dev の fireworks-ai から取ります。Claude Code の Anthropic リクエストと Codex の Responses リクエストは、magpie が Chat に変換して送ります。

Fireworks Nexus

Nexus のキーは nexus.fireworks.ai で作るもので、Fireworks プラットフォームのキーとは別です。/inference エンドポイントは Chat Completions・Responses・Anthropic Messages のどれも話すので、Codex と Claude Code のリクエストはそれぞれの API のまま送られます。

ターミナル
magpie provider add fireworks-nexus fw_…
magpie codex fireworks-nexus/auto
magpie claude fireworks-nexus/auto

Pro と Team は auto（Nexus Auto）しか受け付けず、オープンモデルを直接指定すると 403 で断られます。そのためプリセットの一覧は auto だけです。Enterprise アカウントで使えるオープンモデルは、プロバイダーのモデルに ID を自分で入力します。

Nexus で Claude と GPT を使う

Nexus Auto が Claude と GPT を使うときは、あなた自身のキーを x-anthropic-api-key と x-openai-api-key の 2 つのヘッダーに入れるか、Nexus アカウントで Provider Keys を設定します。magpie のプロバイダー編集画面では ヘッダー がこの 2 つの名前を候補に出し、値はあなたが入れます。CLI では次のとおりです。

ターミナル
magpie provider set fireworks-nexus header.x-anthropic-api-key=sk-ant-…
magpie provider set fireworks-nexus header.x-openai-api-key=sk-…

自分で加えたヘッダーはすべてのリクエストに付きます。値を空にすると削除されます。

補足

  • エージェントがつなぐのは magpie だけで、Fireworks のキーもアドレスも持ちません。
  • 同じオープンモデルを提供するほかのプロバイダーと同じルーティンググループに入れれば、1 つが失敗しても次のメンバーが答えます。
  • Nexus のプランと上限は Fireworks 自身のページのとおりで、このページは magpie のつなぎ方だけを扱います。

よくある質問

magpie は Fireworks AI に対応していますか？

対応しています。fireworks プリセットに Fireworks の API キーを入れると、api.fireworks.ai/inference/v1 の Chat Completions を使います。モデル ID は fireworks/<モデル> です。

Fireworks Nexus と Fireworks の違いは？

Nexus は独立したアカウントとプランで、キーは nexus.fireworks.ai で作ります。エンドポイントは Chat・Responses・Messages を話し、Nexus Auto がモデルを選び、Pro と Team は auto だけです。

Nexus の一覧が auto だけなのはなぜ？

Pro と Team はオープンモデルの直接指定を 403 で断り、auto だけを受け付けます。Enterprise アカウントはオープンモデルの ID を自分で入力します。

Nexus で Claude と GPT を使うには？

自分の Anthropic と OpenAI のキーを x-anthropic-api-key と x-openai-api-key のヘッダーに入れるか、Nexus アカウントで Provider Keys を設定します。
