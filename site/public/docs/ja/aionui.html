AionUi

ドキュメント · ガイド

AionUi を任意のモデルで

AionUi は Claude Code、Codex、Gemini CLI を動かし、独自のチャットも持つ Electron のデスクトップアプリです。モデルプロバイダーは自身のデータベースにあり、キーは暗号化されているので、magpie はそこに何も書きません。代わりに AionUi 自身のプロバイダー追加リンクを開き、magpie を入力済みの AionUi のモデル追加フォームを出して、AionUi で確認してもらいます。すると AionUi で magpie のすべてのモデル（DeepSeek、GLM、Kimi、Qwen、OpenAI や Anthropic のキー、サインインした Claude、ChatGPT、Copilot のサブスクリプション）が使えます。

AionUi に magpie を追加

  1. AionUi を一度開くAionUi が一度動くとデータフォルダーに aionui フォルダーができ、magpie の エージェント ページに出ます。
  2. magpie にプロバイダーを追加プロバイダー ページで API キーを追加するか、サブスクリプションにサインインします。
  3. 「magpie を追加」をクリックAionUi の行で magpie を追加 をクリックします。AionUi が 設定 → モデル の追加フォームを開き、magpie が入力済みです：名前 magpie、プラットフォーム custom（OpenAI 互換）、ゲートウェイのアドレスとキー。
  4. AionUi で確認する確認するまで何も追加されません。

magpie が開くリンクはこのような形です：

ターミナル
aionui://add-provider?api_key=…&base_url=http%3A%2F%2F127.0.0.1%3A3425%2Fv1&name=magpie&platform=custom

何も開かないときは、このコンピューターに AionUi のリンクを扱うプログラムがまだありません。AionUi を一度開くか入れ直してから、もう一度 magpie を追加 をクリックしてください。

モデルを選ぶ

magpie プロバイダーのアドレスは AionUi 自身の OpenAI プリセットと同じく /v1 で終わり、ゲートウェイから magpie のすべてのモデルを プロバイダー/モデル の名前で一覧します（例 deepseek/deepseek-v4-pro）。あとで magpie に加えたプロバイダーは、AionUi で一覧を取り直せば出てきて、AionUi 側の変更は要りません。一つのモデルの裏の複数アカウント、429 後の休止、フォールバックは他のエージェントと同じく働きます。

コマンドライン

ターミナル
magpie aionui add      # AionUi を開いて magpie を追加し、そこで確認

追加済みを magpie が知る方法

magpie は AionUi のデータベース（AionUi のデータフォルダーの aionui/aionui-backend.db：macOS は ~/Library/Application Support/AionUi、Windows は %APPDATA%\AionUi、Linux は ~/.config/AionUi）を読み取り専用で読み、ゲートウェイのアドレスを指すプロバイダーがあるかを見ます。AionUi の起動中も読め、書くことはありません。あれば行に追加済みと出て、必要ならもう一度クリックして追加し直せます。データベースが読めないときは、未追加ではなく分からないと表示します。

使用量とキー

リンクのキーは AionUi 専用なので、そのリクエストは magpie の使用量で他のエージェントと分けて AionUi の分として数えられます。

よくある質問

AionUi で Claude や ChatGPT を使うのに API キーは要りますか？

要りません。magpie で Claude、ChatGPT、Copilot のサブスクリプションにサインインすれば、そのモデルが AionUi の magpie プロバイダーに出ます。

magpie は AionUi の設定を変えますか？

変えません。magpie は AionUi 自身のモデル追加フォームを開き、確認するのはあなたです。追加済みかを表示するために AionUi のデータベースを読むだけです。

magpie プロバイダーのアドレスとプラットフォームは？

プラットフォーム custom（OpenAI 互換）、アドレス http://127.0.0.1:3425/v1、または magpie で設定したゲートウェイのアドレスです。

magpie のエージェントページに AionUi がありません。

AionUi がこのコンピューターで一度動くと magpie に出ます。AionUi を一度開いてから見てください。

同じモデルを他のデスクトップアプリでも：magpie で Cherry Studio にすべてのモデルを、AstrBot を任意のモデルで。コーディングエージェントも使うなら どのエージェントでもサブスクを使う。エラーが出るときは よくあるエラーの直し方、または Discord で質問してください。
