Volcengine Ark

ドキュメント · プロバイダー

Volcengine Ark Coding Plan を Claude Code と Codex で

Volcengine Ark（火山方舟）には Coding Plan、Agent Plan、従量課金の 3 つがあります。プランはそれぞれ専用のエンドポイントを持ち、プランの枠はそこでだけ消費されます。従量課金の /api/v3 に送ると別に課金されます。magpie にキーとプランを追加すれば、Claude Code、Codex、Gemini CLI、OpenCode などが 127.0.0.1:3425 のローカルゲートウェイ経由で Ark の Doubao、GLM、DeepSeek、Kimi を使えます。

Volcengine Ark を追加

  1. キーを取得Ark の API キー管理ページ（ark.volcengine.com）で作成します。プランの枠はプランを契約してから消費されます。
  2. プロバイダーを追加してプランを選ぶプロバイダー で ＋ プロバイダーを追加 を押し、Volcengine Ark を選び、キーのプランを Coding Plan、Agent Plan、Pay as you go から選んで保存します。
  3. ツールで選ぶエージェント でツールの行に ark-code-latest や doubao-seed-2.1-pro などを選びます。
ターミナル
magpie claude volcengine/ark-code-latest
magpie codex volcengine/doubao-seed-2.1-pro
magpie opencode volcengine/glm-5.3

プランとエンドポイント

プランベース URL（Chat Completions と Responses）Anthropic Messages
Coding Planhttps://ark.cn-beijing.volces.com/api/coding/v3https://ark.cn-beijing.volces.com/api/coding
Agent Planhttps://ark.cn-beijing.volces.com/api/plan/v3https://ark.cn-beijing.volces.com/api/plan
従量課金https://ark.cn-beijing.volces.com/api/v3—（プリセットに Anthropic エンドポイントなし）

プランのパスはバージョン付きでそのまま使われ、/v1 は付きません。プロバイダー内の各キーが自分のプランを持つので、1 つのプロバイダーに Coding Plan、Agent Plan、従量課金のキーを並べられ、各キーのリクエストは自分のプランのエンドポイントに送られます。

プランのモデル

2 つのプランのモデルは同じです。プランの /models はプランのモデルを返さない（Coding Plan は Ark の一般カタログ、Agent Plan は 404）ため、magpie は Ark のプラン資料にあるテキストモデルを使います。先頭は ark-code-latest で、ark-code-latest, doubao-seed-evolving, doubao-seed-2.1-pro, doubao-seed-2.1-lite, doubao-seed-2.0-mini, glm-5.3, deepseek-v4-pro, deepseek-v4.1-flash, kimi-k3 and kimi-k3.1-pro などです。画像を受け付けるモデルも資料どおりで、glm-5.3-flash と deepseek-v4.1-flash は画像をそのまま受け取ります。従量課金キーは Ark 自身のモデル一覧を読みます。

各エージェントで

  • Claude Code は Anthropic Messages を話します。プランには専用の Anthropic エンドポイント（/api/coding、/api/plan）があり、リクエストはそのまま送られてプランの枠を使います。Claude Code で他のモデル。
  • Codex は OpenAI Responses だけを話します。Ark のプランのエンドポイントは Responses を提供するので、Codex のリクエストはそのまま送られ、モデルは /model に出ます。Codex で他のモデル。
  • Gemini CLI は Gemini の API を話し、magpie がローカルゲートウェイで変換します。Gemini CLI で他のモデル。
  • OpenCode：magpie がモデルを opencode.json に書きます。OpenCode で他のモデル。

Web 検索

Ark の Responses API は web_search ツールを自分で実行します（従量課金と両プラン。Chat API は非対応）。そのため Codex の Web 検索はリクエストから削られず、Ark が実行します。Ark が受け付けない include の値は外され、リクエスト全体が拒否されることはありません。

画像と動画

Agent Plan には Seedream 画像モデル（doubao-seedream-5-0-pro、doubao-seedream-5.0-flash）と Seedance 動画モデル（doubao-seedance-2.0、2.0-fast、2.0-mini、2.5）も含まれます。設定 → 画像 で選ぶと magpie の画像・動画ツールで使えます。Ark には OpenAI 形式の動画 API がないため、magpie は Ark の非同期生成タスクを使います。

利用枠

Coding Plan と Agent Plan には 5 時間、週、月の枠があります。Ark はそれをアカウントのコントロールプレーン（open.volcengineapi.com）にだけ伝え、推論キーには伝えないため、プロバイダーの編集画面でアカウントの AccessKey ID と Secret を求められます。入力すると行にプランの残りが表示されます。従量課金には枠がありません。

よくある質問

Volcengine Ark の Coding Plan を Claude Code で使うには？

magpie に Volcengine Ark を追加してキーのプランを Coding Plan にし、Claude Code の行で ark-code-latest などを選ぶか、magpie claude volcengine/ark-code-latest を実行します。リクエストはプランの Anthropic エンドポイント https://ark.cn-beijing.volces.com/api/coding に送られます。

Coding Plan のキーなのに従量課金されるのはなぜ？

プランの枠は専用のエンドポイントでだけ消費されます。Coding Plan は /api/coding/v3 と /api/coding、Agent Plan は /api/plan/v3 と /api/plan です。/api/v3 は従量課金です。magpie でキーのプランを選べば、プランのエンドポイントに送られます。

Volcengine Ark は Codex で使えますか？

使えます。プランのエンドポイントが OpenAI Responses を提供するので、magpie は Codex のリクエストをそのまま送り、Web 検索も Ark が実行します。magpie codex volcengine/doubao-seed-2.1-pro を実行するか、Codex の行で選びます。

Ark のプランの残りを見るには？

Volcengine Ark プロバイダーを編集してアカウントの AccessKey ID と Secret を入力します。行に 5 時間、週、月の枠が表示されます。

ほかのプロバイダーも同じ方法で：GLM Coding Plan、Kimi、DeepSeek、Qwen。エージェント別ガイド：Claude Code で他のモデル、Codex で他のモデル。エラーは トラブルシューティング へ、または Discord で質問してください。
