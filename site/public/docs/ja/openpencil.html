ドキュメント · ガイド

OpenPencil を任意のモデルで

OpenPencil（ZSeven-W/openpencil、openpencil-desktop）はデザインキャンバスで、チャットは自分で設定する「組み込みエージェント」でモデルを呼びます。Anthropic か OpenAI 互換のエンドポイント、キー、モデルの一覧で、どれもチャットのモデルピッカーに並びます。magpie が magpie という名前のエントリを加えると、OpenPencil が DeepSeek、GLM、Kimi、Qwen、Claude、ChatGPT サブスクリプションなど magpie の任意のモデルで動きます。

OpenPencil の設定

  1. magpie にプロバイダーを追加プロバイダー ページで API キーを追加するか、サブスクリプションにサインインします。
  2. OpenPencil を終了理由は下にあります。
  3. エージェント ページで OpenPencil に magpie を選ぶOpenPencil に並べるモデルにチェックを入れます。
  4. OpenPencil を開き、チャットのモデルピッカーで magpie のモデルを選ぶモデルはファイルではなく OpenPencil で選びます。
ターミナル
magpie openpencil magpie

settings.json のエントリ

OpenPencil は設定を一つの settings.json に置きます：

ターミナル
macOS    ~/Library/Application Support/openpencil/settings.json
Linux    ~/.config/openpencil/settings.json   ($XDG_CONFIG_HOME)
Windows  %APPDATA%\openpencil\settings.json

magpie は builtin_agents に id magpie、種類 openai-compat のエントリを一つ書きます。リクエストはゲートウェイの /v1 の下の /chat/completions に送られます。OpenPencil の User-Agent は分からないので、ゲートウェイはキー magpie-openpencil でそのリクエストを見分けます：

ターミナル
{"version": 1,
 "builtin_agents": [{"id": "magpie", "preset": "custom", "display_name": "magpie",
   "kind": "openai-compat", "api_key": "magpie-openpencil",
   "model": "", "models": ["", …],
   "base_url": "http://127.0.0.1:3425/v1", "enabled": true}]}

ほかのエントリと設定はそのまま、OpenPencil で magpie のエントリに付けた名前とオン／オフも残ります。version は 1 でなければなりません。ないと OpenPencil はファイルを壊れたものとして退け、以後設定を保存しなくなります。そこで magpie は自分で作るファイルに version 1 を書き、知らない version のファイルには触れません。

先に OpenPencil を終了

OpenPencil は起動時に一度だけ settings.json を読み、設定を変えたときと終了時に、持っている設定を丸ごと書き戻します。起動中に magpie が書いた内容は終了時に上書きされるので、その間 magpie は変更を断り、OpenPencil を終了してからもう一度試すよう伝えます。起動中かどうか分からない Windows では、先に終了するよう通知で案内します。

モデル一覧

エントリのモデルは、magpie のエージェントページで OpenPencil に選んだモデルで、重複なしで最大 64 個です（OpenPencil は次の保存で残りを捨てます）。2 個以上のときだけ models の一覧を書き、最初のものを model にも入れます。v0.8.4 は model しか読まないので、最初のモデルだけが並びます。magpie での変更は同期されます。

元に戻す

元に戻すと magpie は自分のエントリを builtin_agents から外し、残りが magpie の書いた version と空の一覧だけならファイルも消します。このときも先に OpenPencil を終了してください。

ターミナル
magpie openpencil default

同じ名前の別のアプリ open-pencil/open-pencil はプロバイダーを webview の localStorage に置くので、magpie は書けません。magpie が設定するエージェント（Pi、ACP エージェント）を通すか、ベース URL を入力すれば magpie を使えます。

よくある質問

OpenPencil で DeepSeek、GLM、ChatGPT サブスクリプションを使えますか？

使えます。OpenPencil を終了し、magpie のエージェントページで magpie を選んでから OpenPencil を開き、チャットのモデルピッカーで magpie のモデルを選びます。

なぜ先に OpenPencil を終了するのですか？

OpenPencil は終了時に設定を丸ごと settings.json に書き戻し、起動中に magpie が書いた内容を上書きするからです。

OpenPencil に magpie のモデルが一つしか出ません。

OpenPencil v0.8.4 は model しか読まないので、最初のモデルだけが並びます。新しい版は models の一覧を最大 64 個まで読みます。

元に戻すとほかの組み込みエージェントは残りますか？

残ります。magpie が外すのは id が magpie のエントリだけです。

同じモデルを他のデスクトップアプリでも：Alma を任意のモデルで、Kun を任意のモデルで、Pi を任意のモデルで。エラーが出るときは よくあるエラーの直し方、または Discord で質問してください。
