Kimi K2 と Kimi Code を Claude Code・Codex・Gemini CLI・OpenCode で使う

Moonshot AI の Kimi には、従量課金の Kimi API と Kimi Code メンバーシップの 2 つがあり、それぞれグローバル版と中国版のエンドポイントがあります。magpie には 4 つすべてのプリセットがあります。キーを一度追加すれば、Claude Code、Codex、Gemini CLI、OpenCode などが magpie のゲートウェイ 127.0.0.1:3425 を通して Kimi のモデルを使えます。

Kimi を追加する

  1. キーを取得Kimi API は Kimi プラットフォームの API キーページ、Kimi Code は Kimi Code コンソールで取得します。下の表にそれぞれのリンクがあります。
  2. プロバイダを追加プロバイダ で ＋ プロバイダを追加 を押し、キーを発行したプリセット（Kimi、Kimi（中国）、Kimi Code、Kimi Code（中国））を選んでキーを貼り付け、保存します。magpie が Kimi に提供モデルを問い合わせます。
  3. ツールで選ぶエージェント タブでツールの行の Kimi モデルを選びます。API なら kimi-k2.6、Kimi Code なら kimi-for-coding などです。
ターミナル
magpie provider add moonshot sk-…        # Kimi API（platform.kimi.ai）
magpie provider add moonshot-cn sk-…     # Kimi API 中国版（platform.kimi.com）
magpie provider add kimi-code sk-…       # Kimi Code メンバーシップ
magpie provider add kimi-code-cn sk-…    # Kimi Code メンバーシップ、中国版

モデル ID は provider/model 形式で、moonshot/kimi-k2.6、kimi-code/kimi-for-coding のようになります。並ぶのは、そのとき Kimi があなたのキーに提供しているモデルです。

ツールごとの使い方

エージェント タブで各ツールの行のモデルをクリックして選ぶか、ターミナルで選びます。各ガイドに、magpie がそのツールの設定に何を書くか、どう元に戻すかがあります。

ターミナル
magpie claude moonshot/kimi-k2.6
magpie codex moonshot/kimi-k2.6
magpie gemini model moonshot/kimi-k2.6
magpie opencode kimi-code/kimi-for-coding
  • Claude Code は Anthropic Messages を話し、Kimi の Anthropic エンドポイントも同じなので、リクエストはそのまま渡されます。opus・sonnet・haiku の各ティアは、個別に指定しない限り選んだモデルで動きます。Claude Code で他のモデル。
  • Codex が話すのは OpenAI Responses だけです。Kimi は Chat Completions と Anthropic Messages を提供し、Responses は提供していないので、magpie がリクエストと返答を変換します。ストリーミングとツール呼び出しもそのままです。モデルは推論レベル付きで Codex の /model に並びます。Codex で他のモデル。
  • Gemini CLI は Gemini の API を話します。magpie がゲートウェイに向けて変換します。Gemini CLI で他のモデル。
  • OpenCode には、magpie が opencode.json にモデルを推論バリアントと価格つきで書きます。OpenCode で他のモデル。

思考

常に思考する Kimi モデルもあります。Kimi Code（中国）の K3.1 は思考をオフにするリクエストを受け付けません。ツールがオフを求めてモデルが断ったとき、magpie は思考をオンのまま聞き直すので、ツールにはエラーではなく返答が届きます。

残高・使用量ウィンドウ・検索

  • Kimi API。行に残高が表示されます。Kimi（中国）は人民元、Kimi はドルです。
  • Kimi Code。Kimi から読んだメンバーシップのウィンドウ（週の枠、5 時間などの短いウィンドウ、月の枠、ブースターパックの残高）が行に表示されます。
  • 費用。Kimi Code のモデルは $0 と記載されているので、magpie の 使用量 タブは同じモデルの Kimi API 価格で計算します。
  • ウェブ検索。Kimi Code のキーはメンバーシップ専用の検索エンドポイントで検索でき、magpie は自分では検索できない Kimi Code モデルにそれを渡します。

よくある質問

Kimi K2 を Codex で使うには？

magpie に Kimi のキーを追加し、Codex の行で kimi-k2.6 などの Kimi モデルを選ぶか、magpie codex moonshot/kimi-k2.6 を実行します。Kimi は Codex が話す Responses API を提供していないので、magpie がリクエストと返答を変換します。ストリーミングとツール呼び出しもそのままです。

Kimi Code のメンバーシップを Claude Code や Codex で使えますか？

使えます。Kimi Code（または Kimi Code（中国））のプリセットに Kimi Code コンソールのキーを追加します。magpie はメンバーシップ専用のエンドポイントにリクエストを送り、使用量ウィンドウを表示します。

Kimi と Kimi（中国）のどちらを選べば？

キーを発行したほうです。platform.kimi.ai のキーは Kimi（api.moonshot.ai）、platform.kimi.com のキーは Kimi（中国）（api.moonshot.cn）。Kimi Code も kimi.ai と kimi.com の 2 つに分かれます。

Kimi Code は定額なのに、なぜ費用が表示されますか？

Kimi Code のモデル一覧は価格を $0 としているので、magpie は同じモデルの Kimi API 価格で各呼び出しを計算します。API で同じ作業をした場合の額で、請求はされません。

Kimi Code でウェブ検索できますか？

できます。Kimi Code のキーはメンバーシップ専用の検索エンドポイントで検索でき、magpie は自分では検索できない Kimi Code モデルにその検索を渡します。

ツールごとのガイド：Claude Code で他のモデル、Codex で他のモデル、Gemini CLI で他のモデル、OpenCode で他のモデル。困ったときは Discord で質問してください。
