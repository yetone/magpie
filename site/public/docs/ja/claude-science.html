Claude Science

ドキュメント · ガイド

Claude Science を任意のモデルで

Claude Science は Anthropic の研究アプリです。デーモン claude-science が localhost で UI を提供し、ウィンドウ（Mac では Swift のランチャー、Windows では Electron、Linux ではブラウザー）は動いているデーモンにつながり、なければ自分で起動します。デーモンは環境変数 ANTHROPIC_BASE_URL が指すアドレスに Anthropic の Messages API を求め、アプリにはそれを変える設定がありません。そこで magpie はゲートウェイを指す ANTHROPIC_BASE_URL でデーモンを起動し、Claude Science は DeepSeek、GLM、Kimi、Qwen、ChatGPT サブスクなど magpie の任意のモデルで動きます。

Claude Science を設定する

  1. magpie にプロバイダーを追加プロバイダー ページで API キーを追加するか、サブスクリプションにサインインします。
  2. エージェント ページで Claude Science のプロバイダーを magpie にするmagpie がデーモンを再起動します。実行中のセッションは中断されます。
  3. Claude Science を開き直すウィンドウが開いていれば再読み込みし、モデルメニューで magpie のモデルを選びます。

デーモン

magpie がするのは一つだけです。stop してから、元のポートで serve --detached --no-browser を ANTHROPIC_BASE_URL 付きで起動します。あなたの環境変数は設定せず、Claude Science のファイルも書きません。ターミナルで手動で起動するなら次と同じです。

ターミナル
claude-science stop; ANTHROPIC_BASE_URL=http://127.0.0.1:3425 claude-science serve --detached

Claude Science が受け付けるのは https のアドレスか、ループバックアドレスの http なので、ローカルのゲートウェイ http://127.0.0.1 がそのまま使えます。magpie は claude-science を Mac アプリのバンドル、Windows のユーザー別 Programs フォルダー、インストーラーがリンクする ~/.local/bin（Linux ではここだけ）、または PATH から探します。

Claude のサインイン

Claude Science には引き続き Claude アカウントでのサインインが必要で、API キーは使えません。サインインしていなければ何も送りません。サインインするとその資格情報をリクエストの Bearer として送りますが、magpie のゲートウェイはどのプロバイダーにも転送しません。ゲートウェイは毎回付く X-Anthropic-Surface: operon ヘッダーで Claude Science のリクエストを見分けます。

モデルメニュー

Claude Science のモデルメニューは claude- で始まる ID しか表示しないため、magpie は各モデルを別名 claude-magpie-<番号> で渡し、表示名はエージェントページと同じにします。あなたの選択がない場面（選ぶ前の既定モデル、小さな作業用の haiku）では Claude 自身の ID で求めます。magpie が提供しないモデルは、直前のターンのモデルに回します。

接続を保つ

デーモンは止められるかコンピューターが再起動するまで動きます。接続中、動いていなければ magpie が再び起動します。Claude Science のウィンドウはデーモンがないと変数なしで自分のものを起動し、アプリは更新後に自分のデーモンに替えることを提案することがあります。magpie はセッションが動いていないときに自分のデーモンに戻しますが、launchd や systemd などのサービスマネージャーが管理するもの（止めてもすぐ戻る）には替えません。その間はエージェントページに表示されます。1 時間のうちに何度も元に戻されたものはそのままにします。

WSL

Claude Science が WSL のディストリビューションにあるとき、Windows の magpie は wsl.exe 経由でそこでデーモンを ANTHROPIC_BASE_URL 付きで起動し、ディストリビューションが動いている間は接続を保ちます。止まっているディストリビューションは起動しません。ミラーネットワークではディストリビューションの 127.0.0.1 が Windows のものなので、ゲートウェイのアドレスをそのまま渡します。NAT では magpie がディストリビューション内で 127.0.0.1 のゲートウェイのポートに socat の中継を立て、WSL ネットワーク上の Windows のアドレスにつなぎます。

元に戻す

エージェントページで Claude Science の magpie をオフにすると、magpie は動いているデーモンを変数なしで再起動し、Anthropic の API に戻します。

よくある質問

Claude Science で DeepSeek、GLM、ChatGPT サブスクを使えますか？

はい。magpie のエージェントページで Claude Science のプロバイダーを magpie にし、モデルメニューで magpie のモデルを選びます。

magpie は Claude Science のファイルや環境変数を変えますか？

いいえ。ANTHROPIC_BASE_URL 付きでデーモンを再起動するだけで、ファイルは書かず、変数も設定しません。

Claude アカウントでのサインインは必要ですか？

はい。Claude Science は API キーを受け付けず Claude のサインインが必要です。その資格情報を magpie はどのプロバイダーにも転送しません。

モデル名が claude-magpie で始まるのはなぜですか？

Claude Science は claude- で始まる ID しか表示しないため、magpie は各モデルを claude-magpie-<番号> として渡し、表示名はエージェントページと同じにします。

同じモデルを他のエージェントでも：Claude Desktop を任意のモデルで、mu を任意のモデルで、Mister Morph を任意のモデルで、VS Code を任意のモデルで。エラーが出るときは よくあるエラーの直し方、または Discord で質問してください。
