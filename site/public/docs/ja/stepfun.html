StepFun Step Plan を Claude Code と Codex で

StepFun には中国の platform.stepfun.com と国際の platform.stepfun.ai の 2 サイトがあり、アカウントは別です。どちらにも Step Plan と従量課金があり、Step Plan は専用の step_plan エンドポイントで提供され、そのキーは従量課金のエンドポイントでは拒否されます。magpie でサイトに合うプロバイダーを追加してキーのプランを選べば、Claude Code、Codex、Gemini CLI、OpenCode が 127.0.0.1:3425 のローカルゲートウェイ経由で Step のモデルを使えます。

StepFun を追加

  1. プロバイダーを追加してプランを選ぶプロバイダー で ＋ プロバイダーを追加 を押し、StepFun か StepFun (China) を選び、キーのプランを Step PlanかPay as you go から選んで保存します。
  2. ツールで選ぶエージェント でツールの行に step-5-preview などを選びます。

国際サイトのアカウントは StepFun（プロバイダー id stepfun）、中国サイトは StepFun (China)（stepfun-cn）です。

ターミナル
magpie claude stepfun-cn/step-5-preview
magpie codex stepfun-cn/step-3.7-flash
magpie opencode stepfun/step-5-preview

Step Plan のキーは step_plan 以下のエンドポイントでしか使えず、従量課金では拒否されるため、magpie はキーのプランに従ってリクエストを送ります。同じサイトの Step Plan キーと従量課金キーは 1 つのプロバイダーに並べられます。どちらも Responses はありません。

モデル

Step Plan のカタログのチャットモデルは step-5-preview、step-3.7-flash、step-3.5-flash、step-3.5-flash-2603 で、中国の Step Plan には step-router-v1 もあります。従量課金には音声モデル stepaudio-2.5-asr、stepaudio-2.5-tts、step-tts-2 があります。

残高と Step Plan の枠

  • 残高：magpie は API キーで /v1/accounts を読み、中国サイトは人民元、国際サイトはドルで表示します。
  • Step Plan の枠：5 時間枠、週の枠、月のクレジットはキーではなく StepFun プラットフォームのサインインにだけ返されます。自分のブラウザでサインインし、そのページで magpie のブックマークレットを実行して、コピーされた内容を magpie に貼り付けます。以後 magpie がサインインを更新して枠を読みます。サインインは providers.json の隣の stepfun-auth.json に、あなただけが読める形で保存されます。

各エージェントで

  • Claude Code は Anthropic Messages を話します。StepFun の両サイトに Anthropic エンドポイントがあり、リクエストはそのまま送られます。Claude Code で他のモデル。
  • Codex は OpenAI Responses だけを話します。StepFun は Responses を提供しないため、magpie が Codex のリクエストを Chat Completions に変換します。apply_patch などのカスタムツールも使えます。モデルは /model に出ます。Codex で他のモデル。
  • Gemini CLI は Gemini の API を話し、magpie がローカルゲートウェイで変換します。Gemini CLI で他のモデル。
  • OpenCode：magpie がモデルを opencode.json に書きます。OpenCode で他のモデル。

よくある質問

StepFun Step Plan を Claude Code で使うには？

magpie に StepFun か StepFun (China) を追加してキーのプランを Step Plan にし、Claude Code の行で step-5-preview を選ぶか、magpie claude stepfun/step-5-preview を実行します。

Step Plan のキーが /v1 で拒否されるのはなぜですか？

Step Plan のキーは step_plan 以下のエンドポイントでしか使えません。magpie でキーのプランを Step Plan にすれば /step_plan/v1 に送られます。

StepFun は Codex で使えますか？

使えます。Responses エンドポイントがないため、magpie が Codex のリクエストを Chat Completions に変換します。magpie codex stepfun/step-3.7-flash を実行してください。

Step Plan の 5 時間と週の枠を magpie で見られますか？

見られます。ブラウザで platform.stepfun.ai か .com にサインインし、magpie のブックマークレットを実行してコピーされた内容を magpie に貼り付けてください。残高はキーだけで見られます。

ほかのプロバイダーも同じ方法で：Xiaomi MiMo、Huawei Cloud MaaS、MiniMax、GLM Coding Plan、Kimi、DeepSeek、Qwen。エラーは トラブルシューティング へ、または Discord で質問してください。
