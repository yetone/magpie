コントリビューター

magpie は、何が壊れたか、何が足りないかを教えてくれる人たちによって形作られています。以下の全員が magpie の履歴に名前が記されており、その報告やアイデア、コードが入ったリリースを新しい順に並べています。ありがとうございます。

一覧

一覧はサイトをデプロイするたびに git の履歴から作られますが、今はここにありません。GitHub の各リリースノートの最後に、そのリリースで感謝する人が載っています。

名前の集め方

リリースに入ったコミットが次のどれかに当てはまると、その名前が載ります。

  • コミットの件名にその人の名前がある（(name on Discord)、(spotted by @login) など）。
  • コミットが挙げる issue や pull request（#1234、plugins#56）をその人が GitHub で開いた。
  • その人がコミットを書いた、または共同作者である。

magpie の履歴ですでに公開されている名前だけを、そこでの表記のまま使います。メールアドレスは表示しません。メンテナー、コーディングエージェント、ボットは載せません。GitHub へのリンクがある名前はそのアカウントで、名前の下のプラットフォームは報告が来た場所です。一覧はサイトをデプロイするたびに更新され、各リリースノートも同じ方法でそのリリースの人に感謝します。

載せないでほしいとき

ここやリリースノートに名前を載せたくない場合は、Discord で伝えるか、issue を開くか、site/contributors-exclude.txt に名前を加える pull request を送ってください。次のデプロイと次のリリースから載らなくなります。名前の間違いや漏れも同じように教えてください。
