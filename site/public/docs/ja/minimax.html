MiniMax と Coding Plan を Claude Code・Codex・Gemini CLI・OpenCode で使う

MiniMax は OpenAI 互換の Chat API と Anthropic 互換の API を、国際版と中国版のサイトで、従量課金と Coding Plan のどちらのキーにも提供しています。キーを magpie に一度追加すれば、Claude Code・Codex・Gemini CLI・OpenCode などつないだすべてのツールが、magpie のゲートウェイ 127.0.0.1:3425 経由で MiniMax-M3 や MiniMax-M2.7 などのモデルを使えます。

MiniMax を追加する

  1. キーを取得platform.minimax.io で作ります（中国版は platform.minimaxi.com）。Coding Plan のキーは sk-cp- で始まります。
  2. プロバイダを追加magpie の プロバイダ で ＋ プロバイダを追加 を押し、MiniMax か MiniMax (China) を選んでキーを貼り付け、保存します。従量課金のキーも Coding Plan のキーも同じ手順です。
  3. ツールで選ぶエージェント タブで、ツールの行の MiniMax モデルを選びます。
ターミナル
magpie provider add minimax sk-…        # platform.minimax.io
magpie provider add minimax-cn sk-cp-…  # Coding Plan、platform.minimaxi.com

プランとエンドポイント

プリセットサイトChat CompletionsAnthropic Messages
MiniMax minimaxplatform.minimax.io（国際）https://api.minimax.io/v1https://api.minimax.io/anthropic
MiniMax (China) minimax-cnplatform.minimaxi.com（中国）https://api.minimaxi.com/v1https://api.minimaxi.com/anthropic

Coding Plan も従量課金と同じエンドポイントを使い、どちらで課金されるかはキーで決まります。国際版と中国版は別のアカウントなので、キーはそれぞれのサイトのプリセットに入れます。

ツールごとの使い方

エージェント タブで各ツールの行のモデルをクリックして選ぶか、ターミナルで選びます。各ガイドに、magpie がそのツールの設定に何を書くか、どう元に戻すかがあります。

ターミナル
magpie claude minimax/MiniMax-M3
magpie codex minimax/MiniMax-M3
magpie gemini model minimax/MiniMax-M2.7
magpie opencode minimax/MiniMax-M3
  • Claude Code は Anthropic Messages を話し、MiniMax の Anthropic エンドポイントも同じなので、リクエストはそのまま渡されます。opus・sonnet・haiku の各ティアは、個別に指定しない限り選んだモデルで動きます。Claude Code で他のモデル。
  • Codex が話すのは OpenAI Responses だけです。MiniMax は Chat Completions と Anthropic Messages を提供し、Responses は提供していないので、magpie がリクエストと返答を変換します。ストリーミングとツール呼び出しもそのままです。モデルは推論レベル付きで Codex の /model に並びます。Codex で他のモデル。
  • Gemini CLI は Gemini の API を話します。magpie がゲートウェイに向けて変換します。Gemini CLI で他のモデル。
  • OpenCode には、magpie が opencode.json にモデルを推論バリアントと価格つきで書きます。OpenCode で他のモデル。

MiniMax Code も magpie がつなぐエージェントの一つで、その行では MiniMax のモデルも他社のモデルも選べます。

思考と推論レベル

  • インターリーブ思考。MiniMax の Chat API はモデルの思考を返答本文の <think> タグに入れて返し、次のターン以降もそこに戻すよう求めます。magpie はそれを思考としてツールに渡し、MiniMax が求める位置に戻します。
  • 推論レベル。MiniMax-M3.1-Flash とそのプレビューは low から max までの思考レベルを持ちます。magpie は MiniMax Code と同じように、ツールが求めるレベルを output_config.effort で送るので、トークン予算に置き換わって失われることはありません。
  • 常に思考するモデル。MiniMax-M3.1-Flash-Preview は思考をオフにできません。ツールがオフを求めたとき、magpie は思考をオンのまま聞き直すので、ツールにはエラーではなく返答が届きます。

Coding Plan のウィンドウと使用量

  • Coding Plan のウィンドウ。Coding Plan のキーの行に、MiniMax から読んだ各ウィンドウ（ローリングのものと週単位のもの）の残りが表示されます。モデルは汎用の枠を使い、動画など別に数える枠は 4 / 5 のように回数で表示されます。従量課金のキーにはウィンドウもカードもありません。
  • ルーティング。Coding Plan のキーが複数あるとき、magpie はウィンドウで重みづけし、ウィンドウを使い切ったキーはリセットまで休ませます。
  • 使用量。使用量 タブは、magpie を通った各ツールとモデルのトークン、キャッシュヒット、費用を数えます。

よくある質問

Claude Code で MiniMax M2.7 や M3 を使うには？

magpie に MiniMax のキーを追加し（プロバイダ → プロバイダを追加 → MiniMax か MiniMax (China)）、Claude Code の行で MiniMax-M3 などのモデルを選ぶか、magpie claude minimax/MiniMax-M3 を実行します。magpie が Claude Code の settings.json を書き、リクエストを MiniMax の Anthropic エンドポイント https://api.minimax.io/anthropic に渡します。

MiniMax Coding Plan はどう使いますか？

Coding Plan のキー（sk-cp-…）を、購入したサイトの MiniMax プリセットに従量課金のキーと同じように追加します。magpie は MiniMax がそのキーについて返す情報で両者を見分け、Coding Plan のキーの行に使用量ウィンドウを表示します。

Codex で MiniMax を使えますか？

使えます。MiniMax は Chat Completions と Anthropic Messages を提供し、Responses は提供していないので、magpie が Codex のリクエストと MiniMax の返答を変換します。Codex の行で選ぶか magpie codex minimax/MiniMax-M3 を実行すると、Codex の /model に並びます。

MiniMax Code で他のモデルを使えますか？

使えます。MiniMax Code は magpie がつなぐエージェントの一つなので、エージェント タブのその行で、追加したどのモデルでも選べます。

MiniMax の思考が本文に出るのはなぜ？

MiniMax の Chat API はモデルの思考を返答本文の <think> タグに入れて返します。magpie はそれを取り出して思考としてツールに渡し、次のターンからは MiniMax が求める位置に戻します。

MiniMax のキーを複数使えますか？

使えます。すべて MiniMax プロバイダに追加してそれぞれにチェックを入れます。magpie はリクエストを分散し、Coding Plan のキーはウィンドウで重みづけして、使い切ったキーはリセットまで休ませます。

ツールごとのガイド：Claude Code で他のモデル、Codex で他のモデル、Gemini CLI で他のモデル、OpenCode で他のモデル。困ったときは Discord で質問してください。
