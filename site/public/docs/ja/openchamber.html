OpenChamber を任意のモデルで

OpenChamber は OpenCode のデスクトップ、Web、VS Code フロントエンドです。自分の OpenCode（デスクトップ版は OpenCode 2 を同梱）を、あなたの OpenCode 設定で動かします。magpie は OpenChamber の既定モデルを magpie のモデルにし、OpenCode 設定に magpie プロバイダーを置きます。そのため OpenChamber で magpie のすべてのモデル（DeepSeek、GLM、Kimi、Qwen、OpenAI や Anthropic のキー、ChatGPT や Copilot のサブスクリプション）が使えます。

OpenChamber の設定

  1. magpie にプロバイダーを追加プロバイダー ページで API キーを追加するか、サブスクリプションにサインインします。
  2. OpenChamber の行でモデルを選ぶエージェント ページで OpenChamber の既定モデルを選び、必要なら小モデルも選びます。
  3. 新しいセッションを始めるOpenChamber は新しいセッションから新しいモデルを使います。
ターミナル
magpie openchamber deepseek/deepseek-v4-pro          # new sessions
magpie openchamber small deepseek/deepseek-v4-flash  # titles, commit messages

OpenChamber の設定は $OPENCHAMBER_DATA_DIR、既定では ~/.config/openchamber にあります（XDG_CONFIG_HOME では移りません）。magpie はプロファイルの preferences.json と、古いビルドが読む settings.json のコピー（あれば）を書きます：

ターミナル
// ~/.config/openchamber/preferences.json
{"version": 1, "fields": {
  "defaultModel": {"value": "magpie/deepseek/deepseek-v4-pro", "updatedAt": …},
  "smallModelUseDefault": {"value": false, …},
  "smallModelOverride": {"value": "magpie/deepseek/deepseek-v4-flash", …}
}}

セッションのモデルの決まり方

OpenChamber は新しいセッションに、プロジェクトの defaultModel（settings.json の projects）、プロファイルの defaultModel、エージェント自身のモデル、最後に OpenCode の model の順でモデルを送ります。そのため OpenCode のモデルだけを変えても OpenChamber には届かず、magpie はプロファイルの defaultModel を設定します。独自の既定モデルを持つプロジェクトではそちらが使われ、magpie はプロジェクトとモデルを知らせます。モデルを変えるときは、OpenChamber 自身の選択と同じく、前のモデルの defaultVariant も消します。

小モデル

OpenChamber の小モデルはセッションのタイトルとコミットメッセージを書きます。smallModelUseDefault が false なら smallModelOverride、そうでなければ OpenCode の small_model です。magpie で小モデルを選ぶとこの二つのキーを書き、元に戻すと両方を外して OpenCode に任せます。

OpenCode の設定

OpenChamber のモデルは OpenCode の provider/model なので、magpie のモデルには OpenCode 設定（$OPENCODE_CONFIG_DIR、なければ $XDG_CONFIG_HOME/opencode）の magpie プロバイダーが要ります。そのモデルをすでに magpie のゲートウェイへ送る自分のプロバイダーがあれば、同じモデルの二つ目のリストは作らずそれを使います。OpenCode 2 の設定は OpenCode 2 の書き方で書きます。OpenChamber が magpie を使わなくなり、OpenCode 設定のほかの場所でも magpie のモデルを使っていなければ、magpie プロバイダーも外します。リクエストは OpenChamber の OpenCode が送るので、OpenCode の分として数えます。

新しいセッションと開いているセッション

OpenChamber は新しいセッションで新しいモデルを使い、開いているセッションは元のままです。OpenChamber の起動中は magpie もそう知らせます。

元に戻す

magpie で行を既定に戻すと、プロファイルの defaultModel と defaultVariant を外し、OpenChamber は OpenCode 設定のモデルに戻ります。

ターミナル
magpie openchamber default

よくある質問

OpenChamber で DeepSeek、GLM、Kimi、Qwen は使えますか？

使えます。magpie が OpenChamber の既定モデルを magpie で選んだモデルにし、OpenCode 設定に magpie プロバイダーを置きます。

OpenCode はもう magpie なのに、OpenChamber が前のモデルのままです。

OpenChamber はプロジェクトとプロファイル独自の defaultModel を OpenCode の model より先に使います。magpie で OpenChamber の行にモデルを選んでください。

一つのプロジェクトだけ前のモデルです。

そのプロジェクトは settings.json に独自の既定モデルを持ち、そこでは優先されます。magpie がプロジェクト名を知らせます。

セッションのタイトルとコミットメッセージはどのモデルが書きますか？

小モデルです。smallModelUseDefault が false なら smallModelOverride、そうでなければ OpenCode の small_model です。

同じモデルを他のエージェントでも：OpenCode で他のモデル、T3 Code を任意のモデルで、Craft Agents を任意のモデルで。エラーが出るときは よくあるエラーの直し方、または Discord で質問してください。
