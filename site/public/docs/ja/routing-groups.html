ドキュメント · ガイド

アカウント・キー・プロバイダーのローテーションとフェイルオーバー

Claude のサブスクリプション一つでは足りない、API キーがすぐレート制限される、DeepSeek が落ちたら別のベンダーに切り替えたい。magpie はリクエストを二段でルーティングします。一つのプロバイダーのアカウントやキーの間と、ルーティンググループのプロバイダーやモデルの間です。返信がエージェントに届き始める前に上流が失敗すると、magpie は次の候補に移り、エージェントは気づきません。

複数のアカウントやキー

プロバイダーに二つ目のアカウントやキーを追加してオンにすると、編集画面に ルーティング と 維持 が現れ、リクエストをどう分けるかを決めます。

枠が残っているのにレート制限（429）されたものの扱いも選べます。位置を維持 はベンダーの指定どおり休んでから元の位置に戻り、最後尾へ はレート制限されていないものの後ろに回り、毎回先頭に戻らず負荷が回ります。

ルーティング

  • スマート（既定）：枠に余裕のある間は最初のものが受け、少なくなると残りが最も多いものが引き継ぎます。クレジット切れは 30 分、枠切れはリセットまで、レート制限はベンダーの指定どおり、エラーは 1 分（繰り返すと長く）休みます。
  • 順番：最初のものに送り、枠切れ・レート制限・エラーで次が引き継ぎます。
  • 交互：会話のターンごとに次へ回して負荷を分けます。ターン内のリクエストは始まった場所に残り、プロンプトキャッシュが保たれます。
  • 使用量が最少のものを優先：サブスクリプションは使った枠の割合、キーは直近数時間のトークン数で決めます。
  • 週ペース：更新までの 1 時間あたりの残りが最も多いサブスクリプションへ送り、週のリセットで失う分を減らします。90% 以上使ったものはほかが答えられないときまで待ちます。
  • 重み付け：各キーの重みで分けます。重み 3 のキーは重み 1 のキーの 3 倍を受けます。キーのみで、アカウントには使えません。
  • 無料優先：費用のかからないものを先に使い、それが答えられないときだけ費用のかかるものへ。

維持

維持 は、会話を答えたアカウントやキーに留めるかを決めます。

  • 自動（既定）：ベンダーのキャッシュに保つ価値がある間は留まり、ターン内では常に留まります。
  • セッション：答えられる限りセッション全体で留まります。
  • ターン内：エージェントがツール結果を返す間は動かず、次に話しかけると改めてルーティングします。
  • オフ：リクエストごとに改めてルーティングします。
  • 厳格：レート制限や枠切れでも移らず、エラーがエージェントに届きます。新しい会話は通常どおりです。

ルーティンググループ

ルーティンググループは異なるプロバイダーのモデルをまとめます。たとえば Claude サブスクリプションの Opus と Copilot の Opus、あるいは複数の無料モデルです。エージェントはモデルとして group/<id> を選び、magpie はグループのルーティングとルールに従って各リクエストを送ります。グループは ルーティング ページの ルーティンググループ にあり、新しいグループ で作ります。

  1. magpie が自分でグループを見つける二つ以上のプロバイダーが提供するモデルは自動でグループ（auto-<モデル>）になり、設定は不要です。不要なら グループを自動で作成 をオフにします。
  2. 入れられるものprovider/model で書いた任意のモデル、別のグループ（8 段まで）、パターン。openrouter/*:free なら後から増える無料モデルも入ります。
  3. グループのルーティング上のものに加えて、重み付け（モデルごとの重み）と 手動（選んだモデルだけ、切り替えなし）があります。
  4. ルールターンの長さ、画像の有無、求められた推論の強さ、エージェントで、ターンを最初にどのモデルへ送るかを決めます。

推論の強さも決められます。メンバーを :high などに固定するか、分類モデルが各ターンの始めに難しさを判断して low から xhigh を選びます。

CLI

ターミナル
magpie groups                       # yours, then those magpie found
magpie group add "Opus anywhere" models=claude/claude-opus-5-5,copilot/claude-opus-5.5 routing=order
magpie group set opus-anywhere stays=session models+=openrouter/anthropic/claude-opus-5.5
magpie group set opus-anywhere routing=weight weight=claude/claude-opus-5-5=3
magpie group add my-free-pool models='openrouter/*:free,opencode-zen/*-free' routing=order
magpie group pick opus-anywhere copilot/claude-opus-5.5
magpie claude group/opus-anywhere

ルーティング：smart、order、rotate、usage、pace、weight、manual。維持：auto、session、turn、off、strict。magpie group help ですべての項目が出ます。

既成のグループ

magpie group template は、よくある用途のグループを自分のモデルで一度に作ります。

  • smart：難しいターンは最も強いモデル、簡単なものは安いモデルへ。分類モデルが見分けます。
  • thrifty：まず安いモデル、高い推論や安いものが失敗したときに最も強いモデル。
  • steady：最大三つのプロバイダーそれぞれの最も強いモデルを、順に後ろで控えさせます。
ターミナル
magpie group template            # lists smart, thrifty, steady and the models each would take
magpie group template steady

使い切る前に各アカウントの残りを見るには サブスクリプションとキーの残り枠を見る を参照してください。

よくある質問

複数の Claude アカウントを交互に使えますか？

使えます。同じ Claude サブスクリプションに追加し、編集画面に ルーティング が出たら 交互 か 使用量が最少のものを優先 を選びます。一つが枠切れになると次へ回ります。

API キーがレート制限（429）されたら？

ベンダーの指定どおり休み、同じプロバイダーのほかのキーへ回ります。最後尾へ を選ぶと後ろに回り、負荷が回ります。

DeepSeek が落ちたら別のモデルに切り替えられますか？

できます。DeepSeek と代わりのモデルを順に入れたルーティンググループを作り、ルーティングを 順番 にして、エージェントで group/ を選びます。返信が始まる前の失敗なら次へ移ります。

アカウントを切り替えるとプロンプトキャッシュは失われますか？

維持 は既定で 自動 です。キャッシュに価値がある間は同じアカウントに留まり、ターン内では常に留まるので、ローテーションでリクエストごとにキャッシュを失うことはありません。

関連ページ：Claude Pro/Max・ChatGPT Plus/Pro・GitHub Copilot のサブスクを任意のコーディングエージェントで使う。エラーが出るときは よくあるエラーの直し方：401・429・502・504 など、または Discord で質問してください。
