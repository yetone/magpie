ドキュメント · ガイド

Prime Agent を任意のモデルで

Prime Agent は Prime Intellect が公開している Rust 製のコーディングエージェントで、コマンドは prime-agent です。自分のフォルダーに Pi と同じ settings.json と models.json を持ち、Pi と同じフィールドと型で読みます。magpie は Pi と同じように設定するので、Prime Agent が DeepSeek、GLM、Kimi、Qwen、Claude、ChatGPT サブスクリプションなど magpie の任意のモデルで動きます。

Prime Agent の設定

  1. magpie にプロバイダーを追加プロバイダー ページで API キーを追加するか、サブスクリプションにサインインします。
  2. エージェント ページで Prime Agent のモデルを選ぶvia magpie のモデルを選びます。
  3. prime-agent を実行新しいセッションはそのモデルで始まり、magpie のモデルがすべて一覧に並びます。
ターミナル
magpie prime-agent deepseek/deepseek-v4-pro

書き込まれる内容

ターミナル
~/.prime/agent/            （または $PRIME_AGENT_CODING_AGENT_DIR）
  settings.json            defaultProvider: "magpie"
                           defaultModel:    "deepseek/deepseek-v4-pro"
                           defaultThinkingLevel
  models.json              providers.magpie: ゲートウェイの /v1、
                           キー magpie-prime-agent、magpie のモデル

magpie は models.json に magpie というプロバイダーを加え、ゲートウェイの /v1 と magpie のモデルを書きます。settings.json には defaultProvider、defaultModel、defaultThinkingLevel を設定します。あなた自身のプロバイダーと設定はそのままです。

Prime Agent のリクエストには User-Agent がないので、magpie が渡すキーは magpie-prime-agent という名前で、ゲートウェイはこれで Prime Agent の使用量として数えます。

PRIME_AGENT_CODING_AGENT_DIR

Prime Agent のフォルダーは ~/.prime/agent で、PRIME_AGENT_CODING_AGENT_DIR が設定されていればそちらです（~ はホーム）。相対パスは Prime Agent の作業フォルダー次第で magpie には分からないため採用せず、~/.prime/agent に書きます。WSL の Prime Agent も設定できます。

あなたに任される設定

Pi と同じく、書くのはグローバルの settings.json だけです。次のものはあなたのもので、magpie は変えません：

  1. プロジェクトの .prime/agent/settings.jsonそのプロジェクトの設定です。
  2. allowedModelsデーモンの許可リストで、外れたモデルははっきりエラーになります。
  3. subagentDefaultModelサブエージェントが始まるモデルです。

allowedModels を使っているなら、magpie のモデルを加えてください。

元に戻す

Prime Agent の行で自分のモデルを選ぶか、下のコマンドを実行します。magpie は最初に書く前に二つのファイルを控えています。その後変更がなければバイト単位で元に戻し、変更があれば magpie のプロバイダーだけを消します。

ターミナル
magpie prime-agent default

よくある質問

Prime Agent で DeepSeek や GLM を使えますか？

使えます。magpie のエージェントページで Prime Agent に via magpie のモデルを選ぶと、models.json に magpie のプロバイダーが加わり、DeepSeek、GLM、Kimi、Qwen、Claude が使えます。

magpie はどのフォルダーに書きますか？

~/.prime/agent、または設定されていれば PRIME_AGENT_CODING_AGENT_DIR（~ は展開）。相対パスは採用しません。

magpie のモデルが許可されていないとエラーになります。

allowedModels にそのモデルがありません。magpie はこのリストを変えないので、モデルを加えてください。

magpie はどうやって Prime Agent のリクエストを見分けますか？

magpie が渡す専用キー magpie-prime-agent で見分けます。リクエストに User-Agent がないためです。

同じモデルを他のエージェントでも：Pi を任意のモデルで、Kimi Code を任意のモデルで、DS Bot を任意のモデルで、Muse Code を任意のモデルで。エラーが出るときは よくあるエラーの直し方、または Discord で質問してください。
