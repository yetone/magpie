Qwen を Claude Code・Codex・Gemini CLI・OpenCode で使う

Alibaba は Qwen を DashScope で提供しています。Alibaba Cloud Model Studio、百炼、Qwen Cloud があり、従量課金と Token Plan があります。どれも OpenAI Chat Completions と Anthropic Messages を話します。キーを magpie に一度追加すれば、Claude Code・Codex・Gemini CLI・OpenCode などつないだすべてのツールが、magpie のゲートウェイ 127.0.0.1:3425 経由で Qwen を使えます。

Qwen を追加する

  1. キーを取得従量課金は Model Studio（国際版）か 百炼（中国）で作ります。Token Plan のキーはそれぞれのプランのページで作ります。
  2. プロバイダを追加magpie の プロバイダ で ＋ プロバイダを追加 を押し、キーを作ったサイトの Qwen プリセット（下の表）を選んでキーを貼り付け、保存します。magpie がエンドポイントに提供モデルを問い合わせます。
  3. ツールで選ぶエージェント タブで、ツールの行の qwen3.8-max などの Qwen モデルを選びます。
ターミナル
magpie provider add qwen sk-…                     # Model Studio（国際版）
magpie provider add qwen-cn sk-…                  # 百炼（中国）
magpie provider add qwen-token-plan sk-sp-…       # Qwen Token Plan
magpie provider add qwencloud sk-ws-… region=us-east-1
キーは自分のホストでしか使えません。Token Plan のキー（sk-sp-…）は従量課金のエンドポイントでも他の Token Plan でも断られ、Qwen Cloud のキーは自分のリージョンの外では断られます。401 が返ったら、キーを作ったサイトのプリセットに入れたか確かめてください。

ツールごとの使い方

エージェント タブで各ツールの行のモデルをクリックして選ぶか、ターミナルで選びます。各ガイドに、magpie がそのツールの設定に何を書くか、どう元に戻すかがあります。

ターミナル
magpie claude qwen/qwen3.8-max
magpie codex qwen/qwen3.8-max
magpie gemini model qwen/qwen3.7-plus
magpie opencode qwen/qwen3.8-max
  • Claude Code は Anthropic Messages を話し、Qwen の Anthropic エンドポイントも同じなので、リクエストはそのまま渡されます。opus・sonnet・haiku の各ティアは、個別に指定しない限り選んだモデルで動きます。Claude Code で他のモデル。
  • Codex が話すのは OpenAI Responses だけです。DashScope は Chat Completions と Anthropic Messages を提供し、Responses は提供していないので、magpie がリクエストと返答を変換します。ストリーミングとツール呼び出しもそのままです。モデルは推論レベル付きで Codex の /model に並びます。Codex で他のモデル。
  • Gemini CLI は Gemini の API を話します。magpie がゲートウェイに向けて変換します。Gemini CLI で他のモデル。
  • OpenCode には、magpie が opencode.json にモデルを推論バリアントと価格つきで書きます。OpenCode で他のモデル。

Qwen Code も magpie がつなぐエージェントの一つで、その行では Qwen のモデルも他社のモデルも選べます。

思考と画像

  • ストリーミングしない返答。思考する Qwen モデルは DashScope ではストリーミングでしか返答せず、返答をまとめて求めるリクエストは断られます。ツールやルーティンググループの分類器がまとめた返答を求めたとき、magpie は DashScope にストリーミングで求め、思考を含めた返答全体をツールに渡します。
  • 常に思考するモデル。DashScope の glm-5.3 のように、思考をオフにできないモデルがあります。ツールがオフを求めてモデルが断ったとき、magpie は思考をオンのまま聞き直します。
  • 画像。Qwen-Image と wan2.7-image モデルは DashScope 自身の画像 API で描きます。6 つのプリセットのどれでも使えます。magpie の 設定 → モデル → 画像 で選びます。サイズは 幅x高さ で、最大 2048×2048 です。

残高と使用量

magpie は Qwen の残高やプランのカードを表示しません。DashScope にはキーの残高を読む API がなく、どちらの Token Plan にもクレジットを読む API がないためです（クレジットは Alibaba のコンソールのサブスクリプションページにあります）。使用量 タブは、magpie を通った各ツールとモデルのトークン、キャッシュヒット、費用を数えます。

よくある質問

Claude Code で Qwen を使うには？

magpie にキーを追加し（プロバイダ → プロバイダを追加 → キーを作ったサイトの Qwen プリセット）、Claude Code の行で qwen3.8-max などの Qwen モデルを選ぶか、magpie claude qwen/qwen3.8-max を実行します。magpie が Claude Code の settings.json を書き、リクエストを DashScope の Anthropic エンドポイントに渡します。

Codex で Qwen（Qwen3 Coder も）を使えますか？

使えます。magpie は DashScope がそのキーに出すモデルを Coder モデルも含めて一覧にし、Codex はどれでも使えます。Codex の Responses リクエストを magpie が Chat Completions に変換し、返答も戻します。Codex の行で選ぶか magpie codex qwen/qwen3.8-max を実行すると、Codex の /model に並びます。

キーはどのプリセットに入れればいいですか？

キーを作ったサイトのプリセットです。Token Plan のキー（sk-sp-…）はそのプランのホストでしか使えず、Qwen Cloud の従量課金キー（sk-ws-…）は自分のリージョンでしか使えないので、別のプリセットに入れると 401 で断られます。

Qwen Code で他のモデルを使えますか？

使えます。Qwen Code は magpie がつなぐエージェントの一つなので、エージェント タブのその行で、追加したどのモデルでも選べます。

Token Plan の残りクレジットは表示されますか？

されません。どちらの Token Plan にもクレジットを読む API がなく、Alibaba のコンソールのサブスクリプションページに表示されます。magpie の使用量タブは、各ツールが使ったトークンを数えます。

ツールごとのガイド：Claude Code で他のモデル、Codex で他のモデル、Gemini CLI で他のモデル、OpenCode で他のモデル、Qwen Code を任意のモデルで。困ったときは Discord で質問してください。
