ドキュメント · ガイド

Snow CLI を任意のモデルで

Snow CLI（snow、npm パッケージ snow-ai）は API の設定をプロファイルとして保存します。magpie は Snow を magpie のゲートウェイに向ける専用のプロファイルを追加するので、Snow は magpie にある任意のモデルで動きます：DeepSeek、GLM、Qwen、OpenAI や Anthropic のキー、ChatGPT や Copilot のサブスクリプション。

Snow の設定は ~/.snow（または $SNOW_CONFIG_DIR）にあります。各プロファイルは profiles/ のファイルで、active-profile.json が使用中のものを示し、config.json はその写しです。magpie は profiles/magpie.json を書きます：使っていたプロファイルの写しに、magpie のゲートウェイをベース URL、Snow の名前入りのキー、Chat Completions のプロトコル、選んだモデルを入れたものです。それを使用中のプロファイルにして config.json に写します。Snow 自身のプロファイル切り替えと同じ手順です。ゲートウェイは各リクエストをモデルのプロバイダに送ります。

Snow をつなぐ

  1. magpie にプロバイダを追加プロバイダ タブで API キーを追加するか、サブスクリプションにサインインします。
  2. Snow CLI の行でモデルを選ぶエージェント タブで magpie の下のモデルを選びます。
  3. 開いている snow セッションを再起動Snow はプロファイルを起動時に読みます。
ターミナル
magpie snow deepseek/deepseek-v4-pro    # Snow を DeepSeek で
magpie snow default                     # 自分のプロファイルに戻す

Windows の WSL ディストリビューションの Snow でも同じです：そこでのプロファイルには、ディストリビューションから届くゲートウェイのアドレスが入ります。

自分のプロファイル

自分のプロファイルは変更されません。magpie のプロファイルは使っていたものからほかの設定を写しますが、サブスクリプションのサインイン（snowcfg.oauth）は含めません。自分のプロファイルがたまたま magpie という名前なら、退避されて後で戻ります。行には自分の各プロファイルのモデルも並び、それを選ぶと Snow はそのプロファイルに切り替わります。

ウィンドウと画像

magpie は選んだモデルについてカタログから maxContextTokens、maxTokens、supportsVision を設定するので、Snow は実際のウィンドウと画像を扱えるかを知ります。上限がわからないモデルには Snow 自身の既定値 200K と 64K が使われます。Snow の設定で変えた値は、変えたとおりに残ります。自分のビジョンモデルは、専用のエンドポイントとキーがある場合だけ残ります。画像を見られないモデルへの画像は、magpie の Vision がゲートウェイで説明文にします。

軽量モデル

Snow は要約、圧縮、ファイル検索に軽量モデル（basicModel）を使います。magpie のプロファイルではメインモデルに従いますが、行の small 欄で別の magpie モデルを選べます。その選択はメインモデルを変えても残ります。

思考

行の thinking 欄は magpie のプロファイルの chatThinking を設定します：レベルを選ぶと各リクエストに reasoning_effort が付き、オフは Snow の既定です。推論レベルを持つモデルだけに表示されます。

Snow App

Snow App は独自の API 設定を持ちます。Sync Snow CLI API config ボタンで Snow CLI のプロファイルが magpie のものも含めて写されるので、アプリでも magpie のモデルが使えます。

元に戻す

行で自分のモデルを選ぶか、magpie snow default を実行するか、行を magpie から外します。Snow は使っていたプロファイルに戻り、profiles/magpie.json は削除され、config.json は再び自分のプロファイルの写しになります。

よくある質問

Snow CLI で DeepSeek、GLM、Qwen は使えますか？

使えます。magpie にあるすべてのモデルを Snow のモデルにできます：DeepSeek、GLM、Qwen、GPT、Claude など。

magpie は自分の Snow プロファイルを変えますか？

変えません。専用のプロファイル profiles/magpie.json を追加し、使用中にします。元に戻すと自分のプロファイルが再び使用中になります。

Snow のコンテキストサイズの表示が違うのはなぜ？

magpie は選んだモデルについてカタログから maxContextTokens と maxTokens を設定します。Snow で自分で変えた値はそのまま残ります。

Snow と magpie の間のプロトコルは？

Chat Completions（requestMethod は chat）です。magpie のプロファイルが別のプロトコルになっていると、行に警告が出ます。

同じモデルで使えるほかのエージェント：Gemini CLI で他のモデル、Cursor Private Inference を任意のモデルで、Antigravity を任意のモデルで。うまくいかないときは よくあるエラーの対処 を見るか、Discord で質問してください。
