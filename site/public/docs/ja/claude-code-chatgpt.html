Claude Code で ChatGPT

仕組み ChatGPT にサインイン GPT モデルを選ぶ Opus・Sonnet・Haiku 推論レベル 上限と使用量 複数のアカウント 元に戻す 逆の使い方 よくある質問

ドキュメント · ガイド

ChatGPT Plus/Pro のサブスクを Claude Code で使う

Claude Code は ChatGPT Plus・Pro プランの GPT モデルで動かせます。magpie で ChatGPT にサインインし、Claude Code に codex/… のモデルを選べば、あとはいつもどおり使えます。OpenAI の API キーは要りません。

Claude Code は Anthropic の Messages API で話します。magpie はお使いのコンピュータ上でゲートウェイ（127.0.0.1:3425）を動かし、Claude Code のリクエストを GPT モデル向けに、返答を Claude Code 向けに変換します。ストリーミングとツール呼び出しも含みます。magpie はゲートウェイのアドレスとキーを Claude Code の settings.json に書き込み、ChatGPT のサインインは magpie の中だけに置かれます。

ChatGPT にサインイン

  1. プロバイダの追加を開くmagpie の プロバイダ タブで ＋ プロバイダを追加 を押します。
  2. ChatGPT のタイルをクリックブラウザで OpenAI 自身のサインインページが開きます。終わるとすぐにアカウントが表示されます。

ターミナルからでも追加できます。

ターミナル
magpie accounts add codex      # ChatGPT アカウントにサインイン

このアカウントのモデルは codex/… です。

Claude Code に GPT モデルを選ぶ

エージェント タブで Claude Code の行のモデルをクリックし、codex/… のモデルを選びます。ターミナルからは：

ターミナル
magpie models                  # すべてのモデルを provider/model で表示
magpie claude codex/gpt-5.5

Claude Code の中でも、/model に magpie のモデルが “via magpie” 付きで並ぶので、そこで切り替えられます。

一部のセッションだけ GPT にしたいとき。magpie で Claude Code を接続せず、必要なときに claude-magpie を実行します。同じ claude をそのセッションだけ magpie の設定で起動し、settings.json は書き換えません。

Opus・Sonnet・Haiku の対応

Claude Code はティアでモデルを求めます：opus、sonnet、haiku、fable。セッションのタイトルや Explore サブエージェントなどの小さな仕事は haiku ティアに行きます。メインモデルが GPT モデルのときは：

ティアenv の変数既定
opusANTHROPIC_DEFAULT_OPUS_MODEL選んだ GPT モデル
sonnetANTHROPIC_DEFAULT_SONNET_MODEL選んだ GPT モデル
haikuANTHROPIC_DEFAULT_HAIKU_MODEL、ANTHROPIC_SMALL_FAST_MODEL選んだ GPT モデル
fableANTHROPIC_DEFAULT_FABLE_MODEL設定しない

ティアに別のモデルを使うには（haiku を小さいモデルにするなど）、magpie の Claude Code の行で設定するか、ターミナルから：

ターミナル
magpie claude haiku codex/…    # 1 つのティアだけ別のモデルに
magpie claude haiku ""         # メインモデルに戻す

推論レベル

Claude Code が thinking を有効にしたリクエストでは、Claude Code が求める推論レベルがそのまま GPT モデルの推論レベルになります。magpie は各モデルが持つ推論レベルも Claude Code に伝えます。

Claude Code の求めに関わらず固定したいときは、Claude Code の行で 推論レベル を設定します。opus の推論レベル などはティアごと、サブエージェントの推論レベル はサブエージェントの設定です。どれも既定は Claude Code が要求する推論レベル です。開いている Claude Code セッションは起動時の推論レベルのままなので、反映するには再起動してください。

上限と使用量

リクエストはあなたの ChatGPT アカウントで処理されるので、Codex 自身のリクエストと同じくプランの使用量上限に数えられます。

  • 使用量を見る。Claude Code の行の ステータスライン をオンにすると、Claude Code の入力欄の下に、magpie が使うアカウントの 5 時間と 7 日の使用量を表示します。magpie accounts は各アカウントの使用済みの割合を表示します。履歴は 使用量 タブにあります。
  • アカウントを使い切ったとき。magpie はそのアカウントを、OpenAI の拒否が示すリセット時刻まで、示されなければ枠全体が更新されるまで、それも分からなければ 5 時間休ませ、その間のリクエストを次のアカウントかプロバイダの フォールバック に送ります。枠が更新されるとアカウントは自動で戻ります。

複数のアカウントとフェイルオーバー

  • アカウントを増やす。ChatGPT のタイルをもう一度クリックするか、magpie accounts add codex をもう一度実行します。各アカウントはプロバイダの下に並びます。
  • リクエストを分散する。プロバイダの行を開き、使うアカウントにチェックを入れます。既定の スマート ルーティングは、クォータに余裕があり、最も早く更新されるアカウントに送ります。
  • 別のモデルに切り替える。プロバイダの フォールバック には、すべてのアカウントが切れたり、レート制限やエラーになったときに使うモデルを並べます。別のサブスクや API キーのモデルも選べます。

ルーティングの種類は はじめに にあります。

元に戻す

Claude Code の行で Claude Code 自身のモデルを選ぶか、次を実行します。

ターミナル
magpie claude default

magpie による接続を外し、元の設定に戻します。Claude Code の行の 切断 も同じです。

claude.ai のサインイン。magpie のモデルを使うとき、Claude Code の サインイン の既定は magpie のキー です。claude.ai からはサインアウトされ、/usage のプラン上限、コネクタ、音声、/teleport は使えません。残したいときは claude.ai にします。

逆の使い方：Codex で Claude

Claude Pro や Max のサブスクも同じように Codex で使えます。magpie で Claude にサインインし、Codex に claude/… のモデルを選びます。Claude サブスクのリクエストはコンピュータにインストールされた Claude Code を通るので、アンインストールしないでください。

ターミナル
magpie accounts add claude
magpie codex claude/claude-opus-5-5

Codex で他のモデルとサブスクを任意のエージェントでも参照してください。

よくある質問

ChatGPT Plus や Pro のサブスクを Claude Code で使えますか？

使えます。magpie で ChatGPT にサインインし、Claude Code の行で codex/… のモデルを選ぶか、magpie claude codex/gpt-5.5 を実行します。magpie が Claude Code のリクエストを GPT モデル向けに、返答を元の形に変換します。ツール呼び出しも含みます。

OpenAI の API キーは必要ですか？

不要です。magpie は OpenAI 自身のページでサインインし、Claude Code にはゲートウェイのキーが渡されます。サインインは magpie の中だけに置かれます。

ChatGPT プランの上限は消費されますか？

はい。リクエストはあなたの ChatGPT アカウントで処理され、その使用量上限に数えられます。magpie のステータスラインは、Claude Code の入力欄の下に各アカウントの 5 時間と 7 日の使用量を表示します。

Claude Code の Haiku のリクエストはどのモデルを使いますか？

選んだ GPT モデルです。magpie claude haiku <model> で haiku ティアに別のモデルを設定することもできます。

Claude 自身のモデルに戻すには？

magpie claude default を実行するか、magpie の Claude Code の行で Claude Code 自身のモデルを選びます。

リクエストは magpie のサーバーを通りますか？

通りません。ゲートウェイはお使いのコンピュータ上で動き、リクエストはそこから OpenAI に直接送られます。間に magpie のサーバーはありません。

API キーを使う場合は Claude Code で他のモデルを参照してください。エラーが出るときは よくあるエラーの直し方、または Discord で質問してください。
