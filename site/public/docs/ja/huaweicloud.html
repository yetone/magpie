ドキュメント · プロバイダー

Huawei Cloud MaaS Token Plan を Claude Code と Codex で

Huawei Cloud ModelArts MaaS の Token Plan は個人アカウント向けで西南-貴陽一リージョンにあり、GLM、Kimi、DeepSeek を Chat Completions と Anthropic Messages で提供します。magpie に Huawei Cloud を追加してプランを選べば、Claude Code、Codex、Gemini CLI、OpenCode が 127.0.0.1:3425 のローカルゲートウェイ経由で使えます。

Huawei Cloud を追加

  1. プロバイダーを追加してプランを選ぶプロバイダー で ＋ プロバイダーを追加 を押し、Huawei Cloud MaaS を選び、キーのプランを Token PlanかPay as you go から選んで保存します。
  2. ツールで選ぶエージェント でツールの行に glm-5.3 などを選びます。
ターミナル
magpie claude huaweicloud/glm-5.3
magpie codex huaweicloud/deepseek-v4.1-flash
magpie opencode huaweicloud/kimi-k2.6

プランとエンドポイント

プランChat CompletionsAnthropic Messages
Token Planhttps://api.modelarts-maas.com/plan/v2https://api.modelarts-maas.com/plan/anthropic
従量課金https://api.modelarts-maas.com/openai/v1https://api.modelarts-maas.com/anthropic

Token Plan の枠は /plan 以下のエンドポイントでのみ消費されるため、magpie は既定でプランのエンドポイントを使います。従量課金は別請求です。どちらも ModelArts コンソールの認証管理で作る MaaS API キーを使います。プロバイダー内の各キーが自分のプランを持ちます。どちらも Responses はありません。

モデル

一覧を取得するまで、magpie はプランのモデルを示します：glm-5.3、glm-5.1、kimi-k2.6、deepseek-v4.1-flash、deepseek-v4-flash。Huawei の OpenClaw ページと同じく小文字です。一覧を取得した後は Huawei の一覧が使われます。

各エージェントで

  • Claude Code は Anthropic Messages を話し、プランにあるのでそのまま送られます。Claude Code で他のモデル。
  • Codex は OpenAI Responses だけを話しますが Huawei Cloud にはないため、magpie が Chat Completions に変換します。apply_patch などのカスタムツールは関数として渡り、Codex が実行できる形で戻ります。Codex で他のモデル。
  • Gemini CLI は Gemini の API を話し、magpie がローカルゲートウェイで変換します。Gemini CLI で他のモデル。
  • OpenCode：magpie がモデルを opencode.json に書きます。OpenCode で他のモデル。

よくある質問

Huawei Cloud Token Plan を Claude Code で使うには？

magpie に Huawei Cloud MaaS を追加してキーのプランを Token Plan にし、Claude Code の行で glm-5.3 を選ぶか、magpie claude huaweicloud/glm-5.3 を実行します。リクエストは https://api.modelarts-maas.com/plan/anthropic に送られます。

Huawei Cloud MaaS は Codex で使えますか？

使えます。Responses エンドポイントがないため、magpie が Codex のリクエストを Chat Completions に変換します。magpie codex huaweicloud/deepseek-v4.1-flash を実行してください。

なぜ /plan 以下のエンドポイントなのですか？

Token Plan の枠は /plan/v2 と /plan/anthropic でのみ消費され、/openai/v1 など従量課金のエンドポイントは別請求です。magpie は既定でプランのものを使います。

Huawei Cloud Token Plan のモデルは？

一覧を取得するまで glm-5.3、glm-5.1、kimi-k2.6、deepseek-v4.1-flash、deepseek-v4-flash を示し、取得後は Huawei の一覧を使います。

ほかのプロバイダーも同じ方法で：Tencent Cloud、Baidu Qianfan、Volcengine Ark、GLM Coding Plan、Kimi、DeepSeek、Qwen。エラーは トラブルシューティング へ、または Discord で質問してください。
