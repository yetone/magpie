ドキュメント · ガイド

OpenCode で DeepSeek・Kimi・GLM や Claude・ChatGPT のサブスクを使う方法

OpenCode は設定ファイルのプロバイダ（provider）を通じてモデルを呼び出します。magpie は magpie という名前のプロバイダを 1 つ追加し、あなたのマシン上のゲートウェイへつなぎます。magpie にあるモデルはすべてその下に並びます。DeepSeek・Kimi・GLM・Qwen のキーも、Claude・ChatGPT・Copilot のサブスクのモデルも同じです。

ゲートウェイは 127.0.0.1:3425 で動きます。OpenCode は OpenAI Chat Completions でリクエストを送り、magpie がそれを各プロバイダの API で送り直します。API が違えばリクエストと応答を変換し、ストリーミングもツール呼び出しもそのままです。OpenCode 自身のプロバイダはそのまま残り、magpie のものと並びます。

中国のモデル

DeepSeek、Kimi と Kimi Code、Zhipu GLM（従量課金または Coding Plan）、Z.ai、MiniMax、Qwen。

サブスクリプション

Claude Pro/Max、ChatGPT Plus/Pro、GitHub Copilot。magpie で一度サインインするだけです。

その他

任意の OpenAI・Anthropic 互換の URL とキー、Ollama、LM Studio。

セットアップ

  1. プロバイダを追加するmagpie の プロバイダ タブで ＋ プロバイダを追加 を押し、DeepSeek・Kimi・Zhipu GLM・MiniMax・Qwen のいずれかを選んで API キーを貼り付け、保存します。magpie がベンダーに提供モデルを問い合わせます。
  2. OpenCode のモデルを選ぶエージェント タブで OpenCode の行のモデルをクリックし、deepseek/deepseek-v4-pro などを選びます。magpie が OpenCode の設定に "model": "magpie/deepseek/deepseek-v4-pro" を書き込み、magpie プロバイダも追加します。
  3. OpenCode の中で選んでもよいプロバイダが入れば、magpie のモデルは OpenCode 自身の /models 一覧の magpie の下に並ぶので、そこで切り替えられます。

ターミナルからも同じことができます。

ターミナル
magpie provider add deepseek sk-…
magpie models                                    # すべてのモデル（プロバイダ/モデル）
magpie opencode deepseek/deepseek-v4-pro         # OpenCode のモデル
magpie opencode small deepseek/deepseek-v4-flash # small_model

OpenCode の small_model は行の中で別に選べるので、メインより安いモデルを割り当てられます。

Zhipu GLM Coding Plan。Zhipu GLM や Z.ai を追加するときは、キーに合ったプランを選んでください。Coding Plan のキーには専用のエンドポイントがあり、従量課金のエンドポイントに送ると残高不足と返されます。

サブスクリプション

magpie で一度サインインすれば（＋ プロバイダを追加 またはターミナルから）、サブスクのモデルもほかのモデルと同じく OpenCode の magpie の下に並びます。API キーは要りません。

サブスクモデル名ターミナル
Claude（Pro、Max、Team）claude/…magpie accounts add claude
magpie opencode claude/claude-opus-5-5
ChatGPT（Plus、Pro、Business）codex/…magpie accounts add codex
magpie opencode codex/gpt-5.5
GitHub Copilotcopilot/…magpie accounts add copilot

Claude のサブスクへのリクエストは、マシンにインストールされた Claude Code を通して送られるので、Claude Code は残しておいてください。Copilot はサインイン時にコードが表示されるので、GitHub のページで入力します。同じサブスクの複数アカウントで負荷を分け、切り替えることもできます。サブスクを任意のエージェントで を参照してください。

opencode.json の変更点

magpie が書き込むのは、OpenCode が設定フォルダから読む設定ファイルです。フォルダは $OPENCODE_CONFIG_DIR（設定されていれば）、なければ ~/.config/opencode。ファイルは opencode.jsonc・opencode.json・config.json のうち最初に見つかったもので、どれもなければ opencode.json を新しく作ります。変えるのは次のキーだけで、ほかの設定はそのままです。

キー値
modelmagpie/<プロバイダ>/<モデル>
small_model同じ形式（設定したときだけ）
provider.magpie.npm@ai-sdk/openai-compatible
provider.magpie.options.baseURLhttp://127.0.0.1:3425/v1
provider.magpie.options.apiKeyゲートウェイのキー
provider.magpie.modelsmagpie が OpenCode に見せるすべてのモデル

各モデルにはコンテキストウィンドウと出力の上限（OpenCode が圧縮のタイミングを判断するのに使います）、画像を受け付けるかどうか、推論レベル、料金が入ります。プロバイダやアカウントを追加すると、magpie がこの一覧を更新します。ファイルの providers（OpenCode 2 の書き方）にもこのプロバイダがあれば、そちらにも書き込みます。Windows の WSL ディストリビューション内の OpenCode も同じように設定され、そのディストリビューションの ~/.config/opencode に書き込みます。

推論レベルと料金

  • 推論レベル。モデルの推論の強さは、OpenCode ではそのモデルのバリアント（variant）として書き込まれ、それぞれが対応する reasoningEffort を指定します。ChatGPT のサブスクの GPT モデルのように高速処理に対応するモデルには、各レベルに fast のバリアントも付きます。
  • 料金。magpie は各モデルの 100 万トークンあたりの価格（入力・出力・キャッシュ読み取り・キャッシュ書き込み）を書き込むので、OpenCode のセッション料金が計算されます。書かれていないとどのモデルも 0 になります。
  • プロンプトキャッシュ。magpie は自分のプロバイダで OpenCode の prompt cache key を有効にするので、このキーでキャッシュするプロバイダではターンをまたいでキャッシュが効きます。

モデル一覧を絞る

既定では、OpenCode には magpie のすべてのモデルが見えます。一部のプロバイダやグループだけにするには：

ターミナル
magpie visible opencode deepseek,claude   # このプロバイダだけ
magpie visible opencode all               # すべてに戻す

一覧から外したモデルも、OpenCode が名前で指定すれば応答します。

元に戻す

magpie の OpenCode の行のモデル選択には、OpenCode 自身のプロバイダ（auth.json でサインイン済みのもの）も並びます。その中から選ぶか、次を実行します。

ターミナル
magpie opencode default

magpie を使う前の model と small_model が戻り、magpie プロバイダがファイルから取り除かれます。

プロバイダ別：DeepSeek · Kimi と Kimi Code · GLM Coding Plan · Qwen · MiniMax · Gemini · Grok · Mistral · OpenRouter · GitHub Copilot · Ollama

よくある質問

OpenCode で DeepSeek を使うには？

magpie に API キーで DeepSeek を追加し、エージェントタブで OpenCode の行に DeepSeek のモデルを選ぶか、magpie opencode deepseek/deepseek-v4-pro を実行します。magpie が opencode.json に magpie プロバイダを追加し、モデルを設定します。

OpenCode で Kimi や GLM は使えますか？

使えます。magpie に Kimi か Zhipu GLM を追加し、OpenCode のモデルに選ぶだけです。GLM Coding Plan のキーには専用のエンドポイントがあるので、追加するときに Coding Plan を選んでください。

OpenCode で Claude Pro/Max のサブスクは使えますか？

使えます。magpie で Claude にサインインし（magpie accounts add claude）、OpenCode に claude/… のモデルを選びます。Claude のサブスクへのリクエストはマシンにインストールされた Claude Code を通して送られるので、残しておいてください。

OpenCode で ChatGPT Plus/Pro のサブスクは使えますか？

使えます。magpie で ChatGPT にサインインし（magpie accounts add codex）、codex/gpt-5.5 などの codex/… のモデルを選びます。推論レベルは OpenCode ではモデルのバリアントとして表示されます。

magpie はどのファイルを変更しますか？

~/.config/opencode（または $OPENCODE_CONFIG_DIR）にある OpenCode の設定です。opencode.jsonc・opencode.json・config.json のうち最初に見つかったもの、なければ新しい opencode.json。model と small_model を設定し、provider.magpie を追加します。ほかの設定はそのままです。

OpenCode 自身のモデルに戻すには？

magpie の OpenCode の行で OpenCode 自身のモデルを選ぶか、magpie opencode default を実行します。以前の model と small_model が戻り、magpie のプロバイダは取り除かれます。

ほかのエージェント：Claude Code でほかのモデルを使う、Codex でほかのモデルを使う、Gemini CLI でほかのモデルを使う。困ったときは Discord で質問してください。
