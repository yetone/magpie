Craft Agents

ドキュメント · ガイド

Craft Agents を任意のモデルで

Craft Agents（lukilabs/craft-agents-oss）は Claude と Pi のセッションを動かす Electron アプリです。モデルは「接続」から来て、カスタムエンドポイントも接続の一つです。magpie は magpie という接続を加え、新しいセッションの既定にします。そのため Craft Agents で magpie のすべてのモデル（DeepSeek、GLM、Kimi、Qwen、OpenAI や Anthropic のキー、ChatGPT や Copilot のサブスクリプション）が使えます。

Craft Agents の設定

  1. Craft Agents を一度開くCraft Agents はワークスペースのない config.json を読み込まないので、magpie はこのファイルを作りません。Craft Agents を一度起動すると作られます。
  2. magpie にプロバイダーを追加プロバイダー ページで API キーを追加するか、サブスクリプションにサインインします。
  3. Craft Agents の行でモデルを選ぶエージェント ページで Craft Agents に magpie のモデルを選びます。Craft Agents は config.json を監視するので、起動中のアプリも次の新しいセッションから使います。
ターミナル
magpie craft-agents deepseek/deepseek-v4-pro

magpie 接続

接続は Craft Agents の設定フォルダーの config.json（CRAFT_CONFIG_DIR があればそこ、なければ ~/.craft-agent）にあります。magpie の接続は OpenAI 互換の Chat Completions を使う pi_compat 接続で、models は magpie で Craft Agents 用に選んだモデル、defaultModel は選んだモデルです。

ターミナル
"llmConnections": [
  …,
  {"slug": "magpie", "name": "magpie", "providerType": "pi_compat",
   "authType": "none",
   "baseUrl": "http://127.0.0.1:3425/agent/craft-agents/v1",
   "customEndpoint": {"api": "openai-completions"},
   "models": [{"id": "deepseek/deepseek-v4-pro", "name": …}, …],
   "defaultModel": "deepseek/deepseek-v4-pro"}
],
"defaultLlmConnection": "magpie"

Craft Agents は models にない defaultModel をリストの最初のモデルに戻すので、magpie は選んだモデルを必ずリストに入れます。Craft Agents でこの接続に付けた名前などのフィールドは、magpie の同期でも保たれます。

キーは不要

Craft Agents のキーは config.json とは別に credentials.enc に暗号化して保存され、magpie はそれを開きません。magpie の接続は authType: none で、これは Craft Agents 自身がこのコンピューター上のキーなしのエンドポイント（「Local Model」）に保存する形です。Pi サーバーはプレースホルダーのキーを送り、ゲートウェイはこのコンピューターからのリクエストとして受け付けます。Craft Agents は独自の User-Agent を送らないので、アドレスの /agent/craft-agents でどのエージェントかを伝えます。

新しいセッションと開いているセッション

新しいセッションは defaultLlmConnection が指す接続で始まり、ワークスペースに独自の既定があればそちらが優先です。開いているセッションは始めたときの接続のままなので、magpie に切り替えたら新しいセッションを始めてください。Craft Agents の起動中は magpie もそう知らせます。

自分の接続

自分の接続と config.json のほかのキーはそのままです。magpie は既定を引き継ぐ前に元の既定を記録し、外すときに戻します（その接続が残っていれば。なければ Craft Agents が最初の接続を選びます）。Craft Agents で magpie 接続を消すと、magpie のチェックがもう magpie を通らないと知らせます。

元に戻す

magpie で行を既定に戻すと、magpie は自分の接続を外し、元の既定を戻します。自分の接続のモデルを選ぶと、magpie はそれをその接続の既定モデルにします。

ターミナル
magpie craft-agents default

よくある質問

Craft Agents で DeepSeek、GLM、Kimi、Qwen は使えますか？

使えます。magpie が Craft Agents の config.json に magpie 接続を加え、新しいセッションの既定にします。magpie で選んだモデルはすべてその接続にあります。

Craft Agents に API キーを入れますか？

いいえ。magpie の接続は authType none で、Craft Agents がこのコンピューター上のキーなしエンドポイントに保存する形と同じです。

切り替えたのに前のモデルのままです。

セッションは始めたときの接続を使い続けます。新しいセッションを始めてください。ワークスペースに独自の既定接続があればそちらが優先です。

magpie が先に Craft Agents を開くよう言います。

Craft Agents はワークスペースのない config.json を読み込まないので、magpie はファイルを作りません。Craft Agents を一度起動してから設定してください。

同じモデルを他のエージェントでも：Claude Code で他のモデル、T3 Code を任意のモデルで、CodeBuddy を任意のモデルで。エラーが出るときは よくあるエラーの直し方、または Discord で質問してください。
