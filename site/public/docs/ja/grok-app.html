Grok App を任意のモデルで

Grok App（RongleCat/grok-app）は grok CLI のデスクトップフロントエンドで、ACP で CLI を起動します。アプリ自身のモデル一覧は Grok Build の公式カタログだけで、自分で選ぶモデルは設定の「プロバイダーチャネル」として加えます。magpie が magpie というカスタムプロバイダーとして加わると、Grok App のモデルピッカーで DeepSeek、GLM、Kimi、Qwen、Claude、ChatGPT サブスクリプションなど magpie の任意のモデルを選べます。

Grok App の設定

  1. magpie にプロバイダーを追加プロバイダー ページで API キーを追加するか、サブスクリプションにサインインします。
  2. エージェント ページで Grok App のモデルを選ぶvia magpie のモデルを選ぶと、magpie がカスタムプロバイダーを書きます。
  3. Grok App で Use を押すGrok App の設定 › Account で magpie の Use を押すと、アプリが magpie に切り替わります。
ターミナル
magpie grok-app deepseek/deepseek-v4-pro

magpie のカスタムプロバイダー

magpie は、アプリ自身がチャネルを書くのと同じ形で、データフォルダーの agent-home/config.toml に [model.magpie] を書きます。base_url はゲートウェイの /v1、api_key は magpie が Grok App 用に出すキー、API は chat completions です。app_models は magpie のモデルの JSON 一覧で、それぞれにコンテキスト長、画像対応、思考レベルが付くため、設定のカスタムプロバイダーに magpie が並び、モデルピッカーにもモデルと思考レベルが出ます。

ターミナル
# /agent-home/config.toml
[model.magpie]
model = "deepseek/deepseek-v4-pro"
base_url = "http://127.0.0.1:3425/v1"
name = "magpie"
api_key = ""
api_backend = "chat_completions"
app_provider_mode = "generic"
app_models = "[…]"
app_efforts = "[…]"
supports_reasoning_effort = …
context_window = …

チャネルのコンテキスト長、画像、思考レベルは選んだモデルに従います。選んだモデルが magpie になくなったときは、一覧の最初のモデルに移ります。

ルートは自分で切り替える

[models] default はアプリが起動時に使うルートです。magpie はこれを書きません。magpie にするとアプリを乗っ取ることになり、アプリは自分のサインインを捨て、セッションが動かなくなるからです。ルートはアプリのままで、切り替えはアプリの設定で Use を押すこと、つまりアプリ自身の選択です。古い magpie はルートを magpie にしていたので、今の magpie は次の同期か接続のときに一度だけ元のルートに戻し、その後に押した Use はそのまま残ります。その後アプリのピッカーで選んだモデルも自分のもので、同期で変わりません。

magpie に切り替えると、アプリは GROK_HOME を agent-home にして CLI を起動します（独立モード）。既定の共有モードでは Grok Build と同じ ~/.grok を使います。

モデルと思考レベル

Grok Build のチャネルには none の思考レベルがないので、レベルはモデルのそれ以外のものです。ピッカーが最初に選ぶのは、アプリのプロバイダーページでそのモデルに付けた既定（モデルにまだそのレベルがあれば）、なければ medium、medium もなければ真ん中のレベルです。

データフォルダー

magpie は Grok App のデータフォルダーを、$GROK_APP_HOME があればそこ、なければ OS ごとに探し、最初に見つかったものを使います。

ターミナル
macOS    ~/Library/Application Support/com.grokapp.grok-app
Windows  %APPDATA%\grokapp\grok-app\data
Linux    $XDG_DATA_HOME/grok-app (~/.local/share/grok-app)
         または ~/.grok-app。$GROK_APP_HOME があればそれ

切断

切断すると magpie は [model.magpie] を消します。ルートに触れるのは、それがまだ magpie を指しているとき（動かないルート）だけで、覚えておいた元のルートに戻すか、なければ消します。ほかのルートはアプリのもので、そのままです。magpie で公式の Grok などアプリ自身のルートを選んだときも、magpie のチャネルを消してそのルートにします。

よくある質問

Grok App で DeepSeek、GLM、ChatGPT サブスクリプションを使えますか？

使えます。magpie が Grok App のカスタムプロバイダーになり、モデルピッカーに magpie のモデルが出ます。設定で magpie の Use を押すと切り替わります。

接続したのに Grok App が magpie にならないのはなぜですか？

ルートを乗っ取るとアプリが自分のサインインを捨てるため、magpie はルートを変えません。Grok App の設定 › Account で magpie の Use を押してください。

Grok App で思考レベルを選べますか？

選べます。magpie の各モデルに思考レベルが付き、既定は自分で付けたレベル、なければ medium です。

切断すると Grok App の元のルートに戻りますか？

ルートがまだ magpie を指していれば戻ります。ほかのルートはそのままです。

同じモデルを他のエージェントでも：fx を任意のモデルで、Aside を任意のモデルで、Ante を任意のモデルで、Mister Morph を任意のモデルで。エラーが出るときは よくあるエラーの直し方、または Discord で質問してください。
