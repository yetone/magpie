ドキュメント · ガイド

API 中継サービスを Claude Code・Codex などのエージェントで使う

中継サービスは 1 つのキーで多くのベンダーのモデルを売り、価格もモデル名も独自のことがよくあります。magpie は中継を 1 つのプロバイダーとして扱い、エージェントは 中継/モデル で使えます。価格・名前・コンテキスト長は中継の実際に合わせて設定できます。

中継を追加する

  1. プリセットの中継。AiHubMix・PipeLLM・302.AI・CherryIN・鱼鱼连线はプリセットで、APIキー を入れるだけです。鱼鱼连线は Auto・Global・China Mainland の回線も選べます。
  2. そのほかの中継。アドレスを指定します。url= は OpenAI 互換、anthropic= は Anthropic 互換で、両方あれば両方、Responses に別アドレスがあれば responses= も加えます。
ターミナル
magpie presets
magpie provider add aihubmix sk-…
magpie provider add "My Relay" url=https://relay.example.com/v1 anthropic=https://relay.example.com key=sk-…
magpie provider test "My Relay"

magpie provider test は API ごとに小さなリクエストを 1 つ送り、レイテンシを表示します。

Claude モデルのキャッシュ

中継に OpenAI と Anthropic の両方のアドレスがあるとき、Claude モデルはエージェントの API にかかわらず Anthropic の Messages に送ります。多くの中継は Chat で cache_control を落とし、毎ターンがキャッシュなしで課金され、思考も失われていました（#997）。Anthropic のアドレスがあれば指定してください。

中継の価格で数える

初期状態では、呼び出しはモデル提供元の定価で数えます。割引や倍率で売る中継ではこの数字は正しくないので、中継の実際の価格を指定すれば、使用量の明細とセッション合計がそれを使います。

ターミナル
magpie model price relay-a/gpt-5.5 0.12,0.60,0.01,0.15
magpie model price relay-a/gpt-5.5
magpie model prices

4 つの数は入力・出力・キャッシュ読み込み・キャッシュ書き込みで、100 万トークンあたりの米ドルです。4 つとも必要で、0 は無料のモデルです。kimi-k3 を moonshot-kimi-k3 として売る中継は kimi-k3 として答えるので、価格のない改名モデルは同じ中継の kimi-k3 の価格で数えます。

モデル名とコンテキスト長

中継はモデル ID に独自の接頭辞や日付を付けることがよくあります。magpie model wire で中継に送る名前を指定し、* はモデル自身を表します。models.dev にないモデルや、サイズが違うモデルには magpie model context と magpie model output でコンテキスト長と応答の上限を指定します。

ターミナル
magpie model wire 'relay-b/*' 'vendor-c/*'
magpie model wire relay-b/model-2 --reset
magpie model context "relay-a/*" 200000
magpie model output relay-a/gpt-5.5 131072

zsh では * を含む引数を引用符で囲んでください。囲まないと no matches found になります。コンテキスト長と上限は、このモデル → このプロバイダーの * → プロバイダー自身の一覧 → models.dev の順に探します。

モデル一覧

中継は新しいモデルをすぐに載せます。ゲートウェイに一覧を定期的に取り直させ、パターンに合う新モデルを自動で公開できます。

ターミナル
magpie provider refresh-every relay 6h
magpie provider auto-include relay 'gpt-*' 're:claude-.*'

補足

  • エージェントがつなぐのは常に magpie だけで、中継のキーもアドレスも持ちません。
  • 複数の中継を同じルーティンググループに入れれば、1 つが失敗しても次のメンバーが答えます。
  • 別のモデルが答えたと応答にあれば、使用量に印が付き、答えたモデルで数えます。

よくある質問

magpie で API 中継サービスを使えますか？

使えます。AiHubMix・PipeLLM・302.AI・CherryIN・鱼鱼连线はキーを入れるだけのプリセットで、ほかの中継は magpie provider add で OpenAI 互換と Anthropic 互換のアドレスを指定します。

中継経由の Claude モデルでキャッシュが効かないのはなぜ？

多くの中継は Chat で cache_control を落とします。中継の Anthropic アドレスを指定すれば、magpie は Claude モデルを Messages に送り、キャッシュと思考が保たれます。

中継が割引価格のとき、費用を正しく数えるには？

magpie model price 中継/モデル で入力・出力・キャッシュ読み込み・書き込みの価格（100 万トークンあたり米ドル）を指定すれば、使用量とセッション合計がそれを使います。

中継のモデル名に接頭辞が付いているときは？

magpie model wire で中継に送る名前を指定します。'relay-b/*' 'vendor-c/*' なら各モデルに vendor-c/ を付けて送ります。
