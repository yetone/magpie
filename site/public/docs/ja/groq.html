ドキュメント · ガイド

Groq を Claude Code・Codex などのエージェントで使う

Groq は自社の LPU チップでオープンモデルを動かし、速さで知られています。OpenAI の gpt-oss やほかの提供元のオープンモデルがあります。magpie の groq プリセットは、それを Claude Code・Codex・OpenCode などにつなぎます。Groq のキー 1 つで、モデル一覧は Groq が返すものです。

追加する

  1. キーを作る。console.groq.com/keys で API キーを作成します。
  2. 追加する。アプリで Groq を選び、APIキー にキーを貼り付けるか、CLI で追加します。
ターミナル
magpie provider add groq 
magpie provider test groq

プリセットは Chat Completions と Responses を https://api.groq.com/openai/v1 に向けているので、アドレスの入力は不要です。OpenCode などで設定した Groq のプロバイダーも、取り込むと groq プリセットになります。

エージェントで使う

モデル ID は groq/<Groq のモデル ID> です。

ターミナル
magpie claude groq/openai/gpt-oss-120b
magpie codex groq/openai/gpt-oss-120b

Claude Code など Anthropic のエージェントのリクエストは、magpie が Chat Completions に変換して Groq に送ります。Groq の Chat API はキャッシュを報告するので、使用量でキャッシュの読み込みが見えます。

Groq のモデルの多くはほかの提供元のもので、models.dev も Groq の下に載せています。そのため magpie は Groq の一覧を提供元自身の情報としては扱いません。

レート制限とコンテキスト

  • Groq の 429 は制限したモデルを名指しします（for model `…`）。magpie はそのキーのそのモデルだけを休ませ、ほかのモデルはそのまま使います。モデルを名指ししない 429 のときだけキー全体を休ませます。
  • Groq が「reduce the length of the messages」と返したとき、magpie はコンテキスト超過と見なし、エージェントが知っているエラー（OpenAI の context_length_exceeded など）に直すので、エージェントは再試行ではなく圧縮します。
  • Groq は受け付けないフィールドに「unsupported」の 400 を返します。magpie が加えるキャッシュキーなどのフィールドなら、外して聞き直し、以後 Groq には送りません。

文字起こしと音声合成

ゲートウェイの /v1/audio/transcriptions と /v1/audio/speech も Groq に使えます。フォームと音声はそのまま Groq に送り、モデルだけを Groq 自身の ID にして、答えは Groq の形式のまま返します。音声合成も同様で、model は groq/playai-tts です。

ターミナル
curl http://127.0.0.1:3425/v1/audio/transcriptions \
  -H 'Authorization: Bearer magpie' \
  -F model=groq/whisper-large-v3 -F file=@meeting.m4a

補足

  • ルーティンググループでは Groq もほかのプロバイダーと同じく順番に聞かれ、失敗すると次のメンバーが答えます。
  • キー 1 つで足りないときは、同じプロバイダーの 2 つ目のアカウントとして追加できます。

よくある質問

magpie は Groq に対応していますか？

対応しています。groq プリセットに Groq の API キーを入れると、Chat Completions と Responses が設定され、モデルは Groq の一覧から取られます。モデル ID は groq/<モデル> です。

Claude Code で Groq のモデルを使えますか？

使えます。magpie が Claude Code の Anthropic リクエストを Chat Completions に変換して Groq に送り、Groq の Chat API がキャッシュを報告するので使用量に出ます。

Groq でレート制限されたら？

Groq の 429 がモデルを名指ししていれば、magpie はそのキーのそのモデルだけを休ませ、ほかのモデルは使い続けます。ルーティンググループにほかのプロバイダーがあれば次に回します。

Groq の Whisper は使えますか？

使えます。magpie の /v1/audio/transcriptions に OpenAI 形式のフォームを送り、model に groq/whisper-large-v3 を指定します。音声合成は /v1/audio/speech です。
