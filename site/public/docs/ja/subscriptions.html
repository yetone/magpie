ドキュメント · ガイド

Claude Pro/Max・ChatGPT Plus/Pro・GitHub Copilot のサブスクを任意のコーディングエージェントで使う

サブスクリプションには magpie で一度サインインするだけです。すると、そのモデルが magpie が設定するすべてのエージェントに並びます：ChatGPT プランの GPT モデルを Claude Code で、Claude プランの Claude モデルを Codex や OpenCode で、Copilot のモデルをそのどれででも。API キーは不要です。

magpie はあなたのコンピューター上の 127.0.0.1:3425 でゲートウェイを動かします。OpenAI、Anthropic、Gemini の API を話し、ストリーミングやツール呼び出しも含めて相互に変換するので、ある API を話すエージェントが別の API で提供されるモデルを使えます。magpie はゲートウェイのアドレスとキーを各エージェント自身の設定ファイルに書き込みます。

対応サブスクリプション

サブスクリプションモデル名ターミナルからサインイン
Claude（Pro、Max、Team）claude/…magpie accounts add claude
ChatGPT（Plus、Pro、Business）codex/…magpie accounts add codex
GitHub Copilotcopilot/…magpie accounts add copilot
Gemini（Code Assist）gemini/…magpie accounts add gemini
Antigravityantigravity/…magpie accounts add antigravity
  • Claude。 Claude サブスクリプションでのリクエストは、コンピューターにインストールされた Claude Code を通じて送られるので、Claude Code はインストールしたままにしてください。
  • Copilot。 Copilot はコードを表示するので、GitHub のページで入力します。独自ドメインの GitHub Enterprise の場合：magpie accounts add copilot --host <name>.ghe.com。
  • Gemini。 これは Gemini CLI の Google サインインです。Google が応じるのは、専用の Google Cloud プロジェクトを持つ Code Assist Standard または Enterprise のアカウントだけです。プロジェクトは magpie accounts project gemini <email> <project> で指定します。
  • Antigravity。 サインインすると Antigravity の Claude と Gemini のモデルが使えます。

その他のサブスクリプションは、magpie の Plugins ページからプラグインとして追加します。プラグインを参照してください。

サインイン

  1. Add provider を開くmagpie の Providers タブで ＋ Add provider を押します。
  2. サブスクリプションのタイルをクリックするmagpie がブラウザでベンダー自身のサインインページを開きます。終わればすぐにアカウントが表示されます。
  3. エージェントにそのモデルを選ぶAgents タブでエージェントの行のモデルをクリックし、サブスクリプションのモデルを選びます。

Claude Code や Codex のように、このマシンですでにサインインしているエージェントも、signed in as … としてプロバイダに表示されます。magpie accounts discovery off で、magpie がそれらのサインインを読まないようにできます。

他のエージェントで使う

サブスクリプションのモデルは、magpie のすべてのエージェントのピッカーに並びます。よく聞かれる組み合わせ：

エージェントサブスクリプションターミナルから
Claude CodeChatGPTmagpie claude codex/gpt-5.5
CodexClaudemagpie codex claude/claude-opus-5-5
Gemini CLIChatGPTmagpie gemini model codex/gpt-5.5
OpenCodeClaudeOpenCode の行で claude/… のモデルを選ぶ

magpie models は選べるすべてのモデルを provider/model で一覧します。各エージェントのガイドに、magpie が設定で何を変えるか、どう元に戻すかが書いてあります：Claude Code、Codex、Gemini CLI。magpie <agent> default は、エージェントから magpie の設定を外し、元の設定を戻します。

複数のアカウントとフェイルオーバー

  • アカウントを追加する。 Claude や ChatGPT のタイルをもう一度クリックするか、magpie accounts add をもう一度実行します。各アカウントはプロバイダの下に並びます。
  • リクエストを分散する。 プロバイダの行を開き、使うアカウントすべてにチェックを入れます。Routing で分散方法を決めます：デフォルトの Smart は、クォータに余裕があり、利用枠が最も早く更新されるアカウントに送ります。他に In order、Until used up、In turn、Least used first、Use before expiry、By weight（Max アカウントを 5、Pro を 1 など）、Speed first があります。
  • 使い切ったらフォールバック。 プロバイダの Fallback には、クォータ切れ、レート制限、障害のときに使うモデルを並べます。
  • 2 つのサブスクリプションで同じモデル。 Claude サブスクリプションの Claude Opus と Copilot の Claude Opus は、自動で 1 つのグループ auto/<model> になります。それを選べば両方を使えます。
  • 残りを確認する。 magpie accounts は各アカウントと、利用枠をどれだけ使ったかを一覧します。

ルーティングモードははじめにで説明しています。

その他のツール

ベース URL を設定できるツールなら、ゲートウェイ経由でサブスクリプションを使えます。Gateway タブの Connect セクションに、コピーできるアドレスとキーがあります。ベース URL は、OpenAI クライアントなら http://127.0.0.1:3425/v1、Anthropic や Gemini のクライアントなら http://127.0.0.1:3425 です。アプリ連携（英語）を参照してください。

複数のアカウントやキーで負荷を分け、互いに引き継げます。アカウント・キー・プロバイダーのローテーションとフェイルオーバー を参照してください。

よくある質問

ChatGPT Plus や Pro のサブスクリプションを Claude Code で使えますか？

はい。magpie で ChatGPT にサインインし、Claude Code の行で codex/… のモデルを選ぶか、magpie claude codex/gpt-5.5 を実行します。magpie が Claude Code の Anthropic リクエストを GPT モデル向けに変換し、応答を戻します。ツール呼び出しも含みます。ティアや推論レベルを含む設定の全体は Claude Code で ChatGPT にあります。

Claude Pro や Max のサブスクリプションを Codex や OpenCode で使えますか？

はい。magpie で Claude にサインインし、エージェントの行で claude/… のモデルを選びます。Claude サブスクリプションでのリクエストは、コンピューターにインストールされた Claude Code を通じて送られるので、Claude Code はインストールしたままにしてください。

GitHub Copilot のモデルを VS Code の外で使えますか？

はい。magpie で Copilot にサインインすると（GitHub が入力用のコードを表示します）、そのモデルが Claude Code、Codex、Gemini CLI、OpenCode など magpie が設定するエージェントで copilot/… として使えます。

サブスクリプションを他のエージェントで使うのに API キーは必要ですか？

いいえ。magpie はベンダー自身のページでサインインし、エージェントにはゲートウェイのキーが渡されます。サインイン情報は magpie の中に残ります。

Claude や ChatGPT のアカウントを複数使い、上限に達したら切り替えられますか？

はい。magpie で各アカウントを追加し、プロバイダの行でチェックを入れます。デフォルトの Smart ルーティングはクォータに余裕のあるアカウントを使い、使い切ったりレート制限されたりすると次へ移ります。magpie accounts で各アカウントの残りを確認できます。

リクエストは magpie のサーバーを通りますか？

いいえ。ゲートウェイはあなたのコンピューターで動きます。プロンプト、応答、キー、アカウントは、あなたが使うプロバイダにだけ送られます。その経路に magpie 自身のサーバーはありません。

各エージェントでサブスクリプションにサインインする必要がありますか？

いいえ。サブスクリプションは他のエージェントの中でサインインするのではなく、magpie で追加します。一度のサインインで、向けたすべてのエージェントに使えます。

キーを使う場合は Claude Code で他のモデルと Codex で他のモデルを参照してください。困ったときは Discord で質問してください。
