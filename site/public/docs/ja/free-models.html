ドキュメント · ガイド

無料モデルを Claude Code・Codex などのエージェントで使う

無料のモデルを出すプロバイダーがあり、キーさえ要らないものもあります。magpie はそれらをほかのモデルと同じ選択欄に並べ、エージェントは プロバイダー/モデル で使えます。無料のものには印が付きます。

キー不要の無料モデル

  1. OpenCode Zen。無料モデル（ID が -free で終わるものと big-pickle）はキー不要です。Zen の無料枠は OpenCode 専用なので、magpie は OpenCode と同じ形でリクエストします。
  2. Kilo Gateway。無料モデル（無料と表示され、ID が :free で終わるもの）はキー不要です。キーなしでは匿名として IP ごとに 1 時間 200 リクエストまでです。
ターミナル
magpie provider add opencode-zen
magpie provider add kilo
magpie models

追加すると、無料モデルがすべてのエージェントの選択欄に出ます。

ターミナル
magpie claude opencode-zen/big-pickle
magpie codex kilo/:free

有料モデルも使うならキーを加えます。無料モデルはそのまま使えます。

ターミナル
magpie provider key opencode-zen 
magpie provider key kilo

選択欄の無料表示

あるプロバイダーで 4 つの価格（入力・出力・キャッシュ読み込み・書き込み）がすべて 0 のモデルには、選択欄で 無料 と表示されます。OpenRouter の :free モデル、OpenCode Zen の -free モデル、NVIDIA NIM の無料モデルなどです。

  • これはそのプロバイダーの価格だけで、同じモデルもほかのプロバイダーではそこでの価格になります。
  • 提供元が無料で出しているモデル（Zhipu の glm-4.7-flash）は、転売するプロバイダーも無料とは限らないので表示しません。
  • プランの価格表は会員がトークンごとに払う額で、モデル自体の価格ではないので数えません。
  • 自分で価格を設定したときはそれが優先され、0 なら無料、それ以外なら表示しません。
ターミナル
magpie model price relay-a/some-model 0,0,0,0

無料モデルを先に、有料を予備に

無料モデルにはよくレート制限があります。無料モデルと有料モデルを同じルーティンググループに入れ、無料を先にしておけば、制限やエラーのときに次のメンバーが答えます。アカウント・キー・プロバイダーのローテーションとフェイルオーバー を参照してください。

補足

  • プロバイダーがモデルの提供終了を返したとき（Zen の 410「Model exo-free has been deprecated.」）、そのモデルは magpie models・/v1/models・各エージェントの一覧から外れます。リクエストに答えが返るか、1 週間たつと戻ります。
  • どのモデルが無料で、どこまで使えるかは各プロバイダーのページのとおりで、変わることがあります。

よくある質問

キーなしで Claude Code に使える無料モデルはありますか？

あります。OpenCode Zen の無料モデル（-free で終わるものと big-pickle）と Kilo Gateway の無料モデル（:free で終わるもの）はキー不要で、magpie provider add opencode-zen か magpie provider add kilo で追加します。

キーなしの Kilo Gateway の制限は？

キーなしでは匿名として IP ごとに 1 時間 200 リクエストまでです。Kilo のキーを加えれば有料モデルも使えます。

選択欄の無料表示はどう決まりますか？

あるプロバイダーがモデルの 4 つの価格をすべて 0 にしていると表示されます。そのプロバイダーの価格だけで、提供元の無料提供やプランの価格表の 0 は数えません。

無料モデルがレート制限されたら？

有料モデルと同じルーティンググループに入れ、無料を先にします。制限やエラーのときは次のメンバーが答えます。
