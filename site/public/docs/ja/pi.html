Pi を任意のモデルで

Pi はコーディングエージェント pi で、models.json に自分のプロバイダを追加できます。magpie はそこに自分を加えるので、pi は magpie にある任意のモデルで動きます：DeepSeek、GLM、Qwen、OpenAI や Anthropic のキー、ChatGPT や Copilot のサブスクリプション。pi にキーを貼る必要はありません。

Pi の設定は ~/.pi/agent、または $PI_CODING_AGENT_DIR が指すフォルダにあります。magpie は models.json に magpie という名前のプロバイダを追加し、ゲートウェイのアドレス、専用のキー、magpie にあるモデルを書くので、それらが pi のモデルピッカーに並びます。次に settings.json の defaultProvider と defaultModel を選んだモデルにします。WSL の Pi も同じように設定されます。

Pi をつなぐ

  1. magpie にプロバイダを追加プロバイダ タブで API キーを追加するか、サブスクリプションにサインインします。
  2. Pi の行でモデルを選ぶエージェント タブで magpie の下のモデルを選びます。
  3. pi を起動そのモデルで始まり、magpie のすべてのモデルがモデルピッカーにあります。
ターミナル
magpie pi deepseek/deepseek-v4-pro    # Pi を DeepSeek で
magpie pi                             # Pi が今使っているモデル

各モデルに書かれる内容

  • そのモデル自身の API各モデルはプロバイダのネイティブ API で呼ばれます：GPT と ChatGPT のモデルは Responses、Claude は Messages、それ以外は Chat Completions。適応的にしか思考しない Claude モデルには forceAdaptiveThinking が付きます。
  • 名前、コンテキスト、返答pi に表示される名前、思考するモデルの reasoning、contextWindow、画像を受け取れるモデルの画像入力、maxTokens。自分で入力した maxTokens は残ります。
  • 思考レベルmagpie で選んだレベルが defaultThinkingLevel に入り、Pi が用意するレベルの範囲に収められます。

Pi は各リクエストにセッションを付けて送る（sendSessionAffinityHeaders）ので、magpie の使用量に pi のセッションごとに表示され、ゲートウェイの会話を記録 にも残ります。自分で設定した値は残ります。

Ctrl+P の一覧

Pi は Ctrl+P で enabledModels のモデルを切り替えます。この一覧は /scoped-models で編集します。一覧があれば magpie は選んだモデルをそこに加えます。なければ作らないので、Ctrl+P は引き続きすべてのモデルを切り替えます。

判断モデルと画像モデル

magpie は Pi のフォルダに拡張 extensions/magpie.ts も置きます。codemode 用に magpie の判断モデルと画像モデルを追加します。magpie プロバイダがある間だけ存在し、プロバイダと一緒に消えます。

あなたのファイル

最初に書き込む前に、magpie は settings.json と models.json を横の .before-magpie ファイルにコピーします。あなたのプロバイダや設定はそのままで、Pi の行には magpie のモデルと並んであなたのモデルも表示されます。

元に戻す

行で自分のモデルを選ぶか、行を magpie から外すか、magpie pi default を実行します。その後何も変えていなければ、magpie は両方のファイルをバイト単位で元に戻します。変えていれば、自分のプロバイダだけを取り除き、あなたの変更は残します。

よくある質問

Pi で DeepSeek や GLM は使えますか？

使えます。magpie にあるすべてのモデルが pi のモデルピッカーにあります：DeepSeek、GLM、Qwen、GPT、Claude など。

Pi で ChatGPT サブスクリプションは使えますか？

使えます。magpie で ChatGPT にサインインし、Pi の行で magpie の下の GPT モデルを選びます。pi は magpie にリクエストを送り、magpie が Responses API でサブスクリプションを使います。

PI_CODING_AGENT_DIR を設定すると、magpie はどこに書きますか？

そのフォルダに書きます。~ は展開されます。相対パスは無視され、magpie は ~/.pi/agent を使います。

WSL の Pi でも使えますか？

使えます。magpie は WSL ディストリの Pi も設定し、プロバイダはディストリから届くゲートウェイを指します。

同じモデルで使えるほかのエージェント：OpenCode で他のモデル、Claude Code で他のモデル、Kimi Code を任意のモデルで、Cursor Private Inference を任意のモデルで。うまくいかないときは よくあるエラーの対処 を見るか、Discord で質問してください。
