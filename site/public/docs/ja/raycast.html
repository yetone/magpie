ドキュメント · ガイド

Raycast を任意のモデルで

Raycast AI は自分のモデルをカスタムプロバイダとして使えます（Raycast Pro、Mac と Windows）。magpie は自身をその一つとして Raycast に加えるので、Quick AI、AI Chat、AI Commands で magpie にある任意のモデルを使えます：DeepSeek、Kimi、GLM、Qwen、OpenAI キー、ChatGPT や Copilot のサブスク。Raycast にキーを貼る必要はありません。

Raycast はカスタムプロバイダをユーザーフォルダの ~/.config/raycast/ai/providers.yaml から読みます（Mac でも Windows でも）。magpie はその providers リストに id が magpie の項目を一つ加えます：ゲートウェイの OpenAI 互換アドレス、Raycast 用のキー、magpie のモデルです。Raycast はこのファイルを監視しているので、再起動しなくてもモデルが現れます。ゲートウェイは各リクエストをモデルのプロバイダ向けに変換し、ツール呼び出しも推論も保ちます。

Raycast を接続

  1. magpie にプロバイダを追加プロバイダ タブで API キーを追加するか、サブスクにサインインします。
  2. Raycast の行を magpie にAgent タブで Raycast のプロバイダを magpie にします。
  3. Raycast でモデルを選ぶQuick AI、AI Chat、AI Command で Raycast のモデル選択を開くと、magpie の下に magpie のモデルが並びます。
ターミナル
magpie raycast magpie     # Raycast AI のピッカーに magpie のモデルを
magpie raycast            # Raycast の今の設定

Windows では、Raycast の設定で Reveal Providers Config を開くと Raycast が設定フォルダを作ります。magpie はそのフォルダで Raycast を見つけます。

並ぶモデル

モデルはファイルではなく Raycast で選ぶので、Raycast のピッカーには Agent ページで Raycast 用に選んだモデルが並びます。そこで隠したモデルは Raycast の一覧からも消えます。各モデルには名前、コンテキスト長、能力が付き、能力はすべて明記されます。書かれていないと Raycast はツールと画像を無効とみなすためです：

  • ツール：すべてのモデルで有効。AI Extensions が動きます。
  • 画像：画像を受け取れるモデルで有効。
  • 推論の強さ：強さの段階があるモデルで有効。
  • 温度：温度を受け付けないモデルで無効。

自分の providers.yaml

magpie が書くのは自分の項目だけです。他のプロバイダ、トップレベルの tools、コメントは残ります。magpie の項目に自分で加えたキー、たとえば include_user_email、additional_parameters、モデルの description も残ります。ファイルは magpie の項目が変わるときだけ書かれます。

元に戻す

Raycast の行から magpie を外すか、magpie raycast default を実行します。magpie は自分の項目を削除し、それが唯一の項目なら providers リストも、ファイルに何も残らなければファイルも削除します。

よくある質問

Raycast Pro は必要ですか？

必要です。カスタムプロバイダは Raycast Pro の機能なので、Pro プランで magpie のモデルが Raycast のピッカーに並びます。

Raycast で ChatGPT サブスクを使えますか？

使えます。magpie で ChatGPT にサインインし、Raycast の行を magpie にして、Raycast で GPT モデルを選びます。Raycast のリクエストは magpie に届き、magpie がサブスクを使います。

Raycast の再起動は必要ですか？

不要です。Raycast は providers.yaml を監視していて、magpie の項目が変わると反映します。

AI Extensions は使えますか？

使えます。すべてのモデルがツール有効で並び、ゲートウェイがツール呼び出しを各モデルのプロバイダへ届けます。

同じモデルを他のエージェントでも：OpenCode で他のモデル、Claude Code で他のモデル、Crush を任意のモデルで、Copilot CLI を任意のモデルで。エラーが出るときは よくあるエラーの直し方、または Discord で質問してください。
