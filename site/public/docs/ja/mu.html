mu

ドキュメント · ガイド

mu を任意のモデルで

mu（qybaihe/mu。npm の mu-agent、mu コマンド、mu デスクトップアプリ）は、Pi に判断カーネルを拡張として加えたエージェントです。起動するのは Pi で、Pi の settings.json と models.json を自分の ~/.mu/agent フォルダーに置き、デスクトップアプリも同じフォルダーを使います。そこで magpie は Pi と同じように mu を設定し、mu は DeepSeek、GLM、Kimi、Qwen、Claude、ChatGPT サブスクなど magpie の任意のモデルで動きます。

mu を設定する

  1. magpie にプロバイダーを追加プロバイダー ページで API キーを追加するか、サブスクリプションにサインインします。
  2. エージェント ページで mu のモデルを選ぶvia magpie のモデルを選び、必要なら思考レベルも選びます。コマンドとデスクトップアプリの両方で使われます。
  3. 新しいセッションを始める新しい mu のセッションがそのモデルを使います。
ターミナル
magpie mu deepseek/deepseek-v4-pro

settings.json と models.json

magpie は settings.json に defaultProvider、defaultModel、defaultThinkingLevel を書き、models.json に自分を magpie というプロバイダーとして加えます。Pi と同じ書き方です。

ターミナル
// ~/.mu/agent/settings.json
{
  "defaultProvider": "magpie",
  "defaultModel": "deepseek/deepseek-v4-pro",
  "defaultThinkingLevel": "…"
}
ターミナル
// ~/.mu/agent/models.json
{
  "providers": {
    "magpie": { "apiKey": "", … }
  }
}

mu は初回起動時、models.json にプロバイダーがなく settings.json に defaultProvider もないときだけ mu setup を求めます。magpie がこれを書いた後は、設定済みとして扱われます。

mu 専用のキー

mu のリクエストは Pi と同じく User-Agent に pi/ とバージョンを書きます。そこで magpie は mu に専用のキー（magpie-mu）を渡し、ゲートウェイはそのリクエストを Pi ではなく mu のものとして数えます。

mu のフォルダー

magpie は mu と同じ規則でフォルダーを探します。次の変数のうち最初に値があるものを使い、その中の ~ はホームを表します。

ターミナル
MU_AGENT_DIR
KYRN_AGENT_DIR
MU_CODING_AGENT_DIR
KYRN_CODING_AGENT_DIR

どれもなければ ~/.mu/agent、古い名前の ~/.kyrn だけがあって ~/.mu がないときは ~/.kyrn/agent です。WSL の mu も同じように設定されますが、そこの変数は magpie からは読めません。

mu はよくある名前です。PATH 上の mu が maildir-utils の mu（djcb/mu）なら、mu-agent とはみなしません。別名 mu-agent でも見つかります。

判定モデル

mu の判断カーネルには独自の設定（mu.json と MU_JUDGE）があります。これは mu のもので、magpie は触りません。

元に戻す

magpie は最初に書く前に settings.json と models.json の元の状態を保存します。元に戻すとき、magpie が残したままなら 1 バイトも違わず元に戻します。

ターミナル
magpie mu default

よくある質問

mu で DeepSeek、GLM、ChatGPT サブスクを使えますか？

はい。magpie のエージェントページで mu に via magpie のモデルを選ぶと、magpie が ~/.mu/agent の settings.json と models.json を書きます。

mu setup はまだ必要ですか？

いいえ。mu は models.json にプロバイダーがなく settings.json に defaultProvider もないときだけ求め、magpie は両方を書きます。

mu のリクエストは Pi のものとして数えられますか？

いいえ。どちらも User-Agent に pi/ と書くため、magpie は mu に専用のキー（magpie-mu）を渡し、mu のものとして数えます。

mu の判定モデルは変わりますか？

いいえ。mu.json と MU_JUDGE は mu 自身の設定で、magpie は触りません。

同じモデルを他のエージェントでも：Pi を任意のモデルで、Mister Morph を任意のモデルで、Grok App を任意のモデルで、Claude Science を任意のモデルで。エラーが出るときは よくあるエラーの直し方、または Discord で質問してください。
