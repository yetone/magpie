NVIDIA NIM

ドキュメント · ガイド

NVIDIA NIM を Claude Code・Codex などのエージェントで使う

NVIDIA は build.nvidia.com で NIM のエンドポイントを提供しています。nvapi- で始まるキー 1 つで そこで提供される多くのモデルを呼べます。magpie の nvidia プリセットは、それを Claude Code・Codex・OpenCode などにつなぎます。

追加する

  1. キーを作る。build.nvidia.com にサインインし、Settings → API Keys で作成します。
  2. 追加する。アプリで NVIDIA NIM を選び、APIキー にキーを貼り付けるか、CLI で追加します。
ターミナル
magpie provider add nvidia nvapi-…
magpie provider test nvidia

プリセットは Chat Completions だけを https://integrate.api.nvidia.com/v1 に設定しています。NIM の /v1/responses は一部のモデルにしか答えず、ほかは 404 なので使いません。

エージェントで使う

モデル ID は nvidia/<NIM のモデル ID> で、一覧は NIM 自身が返します。

ターミナル
magpie claude nvidia/
magpie codex nvidia/

Claude Code は Anthropic の API、Codex は Responses で話しますが、magpie はどちらも Chat Completions に変換して NIM に送り、答えをエージェントが読める形に戻します。

無料モデル

NIM で価格が 0 のモデルには、エージェントのモデル選択欄で 無料 と表示されます。これは NIM の価格だけで、同じモデルもほかのプロバイダーではそこでの価格で数え、NIM の $0 を提供元の価格とは見なしません。

たくさんのキー

CC Switch のようにキーごとに項目を持つアプリから取り込むと、「NVIDIA #001」から「NVIDIA #600」まで数百の項目になることがあります。magpie はキー以外が同じ項目を 1 つのプロバイダーにまとめ、各キーをそのアカウントにします。そうしないと、各モデルがすべてのエージェントの選択欄に数百回並んでいました。元の項目名はキーの名前になり、オフだったものはオフのままです。

補足

  • OpenCode で設定した nvidia プロバイダーも、取り込むとこのプリセットになります。
  • NIM の無料枠が尽きたり制限されたりしたときは、ほかのプロバイダーと同じルーティンググループに入れておけば、次のメンバーが答えます。
  • magpie は NIM のキーが無料か有料かを見分けられないので、キーの課金方法は表示しません。

よくある質問

magpie は NVIDIA NIM に対応していますか？

対応しています。nvidia プリセットに build.nvidia.com の API キーを入れると、integrate.api.nvidia.com/v1 の Chat Completions を使います。モデル ID は nvidia/<モデル> です。

Claude Code と Codex で NIM のモデルを使えますか？

使えます。NIM は Chat Completions だけで使い、magpie が Claude Code の Anthropic リクエストと Codex の Responses リクエストを Chat に変換し、答えを戻します。

どのモデルが無料か分かりますか？

NIM で価格が 0 のモデルは、エージェントのモデル選択欄で無料と表示されます。これは NIM の価格だけで、ほかのプロバイダーではそこでの価格になります。

NVIDIA の項目を数百取り込んでしまったら？

magpie はキー以外が同じ項目を 1 つのプロバイダーにまとめ、各キーをそのアカウントにするので、選択欄でモデルが重複しません。
