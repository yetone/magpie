Crush

仕組み Crush を接続 large・small と強さ 二つのファイル 元に戻す よくある質問

ドキュメント · ガイド

Crush を任意のモデルで

Crush は Charm のターミナル向けコーディング Agent で、設定にあるプロバイダで動きます。magpie は自身をプロバイダとして Crush に加えるので、Crush で magpie にある任意のモデルを使えます：DeepSeek、Kimi、GLM、Qwen、OpenAI キー、ChatGPT や Copilot のサブスク。Crush にキーを貼る必要はありません。

Crush の設定は ~/.config/crush/crush.json です（$XDG_CONFIG_HOME があればその下、Windows では %LOCALAPPDATA%\crush）。magpie はそこに providers.magpie を加えてゲートウェイのアドレス、Crush 用のキー、magpie のモデルを書き、Crush が使うモデルを設定します。ゲートウェイは各リクエストをモデルのプロバイダ向けに変換し、ツール呼び出しも推論も保ちます。WSL の Crush も同じように、ディストリから見えるゲートウェイのアドレスで設定します。

Crush を接続

  1. magpie にプロバイダを追加プロバイダ タブで API キーを追加するか、サブスクにサインインします。
  2. Crush の行でモデルを選ぶAgent タブで Crush の large モデルを、必要なら small モデルも選びます。
  3. crush を起動magpie のモデルは Crush 自身のモデル選択の magpie の下にも並びます。
ターミナル
magpie crush deepseek/deepseek-v4-pro     # Crush の large を DeepSeek で
magpie crush small deepseek/deepseek-v4-flash
magpie crush                              # Crush の今のモデル

large・small と強さ

Crush にはモデルの枠が二つあります：主な作業の large と、軽い作業の small。どちらも magpie のモデルでも自分のプロバイダのモデルでも構いません。行では large モデルの reasoning_effort（low、medium、high）も設定できます。

ターミナル
magpie crush effort high
magpie crush effort default    # Crush の既定に戻す

二つのファイル

Crush は自身のピッカーで選んだモデルをデータファイル ~/.local/share/crush/crush.json（$XDG_DATA_HOME があればその下）に保存し、こちらが設定より優先されます。そのため magpie も選択を Crush と同じそこに書き、プロバイダは設定に置きます。magpie がモデルを選ぶと、Crush のピッカーが前のモデル用に保存した max_tokens などは外すので、あるモデル向けの上限が別のモデルに渡りません。magpie のプロバイダに自分で加えたキーは、magpie がモデルを書き直しても残ります。

元に戻す

両方の枠で自分のプロバイダのモデルを選ぶか、行から magpie を外すか、magpie crush default を実行します。どちらの枠も magpie のモデルを使わなくなると、magpie は crush.json から自分のプロバイダを削除します。

よくある質問

Crush で ChatGPT サブスクを使えますか？

使えます。magpie で ChatGPT にサインインし、Crush の行で GPT モデルを選びます。Crush のリクエストは magpie に届き、magpie がサブスクを使います。

magpie での選択と Crush での選択、どちらが使われますか？

最後に選んだ方です。どちらも Crush のデータファイルに保存されるので、Crush の行でも Crush 自身のピッカーでも、最後に選んだモデルが使われます。

Crush の small モデルは何に使いますか？

主な作業以外の軽い作業です。Crush の行の small で、どのモデルにも設定できます。

WSL の Crush でも使えますか？

使えます。magpie は WSL ディストリの Crush も、ディストリから見えるゲートウェイのアドレスで設定します。

同じモデルを他のエージェントでも：OpenCode で他のモデル、Claude Code で他のモデル、Zed を任意のモデルで、Raycast を任意のモデルで、jcode を任意のモデルで。エラーが出るときは よくあるエラーの直し方、または Discord で質問してください。
