エージェントごとのトークン使用量とコスト

magpie を通るリクエストはすべて記録されます。エージェント、指定したモデルと実際に答えたモデル、アカウント、トークン数、推定コスト、時間、ステータスです。使用量 ページはエージェント・モデル・サブスクリプションアカウントごとに集計し、リクエスト ページは 1 件ずつ表示します。Claude Code や Codex を使うとき、別の計測ツールなしでどこにお金がかかっているか分かります。

コマンドラインで見る

同じ数字はコマンドラインでも見られます。既定は直近 30 日です。

ターミナル
magpie usage                      # the last 30 days: tokens and cost per agent, model and account
magpie usage today                # or 7d, 30d, all
magpie usage --last 24h           # a window ending now (90m, 1.5 days…)
magpie usage --csv 7d             # every request as CSV
magpie usage --csv --account  30d

--last と --days は、ある日の 0 時からではなく、今までの期間を数えます。CSV の各行は 1 件のリクエストで、指定・送信・応答したモデル、トークン、コスト、時間、ステータス、アカウントが入ります。

セッションごとの費用

セッション ページと magpie sessions は、Claude Code・Codex・OpenCode・Pi などの最近のセッションと、それぞれの費用を表示します。モデルやプロジェクトフォルダーで絞り込めます。

ターミナル
magpie sessions                   # the latest sessions, with what each cost
magpie sessions --days 7          # what every session spent, day by day
magpie sessions --model  --folder  --json
magpie sessions read              # which agents' history magpie may read

エージェント自身のセッションファイルは、そのエージェントを許可するまで読みません。既定ではどれも読みません。許可すると、magpie を通らなかったリクエスト（Claude Code が claude.ai に直接サインインしている場合など）も、それらのファイルから使用量に入ります。

価格の出どころ

リクエストは実効価格で数えられます。そのプロバイダーとモデルにあなたが設定した価格、なければプロバイダー自身のカタログの価格、それもなければ models.dev にあるモデル提供元の価格です。

割引や倍率で再販する中継サービスは、提供元の価格では請求しません。実際の価格を設定すれば、使用量とセッションの合計はそれで計算されます。

ターミナル
magpie model price relay-a/gpt-5.5                        # what it is counted at, and where that came from
magpie model price relay-a/gpt-5.5 0.12,0.60,0.01,0.15   # input,output,cache read,cache write
magpie model price relay-a/gpt-5.5 --reset
magpie model prices                                       # every model you priced
  • 4 つの数字は入力・出力・キャッシュ読み取り・キャッシュ書き込みで、単位は 100 万トークンあたりの米ドルです。4 つとも必要です。0 は無料という価格です。
  • プロバイダーのエディターでモデルの下に入力することもできます。
  • 5 つ目の数字は 1 時間キャッシュ書き込みの価格です。Claude のモデルでは省略時に入力の 2 倍（Anthropic のルール）になります。
  • プロバイダーが別のモデルで答えた場合は、請求の対象である答えたモデルの価格で数えます。

価格のないリクエスト

価格の分からないリクエストは合計コストに入らず、無料とも数えません。使用量 ページは合計の横に、価格の付かなかった件数を表示します（「3 件は価格不明」など）。magpie usage も合計のあとに示します。magpie は似た名前から価格を推測しません。-auto、-max、-fast などは価格が違うことがあるので、magpie model price で設定してください。

Claude Code のステータスライン

magpie statusline は Claude Code のステータスラインに 1 行を出します。セッションの最新ターンのモデルと、各サブスクリプションアカウントの枠の使用率で、最後に答えたアカウントに * が付きます。エージェント ページの Claude Code の行でオンにするか、次を実行します。

ターミナル
magpie claude statusline on
# → claude/claude-opus-5-5 | claude a@example.com* 5h 62% 7d 41% | claude B 5h 8% 7d 30%

自分のステータスライン（claude-hud やスクリプト）は上書きされません。Claude Code がゲートウェイにどうサインインしていても使えます。

他のプログラムから読む

使用量ページの集計とリクエスト一覧は、ゲートウェイからも読み取り専用で取得できます。会話の内容は含みません。

ターミナル
GET /v1/magpie/usage
GET /v1/magpie/usage/requests

別のコンピューターからはゲートウェイキーが必要です。予算・モデル・アカウントで制限されたキーは集計を読めず、一覧には自分のリクエストだけが入ります。

よくある質問

Claude Code にいくらかかっているか見るには？

Claude Code を magpie 経由で使うと、各リクエストのトークンと推定コストが記録されます。使用量ページや magpie usage でエージェントごとに、セッションページや magpie sessions でセッションごとに見られます。

中継サービスの価格が公式と違う場合は？

magpie model price <プロバイダー>/<モデル> 入力,出力,キャッシュ読み取り,キャッシュ書き込み（100 万トークンあたりの米ドル）で実際の価格を設定すると、使用量とセッションの合計に反映されます。

全リクエストを書き出せますか？

できます。magpie usage --csv でモデル・トークン・コスト・時間・ステータス・アカウント付きで書き出せます。--account で 1 アカウントに絞れます。

コストのないリクエストがあるのはなぜ？

価格の分からないリクエストは合計に入らず、使用量ページに未設定の件数が出ます。そのモデルに価格を設定すれば数えられます。
