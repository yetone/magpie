magpie で Cherry Studio にすべてのモデルを

Cherry Studio は OpenAI 互換のプロバイダを使えるデスクトップのチャットクライアントです。magpie は magpie という名前のプロバイダとして自分を追加するので、magpie にあるすべてのモデルが Cherry Studio に出ます。API キーを入れたプロバイダも、サインインした Claude・ChatGPT・Copilot のサブスクリプションもです。

magpie はコンピュータ上の http://127.0.0.1:3425 でゲートウェイを動かします。OpenAI Chat Completions API を話し、各リクエストをモデルの背後のプロバイダ（Anthropic、Google、サブスクリプション）向けに変換します。ストリーミング、ツール呼び出し、推論もそのままです。Cherry Studio からは http://127.0.0.1:3425/v1 にある OpenAI 互換のプロバイダが一つ見えます。

Cherry Studio はプロバイダを自分のデータベースに保存し、magpie はそこに書き込みません。代わりに Cherry Studio のプロバイダ追加リンクで自分を追加し、Cherry Studio で確認してもらいます。Cherry Studio 1.x と 2.x のどちらでも動きます。

Cherry Studio に magpie を追加する

  1. magpie にプロバイダを追加プロバイダ タブで API キー（DeepSeek、Kimi、GLM、Qwen、OpenRouter…）を追加するか、サブスクリプションにサインインします。
  2. エージェントタブを開くCherry Studio をこのコンピュータで一度起動すると magpie に表示されます。データフォルダを移動していても見つけます。
  3. 「magpie を追加」を押すCherry Studio の行の magpie を追加 を押すと、Cherry Studio がモデルプロバイダの設定を開き、magpie が入力済みになります：名前 magpie、種類 OpenAI、ゲートウェイのアドレスとキー。
  4. Cherry Studio で確認する確認するまでは何も追加されません。

何も開かないときは、このコンピュータに Cherry Studio のリンクを開くアプリがまだありません。Cherry Studio を一度起動するか入れ直してから、もう一度 magpie を追加 を押してください。

モデルを選ぶ

Cherry Studio はプロバイダのモデル一覧を /v1/models から取得するので、magpie プロバイダには magpie のすべてのモデルが プロバイダ/モデル の名前（例：deepseek/deepseek-v4-pro）で並びます。使いたいモデルを Cherry Studio の magpie プロバイダに追加し、チャットでほかのモデルと同じように選びます。

あとで magpie に追加したプロバイダは、Cherry Studio が次に一覧を取得したときに出ます。Cherry Studio 側の変更は要りません。一つのモデルの裏の複数アカウント、429 後の休止、フェイルオーバーは、ほかのエージェントと同じように働きます。

ターミナルから

ターミナル
magpie cherrystudio add      # Cherry Studio を開いて magpie を追加、そこで確認

cherry-studio という名前でも動きます。

追加されたかどうか

Cherry Studio にゲートウェイのアドレスのプロバイダができると、行にはボタンの代わりに magpie と出ます。magpie は Cherry Studio 2.x のデータベースを読み取り専用で読んで判断します。Cherry Studio 1.x はプロバイダを magpie が読まない場所に保存するため、ボタンは残ります。

使用量とキー

ゲートウェイを共有していなければ、リンクのキーは Cherry Studio 専用なので、そのリクエストは magpie の使用量で Cherry Studio の分として、コーディングエージェントとは別に数えられます。ネットワークでゲートウェイを共有してゲートウェイキーを使っている場合は、そこで使えるキーがリンクに入ります。

よくある質問

Cherry Studio で Claude や ChatGPT を使うのに API キーは要りますか？

要りません。magpie で Claude・ChatGPT・Copilot のサブスクリプションにサインインすると、そのモデルが Cherry Studio の magpie プロバイダに出ます。

magpie は Cherry Studio の設定を変えますか？

変えません。magpie は Cherry Studio 自身のプロバイダ追加ダイアログを開き、あなたが確認します。追加済みかどうかを表示するために、Cherry Studio のデータベースを読むだけです。

magpie プロバイダのアドレスと種類は？

種類は OpenAI、アドレスは http://127.0.0.1:3425/v1 か、magpie で設定したゲートウェイのアドレスです。

新しいモデルが Cherry Studio に出ないのはなぜですか？

Cherry Studio はプロバイダに追加したモデルだけを表示します。magpie プロバイダのモデル一覧を取得し直して、新しいモデルを追加してください。

magpie のエージェントタブに Cherry Studio がありません。

Cherry Studio をこのコンピュータで一度起動すると表示されます。Cherry Studio を一度開いてから、もう一度見てください。

同じモデルを別のデスクトップアプリでも：AionUi を任意のモデルで。コーディングエージェントも使う場合は どのエージェントでもサブスクを使うとはじめにを参照してください。エラーが出るときは よくあるエラーの直し方、または Discord で質問してください。
