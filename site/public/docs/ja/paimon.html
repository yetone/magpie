ドキュメント · ガイド

Paimon を任意のモデルで

Paimon（aisk/paimon、uv tool install paimon で入れる）は pydantic-ai で作られたターミナルのコーディングエージェントです。設定は一つの JSON ファイルで、モデルは provider:name、プロバイダーごとにアドレスとキーを持ちます。magpie がゲートウェイを指すプロバイダーを加えると、Paimon が DeepSeek、GLM、Kimi、Qwen、Claude、ChatGPT サブスクリプションなど magpie の任意のモデルで動きます。

Paimon の設定

  1. magpie にプロバイダーを追加プロバイダー ページで API キーを追加するか、サブスクリプションにサインインします。
  2. エージェント ページで Paimon のモデルを選ぶvia magpie のモデルを選びます。
  3. Paimon を再起動Paimon は起動時に設定を読むので、起動中のものは再起動するまで元のモデルのままです。
ターミナル
magpie paimon deepseek/deepseek-v4-pro

config.json

ファイルは $PAIMON_CONFIG_HOME/config.json、なければ ~/.config/paimon/config.json（Windows も同じ）です。magpie が変えるのは三つ：

ターミナル
{
  "model": "litellm:deepseek/deepseek-v4-pro",
  "providers": {
    "litellm": {
      "api_base": "http://127.0.0.1:3425/v1",
      "api_key": ""
    }
  },
  "compaction": { "context_window": 1000000 }
}

モデルは自分のプロバイダーのキーだけを付けて送られます。ファイルのほかの部分はそのままです。ファイルがなければ magpie が自分だけが読める権限で作ります（キーが入るため）。Paimon 自身が作るのと同じです。WSL のディストリビューションの Paimon も同じように設定します。

litellm を使う理由

magpie は pydantic-ai の litellm プロバイダーを使います。OpenAI 互換のプロキシで、vendor/model の名前をベンダーで判別し、magpie の id の書き方と合います。Paimon のログインには出てこないので、自分のプロバイダーとまずぶつかりません。ゲートウェイは magpie の Paimon 専用キーでこのプロバイダーを見分けます。

コンテキストウィンドウと圧縮

genai-prices が知らないモデル名（magpie の id はそう）では、Paimon は compaction.context_window だけを基準に圧縮し、なければ圧縮しません。そこで magpie はモデルのコンテキストウィンドウを書きます。分からないモデルでは元の値を使い、前のモデルの値は使いません。

元に戻す

最初に入るとき、magpie は元の model、providers.litellm、compaction.context_window を控えます。元に戻すと三つとも書き戻し、残した空のオブジェクトを外し、magpie が作ったファイルは空になれば消します。その後 Paimon で自分のプロバイダーのモデルに替えていれば、それを自分のものとして戻します。

ターミナル
magpie paimon default

よくある質問

Paimon で DeepSeek、GLM、ChatGPT サブスクリプションを使えますか？

使えます。magpie のエージェントページで Paimon に via magpie のモデルを選び、Paimon を再起動します。

config.json のモデルが litellm: で始まるのはなぜですか？

magpie は pydantic-ai の litellm プロバイダーを通します。magpie の vendor/model 形式の id を読める OpenAI 互換プロキシです。

Paimon はコンテキストを圧縮しますか？

します。magpie がモデルのコンテキストウィンドウを書き、Paimon はそれを基準に圧縮します。

元に戻すと設定も戻りますか？

戻ります。magpie が控えた model、litellm プロバイダー、コンテキストウィンドウを書き戻し、ほかの部分には触れていません。

同じモデルを他のエージェントでも：Muse Code を任意のモデルで、Prime Agent を任意のモデルで、Pi を任意のモデルで、PenguinHarness を任意のモデルで。エラーが出るときは よくあるエラーの直し方、または Discord で質問してください。
