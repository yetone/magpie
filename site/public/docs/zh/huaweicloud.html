华为云 MaaS Token Plan 接入 Claude Code 和 Codex

华为云 ModelArts MaaS 的 Token Plan 面向个人账号，开在西南-贵阳一，提供 GLM、Kimi、DeepSeek，接口是 Chat Completions 和 Anthropic Messages。在 magpie 里添加华为云并选好套餐，Claude Code、Codex、Gemini CLI、OpenCode 就都能通过本地网关 127.0.0.1:3425 用上这些模型。

添加华为云

  1. 添加供应商并选套餐在 供应商 页点 ＋ 添加供应商，选 Huawei Cloud MaaS，给 Key 选 Token Plan或Pay as you go，粘贴 Key 并保存。
  2. 给工具选上在 Agent 页给某个工具选 glm-5.3 这类模型。
终端
magpie claude huaweicloud/glm-5.3
magpie codex huaweicloud/deepseek-v4.1-flash
magpie opencode huaweicloud/kimi-k2.6

套餐与接口地址

套餐Chat CompletionsAnthropic Messages
Token Planhttps://api.modelarts-maas.com/plan/v2https://api.modelarts-maas.com/plan/anthropic
按量付费https://api.modelarts-maas.com/openai/v1https://api.modelarts-maas.com/anthropic

Token Plan 的额度只在 /plan 下的接口上扣，所以 magpie 默认用套餐的接口；按量付费的接口单独计费。两者都用 MaaS 的 API Key，在 ModelArts 控制台的鉴权管理里创建。供应商里的每个 Key 都标明自己的套餐。华为云两种接口都不提供 Responses。

模型

拿到模型列表之前，magpie 先给出套餐的模型：glm-5.3、glm-5.1、kimi-k2.6、deepseek-v4.1-flash、deepseek-v4-flash。模型名都是小写，和华为云 OpenClaw 文档里的写法一样。列表拿到后，以华为云返回的为准。

在各个工具里用

  • Claude Code 说的是 Anthropic Messages，华为云套餐有 Anthropic 接口，请求原样转过去。见 Claude Code 接入国产模型。
  • Codex 只说 OpenAI Responses，华为云不提供，所以 magpie 把请求转换成 Chat Completions；apply_patch 这类自定义工具以函数交给模型，调用再以 Codex 能执行的形式还回去。见 Codex 接入第三方模型。
  • Gemini CLI 说 Gemini 的接口，magpie 在本地网关做转换。见 Gemini CLI 接入其他模型。
  • OpenCode：magpie 把模型写进 opencode.json。见 OpenCode 接入其他模型。

常见问题

华为云 Token Plan 怎么接入 Claude Code？

在 magpie 里添加 Huawei Cloud MaaS，把 Key 的套餐选成 Token Plan，然后在 Claude Code 那一行选 glm-5.3 这类模型，或运行 magpie claude huaweicloud/glm-5.3。请求走套餐的 Anthropic 接口 https://api.modelarts-maas.com/plan/anthropic。

华为云 MaaS 能在 Codex 里用吗？

能。华为云没有 Responses 接口，magpie 把 Codex 的请求转换成 Chat Completions，自定义工具也照常能用。运行 magpie codex huaweicloud/deepseek-v4.1-flash。

为什么要用 /plan 下的地址？

Token Plan 的额度只在 /plan/v2 和 /plan/anthropic 上扣，发到 /openai/v1 等按量付费接口的请求会另外计费。magpie 默认用套餐的接口。

华为云 Token Plan 有哪些模型？

magpie 先给出 glm-5.3、glm-5.1、kimi-k2.6、deepseek-v4.1-flash 和 deepseek-v4-flash，拿到华为云的模型列表后以列表为准。

同一套方法用在其他国产模型：腾讯云、百度千帆、火山方舟、GLM 编程套餐、Kimi、DeepSeek、通义千问。遇到报错？见 常见错误排查，或到 Discord 提问。
