文档 · 指南

Claude Code 接入 DeepSeek、Kimi、GLM、Qwen 等国产模型

Claude Code 只会说一种协议：Anthropic Messages。magpie 在你电脑上跑一个本地网关，替你添加的每个供应商说这种协议，再把 Claude Code 指向它。模型在 magpie 里选，或者直接在 Claude Code 的 /model 里切。

网关地址是 127.0.0.1:3425，同时支持 Anthropic、OpenAI 和 Gemini 三种 API。DeepSeek、Kimi、智谱 GLM、MiniMax、通义千问本身就提供 Anthropic 兼容接口，Claude Code 的请求会原样转发过去；不提供的（比如 ChatGPT 订阅里的 GPT 模型），magpie 负责双向转换请求和回复，流式输出和工具调用都包括在内。

国产模型

DeepSeek、Kimi 与 Kimi Code、智谱 GLM（按量付费或 Coding Plan）、Z.ai、MiniMax、通义千问，有国内节点的都单独列出。

订阅

在 magpie 里登录的 ChatGPT、Copilot、Antigravity 账号，它们的模型都能用。

其他

任何 OpenAI 或 Anthropic 兼容的地址和 Key，以及 Ollama、LM Studio。

接入步骤

  1. 添加供应商在 magpie 的 供应商 页点 ＋ 添加供应商，选 DeepSeek、Kimi、智谱 GLM、MiniMax 或通义千问，粘贴 API Key 保存。magpie 会去问供应商有哪些模型。
  2. 给 Claude Code 选模型在 Agent 页点 Claude Code 那一行的模型，选一个，比如 deepseek/deepseek-v4-pro。magpie 会把它写进 ~/.claude/settings.json。
  3. 开一个新会话Claude Code 启动时读取配置，已经打开的会话继续用原来的模型。

命令行也一样：

终端
magpie provider add deepseek sk-…
magpie models                       # 列出所有模型，格式为 provider/model
magpie claude deepseek/deepseek-v4-pro

模型 ID 用的是 magpie 的格式 provider/model。在 Claude Code 里，/model 也会列出 magpie 的模型，标着 “via magpie”，直接在里面切换即可。

智谱 GLM Coding Plan。添加智谱 GLM 或 Z.ai 时，选你的 Key 对应的套餐。Coding Plan 的 Key 有自己的接口地址，发到按量付费的接口会提示余额不足。
想让 claude 继续用自己的账号？在 magpie 里不连接 Claude Code，需要换模型时运行 claude-magpie。它启动的还是同一个 claude，只在这次会话里用 magpie 的设置，不会改写 settings.json。详见 快速上手。

Opus、Sonnet、Haiku 怎么对应

Claude Code 按档位要模型：opus、sonnet、haiku 和 fable。它自己的小任务，比如会话标题、Explore 子代理，走的是 haiku 档。magpie 给每个档位的变量写上模型：

档位env 里的变量默认
opusANTHROPIC_DEFAULT_OPUS_MODEL主模型
sonnetANTHROPIC_DEFAULT_SONNET_MODEL主模型
haikuANTHROPIC_DEFAULT_HAIKU_MODEL、ANTHROPIC_SMALL_FAST_MODEL主模型；主模型是 Claude 时，用同一供应商的 Haiku
fableANTHROPIC_DEFAULT_FABLE_MODEL主模型不是 Fable 时不设置

所以主模型选 DeepSeek，所有档位都跑在 DeepSeek 上。想给某个档位单独配模型，比如 haiku 用便宜一点的，在 magpie 的 Claude Code 那一行设置，或者用命令行：

终端
magpie claude haiku deepseek/deepseek-v4-flash   # 单独给一个档位配模型
magpie claude haiku ""                           # 回到跟随主模型

档位只能配经过 magpie 的模型，而且要先把主模型切到 magpie。

settings.json 里改了什么

Claude Code 从 ~/.claude/settings.json 的 env 里读接口地址。magpie 只改它需要的那几个键，注释和你的其他设置都保留。

键写入的值
env.ANTHROPIC_BASE_URL网关地址
env.ANTHROPIC_AUTH_TOKEN网关的 Key（不是你的供应商 Key，那个留在 magpie 里）
model主模型
env.ANTHROPIC_DEFAULT_*_MODEL、env.ANTHROPIC_SMALL_FAST_MODEL各档位，见上表
env.CLAUDE_CODE_MAX_OUTPUT_TOKENS模型能写的最长回复。Claude Code 对不认识的模型最多只要 32000
env.CLAUDE_CODE_MAX_CONTEXT_TOKENS、env.CLAUDE_CODE_AUTO_COMPACT_WINDOW需要时写入模型的上下文窗口和压缩位置。Claude Code 把不认识的模型当 200K。1M 的模型会标上 [1m]
modelPickermagpie 的模型，给 /model 用。你自己写的 picker 不动

你自己设过的值（比如自己的输出上限）保持不变。ANTHROPIC_MODEL 会被去掉，因为它会盖过 /model 里的选择。文件里如果有 CLAUDE_CODE_USE_BEDROCK 这类云厂商开关，接入 magpie 期间先挪开，切回来时再放回去。

切回 Claude 自己的模型

在那一行选 Claude Code 自己的模型，或者运行 magpie claude default。magpie 去掉它写的内容，把第一次接入时替换掉的东西放回去：你原来的接口地址、Token 和各档位模型。不用手动改文件。

用 ChatGPT 或 Copilot 订阅里的 GPT 模型

在 magpie 里登录订阅：＋ 添加供应商，选 ChatGPT 或 Copilot。magpie 会打开官方的登录页。登录后，账号里的模型以 codex/… 或 copilot/… 出现在 Claude Code 的模型列表里。

终端
magpie accounts add codex      # 登录一个 ChatGPT 账号
magpie claude codex/gpt-5.5

Claude Code 说的还是 Anthropic Messages，magpie 把每个请求转成 GPT 模型能懂的格式，再把回复转回来，工具调用也包括在内。Antigravity 账号同理，模型是 antigravity/…。ChatGPT 套餐的完整用法，包括分档、推理强度和额度，见 Claude Code 用 ChatGPT。

多个 Key 轮换

有多个 Key 或账号时，magpie 可以把 Claude Code 的请求分摊到它们上面，一个用完自动换下一个。

  • 同一家的多个 Key。都加到这个供应商里并勾选。供应商的 路由 决定怎么分摊，备用 列出额度用完或服务挂掉时改用的模型。
  • 同一个模型来自多个供应商。比如 DeepSeek 官方 API 和某个中转都有同一个模型，magpie 会自动建一个组 auto/<model>，给 Claude Code 选它即可。
  • 自己建组。在 路由 页新建一个组，把任意模型放在一个名字下，group/<id>。

各种路由方式见 快速上手。

常见问题

需要自己设置 ANTHROPIC_BASE_URL 吗？

不需要，magpie 会写进 Claude Code 的 settings.json。如果你的 shell 环境变量里设了 CLAUDE_CODE_USE_BEDROCK、CLAUDE_CODE_USE_VERTEX 等云厂商开关，Claude Code 会把请求发到那个云而不是 magpie；magpie 会提示你，把它从 shell 配置里删掉即可。

能在 Claude Code 里切换模型吗？

能。Claude Code 接入 magpie 后，/model 会列出 magpie 的模型和路由组，在里面选的模型会保留。

Claude Code 能用哪些国产模型？

你添加的供应商有的都能用。magpie 内置了 DeepSeek、Kimi、Kimi Code、智谱 GLM、Z.ai、MiniMax、通义千问的预设，Kimi、Kimi Code、MiniMax、通义千问都有国内节点。其他的可以用自定义地址添加。

magpie 必须一直开着吗？

Claude Code 用的是经过 magpie 的模型时，需要：网关跟着应用运行。magpie daemon install 可以把它装成后台服务，不开窗口。

能保留 claude.ai 的登录吗？

Claude Code 那一行有个登录方式设置。默认的 magpie 的密钥 下，Claude Code 接入 magpie 期间会退出 claude.ai，所以 /usage 里的套餐额度、connectors、语音和 /teleport 不可用。选 claude.ai 则保留登录，magpie 不会把它转发出去。两种方式下 Remote Control 和 ultrareview 都不可用。

Claude 订阅和 DeepSeek 能一起用吗？

能。在 magpie 里登录 Claude，它的模型以 claude/… 出现在同一个列表里。Claude 订阅的请求通过你电脑上安装的 Claude Code 发出。

怎么撤销？

在 magpie 里选 Claude Code 自己的模型，或者运行 magpie claude default。magpie 写的内容会去掉，被替换的内容会恢复。
