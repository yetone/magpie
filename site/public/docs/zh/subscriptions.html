文档 · 指南

在任意 Agent 中使用 Claude Pro/Max、ChatGPT Plus/Pro、GitHub Copilot 订阅

在 magpie 里登录一次订阅，它的模型就会出现在 magpie 配置的每个 Agent 里：Claude Code 用 ChatGPT 订阅里的 GPT 模型，Codex 或 OpenCode 用 Claude 订阅里的 Claude 模型，Copilot 的模型哪个 Agent 都能用。不需要 API Key。

magpie 在你电脑上跑一个网关，地址是 127.0.0.1:3425。它同时支持 OpenAI、Anthropic 和 Gemini 三种 API，并在它们之间互相转换，流式输出和工具调用都包括在内，所以只会说一种 API 的 Agent 也能用另一种 API 提供的模型。magpie 会把网关地址和 Key 写进每个 Agent 自己的配置文件。

支持哪些订阅

订阅模型 ID命令行登录
Claude（Pro、Max、Team）claude/…magpie accounts add claude
ChatGPT（Plus、Pro、Business）codex/…magpie accounts add codex
GitHub Copilotcopilot/…magpie accounts add copilot
Gemini（Code Assist）gemini/…magpie accounts add gemini
Antigravityantigravity/…magpie accounts add antigravity
  • Claude。Claude 订阅的请求通过你电脑上安装的 Claude Code 发出，所以要保留 Claude Code。
  • Copilot。Copilot 会给你一个验证码，在 GitHub 页面上输入。使用自有域名的 GitHub Enterprise：magpie accounts add copilot --host <name>.ghe.com。
  • Gemini。这是 Gemini CLI 的 Google 登录。Google 只对有自己 Google Cloud 项目的 Code Assist Standard 或 Enterprise 账号提供服务；用 magpie accounts project gemini <邮箱> <项目> 指定项目。
  • Antigravity。登录后可以用 Antigravity 的 Claude 和 Gemini 模型。

其他订阅以插件形式在 magpie 的 插件 页添加，见 插件。

登录

  1. 打开添加供应商在 magpie 的 供应商 页点 ＋ 添加供应商。
  2. 点订阅的卡片magpie 会在浏览器里打开厂商自己的登录页，登录完成后账号立刻出现。
  3. 给 Agent 选它的模型在 Agent 页点某个 Agent 那一行的模型，选订阅里的一个模型。

本机上已经登录的 Agent，比如 Claude Code 或 Codex，也会作为供应商出现，显示为 已登录 …。运行 magpie accounts discovery off 后，magpie 不再读取这些登录信息。

在其他 Agent 里用

订阅的模型会出现在 magpie 里每个 Agent 的模型列表中。几种常见组合：

Agent订阅命令行
Claude CodeChatGPTmagpie claude codex/gpt-5.5
CodexClaudemagpie codex claude/claude-opus-5-5
Gemini CLIChatGPTmagpie gemini model codex/gpt-5.5
OpenCodeClaude在 OpenCode 那一行选一个 claude/… 模型

magpie models 列出所有可选模型，格式为 provider/model。各 Agent 的指南写了 magpie 改了它配置里的什么、怎么还原：Claude Code、Codex、Gemini CLI。magpie <agent> default 会去掉 magpie 的接入，还原 Agent 原来的设置。

多账号与自动切换

  • 再加一个账号。再点一次 Claude 或 ChatGPT 卡片，或再运行一次 magpie accounts add。每个账号都列在这个供应商下面。
  • 把请求分给多个账号。展开供应商那一行，勾选要用的每个账号。路由 决定请求怎么分：默认的 智能 会发给还有额度、且额度最先重置的账号；另外还有 按顺序、用完再换、轮流、用量少的优先、到期前用完、按权重（比如 Max 账号设 5、Pro 账号设 1）和 速度优先。
  • 用完了自动换。供应商的 备用 列出额度用完、被限流或不可用时改用的模型。
  • 两个订阅里的同一个模型。Claude 订阅和 Copilot 里的 Claude Opus 会自动合成一个组 auto/<model>，选它就能两边一起用。
  • 看还剩多少。magpie accounts 列出每个账号和它的额度用了多少。

路由方式详见 快速上手。

其他工具

任何能设置 base URL 的工具，也能通过网关用订阅。网关 标签页的 接入 部分有地址和 Key 可以直接复制。OpenAI 客户端的 base URL 是 http://127.0.0.1:3425/v1，Anthropic 或 Gemini 客户端是 http://127.0.0.1:3425。见 接入你的应用。

常见问题

Claude Code 能用 ChatGPT Plus 或 Pro 订阅吗？

能。在 magpie 里登录 ChatGPT，在 Claude Code 那一行选一个 codex/… 模型，或者运行 magpie claude codex/gpt-5.5。magpie 把 Claude Code 的 Anthropic 请求转成 GPT 模型的格式，再把回复转回来，工具调用也包括在内。分档、推理强度等完整设置见 Claude Code 用 ChatGPT。

Codex 或 OpenCode 能用 Claude Pro 或 Max 订阅吗？

能。在 magpie 里登录 Claude，在这个 Agent 那一行选一个 claude/… 模型。Claude 订阅的请求通过你电脑上安装的 Claude Code 发出，所以要保留 Claude Code。

GitHub Copilot 的模型能在 VS Code 以外用吗？

能。在 magpie 里登录 Copilot（GitHub 会给你一个验证码），它的模型以 copilot/… 出现在 Claude Code、Codex、Gemini CLI、OpenCode 以及 magpie 配置的其他 Agent 里。

在其他 Agent 里用订阅需要 API Key 吗？

不需要。magpie 在厂商自己的页面登录，Agent 拿到的是网关的 Key。你的登录信息留在 magpie 里。

能同时用多个 Claude 或 ChatGPT 账号、一个到限额就换下一个吗？

能。在 magpie 里添加每个账号，并在供应商那一行勾选。默认的智能路由会用还有额度的账号，一个用完或被限流就换下一个。magpie accounts 能看到每个账号还剩多少。

请求会经过 magpie 的服务器吗？

不会。网关跑在你自己的电脑上。你的提示词、回复、Key 和账号只会发给你使用的供应商，这条路径上没有 magpie 自己的服务器。

每个 Agent 都要登录一次订阅吗？

不用。订阅是在 magpie 里添加的，不需要在别的 Agent 里登录。登录一次，指向 magpie 的每个 Agent 都能用。

用的是 API Key？见 Claude Code 接入其他模型 和 Codex 接入其他模型。遇到问题可以到 Discord 提问。
