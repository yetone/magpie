Empryo

文档 · 指南

让 Empryo 用任意模型

Empryo 的设置在 ~/.empryo/config.json（项目里的 .empryo/config.json 会覆盖它）。它自己的供应商是一个 providers 数组，每项是一个 OpenAI 兼容端点，Empryo 从那里列出模型、调用 /chat/completions。magpie 在里面加一个自己的供应商，把会话起始模型设成 magpie 的模型。这样 Empryo 就能用 DeepSeek、GLM、Kimi、Qwen、GPT 或 ChatGPT 订阅等 magpie 里的任意模型。

接入 Empryo

  1. 在 magpie 里添加供应商在 供应商 页添加 API Key，或登录一个订阅。
  2. 在 Agent 页给 Empryo 选模型Empryo 一行的列表里有你当前的 Empryo 模型，也有 via magpie 的模型。选后者。
  3. 重启 empryoEmpryo 在启动时读设置，已经开着的会话要重开。
终端
magpie empryo deepseek/deepseek-v4-pro

在 Windows 上，WSL 发行版里的 Empryo 也会被找到，接入方式相同，网关地址换成该发行版能访问的地址。

写了哪些内容

终端
{
  "providers": [
    …your own providers, left as they are…,
    {"id": "magpie", "name": "Magpie",
     "baseURL": "http://127.0.0.1:3425/v1",
     "modelsAPI": "http://127.0.0.1:3425/v1/models"}
  ],
  "defaultModel": "magpie/deepseek/deepseek-v4-pro"
}

defaultModel 的格式是 <供应商 id>/<模型 id>，Empryo 在第一个 / 处切开，所以 magpie/deepseek/deepseek-v4-pro 是 magpie 供应商下的 deepseek/deepseek-v4-pro。你自己的供应商和其他设置都保持原样。

magpie 会检查这份接入：如果 config.json 里的 magpie 供应商被删了，或它的 baseURL 已不是当前网关地址，Empryo 那一行会提示。

为什么没有 envVar

Empryo 的供应商可以用 envVar 指定从哪个环境变量读 Key；没有 envVar 时它不发送任何用户的 Key。magpie 的供应商不设 envVar，所以你不需要在环境里放任何 Key。没有 envVar 时，Empryo 只列出 baseURL 有响应（2xx、401 或 403）的供应商，网关的 GET /v1 正好会响应。

什么时候生效

Empryo 只在启动时读设置。empryo 正在运行时，magpie 会提示你重启已打开的 empryo 会话。

切回

切回默认时，magpie 把 defaultModel 还原成接入前的值，并删掉 magpie 供应商。如果 config.json 是 magpie 新建的，删完后文件为空就整个删掉。也可以直接选回你自己的 Empryo 模型。

终端
magpie empryo default

常见问题

Empryo 怎么用 DeepSeek、GLM 或 ChatGPT 订阅？

在 magpie 的 Agent 页给 Empryo 选一个 via magpie 的模型。magpie 在 ~/.empryo/config.json 加一个 id 为 magpie 的供应商，并把 defaultModel 设成 magpie/供应商/模型。重启 empryo 后生效。

需要设置 API Key 环境变量吗？

不需要。magpie 的供应商没有 envVar，Empryo 不会发送你的 Key，请求由 magpie 网关转发到你在 magpie 里添加的供应商。

项目里的 .empryo/config.json 会影响吗？

会。项目的 .empryo/config.json 会覆盖 ~/.empryo/config.json；如果它设了自己的 defaultModel，在那个项目里以它为准。

切回后我原来的模型还在吗？

在。magpie 接入前记下了原来的 defaultModel，切回时放回去，你自己的供应商从没被改动。

更多 Agent 用同样的模型：让 Lody 用任意模型、让 AtomCode 用任意模型、让 Crush 用任意模型、让 miniQ 用任意模型。遇到报错？见 常见错误排查，或到 Discord 提问。
