文档 · 指南

通过 magpie 在 Cherry Studio 里用所有模型

Cherry Studio 是一款桌面 AI 对话客户端，可以接入任何 OpenAI 兼容的供应商。magpie 把自己作为一个名为 magpie 的供应商加进去，于是 magpie 里的每个模型都会出现在 Cherry Studio 中：填了 API Key 的供应商，以及你登录的 Claude、ChatGPT、Copilot 订阅。

magpie 在你的电脑上运行一个网关，地址是 http://127.0.0.1:3425。它支持 OpenAI Chat Completions 接口，并把每个请求翻译给模型背后的供应商（Anthropic、Google 或某个订阅），流式输出、工具调用和推理都保留。Cherry Studio 看到的是一个 OpenAI 兼容的供应商，地址 http://127.0.0.1:3425/v1。

Cherry Studio 把供应商存在自己的数据库里，magpie 从不写入。magpie 通过 Cherry Studio 的“添加供应商”链接把自己加进去，由你在 Cherry Studio 里确认。Cherry Studio 1.x 和 2.x 都适用。

把 magpie 加进 Cherry Studio

  1. 在 magpie 里添加供应商在 供应商 页添加 API Key（DeepSeek、Kimi、GLM、Qwen、OpenRouter…），或登录一个订阅。
  2. 打开 Agent 页Cherry Studio 在这台电脑上运行过之后，magpie 就会列出它，数据目录移到别处也能找到。
  3. 点「添加 magpie」在 Cherry Studio 那一行点 添加 magpie。Cherry Studio 会打开模型服务设置，并已填好 magpie：名称 magpie、类型 OpenAI、网关地址和 Key。
  4. 在 Cherry Studio 里确认确认之前什么都不会添加。

如果什么都没打开，说明这台电脑上还没有程序能处理 Cherry Studio 的链接：先打开一次 Cherry Studio 或重新安装，再点 添加 magpie。

选择模型

Cherry Studio 从 /v1/models 获取供应商的模型列表，所以 magpie 供应商提供 magpie 里的全部模型，名称是 供应商/模型（例如 deepseek/deepseek-v4-pro）。在 Cherry Studio 的 magpie 供应商里添加你要的模型，然后在对话中像其他模型一样选用。

列表里也有 magpie 的图像和视频模型。Cherry Studio 认得其中大多数（gpt-image-2、Gemini 的图像模型、Imagen、Seedream、Grok Imagine…），把它们放在绘画页里，不放进对话。它不认得的，在 magpie 供应商里打开该模型的设置，勾选图像生成。

之后在 magpie 里新增的供应商，会在 Cherry Studio 下次获取列表时出现，Cherry Studio 这边无需改动。一个模型背后的多个账号、429 后的休息时间和故障转移，都和其他 Agent 一样生效。

命令行

终端
magpie cherrystudio add      # 打开 Cherry Studio 添加 magpie，在其中确认

也可以写成 cherry-studio。

magpie 怎么知道已添加

Cherry Studio 里有了指向网关地址的供应商后，这一行会显示 magpie，不再显示按钮。magpie 以只读方式读取 Cherry Studio 2.x 的数据库来判断。Cherry Studio 1.x 把供应商存在 magpie 不读取的地方，所以按钮会一直在。

用量与 Key

网关没有共享时，链接里的 Key 是 Cherry Studio 专用的，所以它的请求在 magpie 的用量里单独记为 Cherry Studio，和编程 Agent 分开。如果你在局域网共享网关并启用了网关 Key，链接会带上在那里可用的 Key。

常见问题

在 Cherry Studio 里用 Claude 或 ChatGPT 需要 API Key 吗？

不需要。在 magpie 里登录 Claude、ChatGPT 或 Copilot 订阅，它的模型就会出现在 Cherry Studio 的 magpie 供应商里。

magpie 会改 Cherry Studio 的设置吗？

不会。magpie 打开的是 Cherry Studio 自己的添加供应商对话框，由你确认。它只读取 Cherry Studio 的数据库，用来显示是否已添加。

magpie 供应商用什么地址和类型？

类型 OpenAI，地址 http://127.0.0.1:3425/v1，或你在 magpie 里设置的网关地址。

为什么 Cherry Studio 里看不到新模型？

Cherry Studio 只显示你添加到供应商里的模型。重新获取 magpie 供应商的模型列表，再把新模型加进去。

magpie 的 Agent 页里没有 Cherry Studio。

Cherry Studio 在这台电脑上运行过之后 magpie 才会列出它。先打开一次 Cherry Studio，再回来看。
