文档 · 指南

让任意模型识图，并在 Agent 里生成图片

DeepSeek、GLM 等很多模型不能看图。在 Claude Code 或 Codex 里粘贴截图后，换到这样的模型，请求通常会被拒绝。通过 magpie 用它们时，magpie 会让一个能看图的模型先把图片描述出来，再把描述放在图片的位置交给模型：当前这一轮、之前的轮次和工具结果里的图片都一样处理。所以换成任何模型，截图照样能用。反过来，Agent 还能通过 Magpie Image 工具生成图片和视频。

识图模型

在 设置 › 模型 › 识图模型 里选择由哪个模型描述图片：

  • 自动：默认值，由 magpie 从你已配置的、能看图的模型里挑一个，优先挑还有额度的。
  • 选一个模型：固定用它。它所在的供应商被删除或关闭后，这一行会提示，并由自动挑选的模型代替。
  • 关闭：不再描述图片，不能看图的模型收到最新一条消息带图的请求时会拒绝。

每张图只描述一次，描述会被缓存，Agent 每轮重发同一张图时不会重复花钱。一个请求里的多张图同时描述，最多 4 张并行。模型旁边可以选思考强度，不选时用该模型最低的一档。

能看图的模型收到的仍是原图，不经过描述。

识图 MCP 服务器

识图也是一个 MCP 服务器（Streamable HTTP），只有一个 analyze_image 工具，用识图模型读图。地址在 识图 MCP 服务器 一行，默认是：

终端
http://127.0.0.1:3425/mcp/magpie/vision
  1. 把地址作为 MCP 服务器添加到 AgentCursor、Claude Desktop 或任何支持 Streamable HTTP 的 Agent 都行。
  2. 调用 analyze_imageimage 可以是 http(s) URL、data URL，或本机文件的绝对路径（支持 ~/ 和 file://，最大 20 MB）。可选的 prompt 用来就图片提问；不给时就描述图片。

本机文件路径只对本机的调用有效。从其他电脑访问时（magpie 开着局域网共享），以 Authorization: Bearer <key> 发送网关密钥，图片用 URL 或 data URL。识图模型关闭或没有能看图的模型时，工具会返回错误，说明去哪里选。

生成图片和视频

Magpie Image 是 magpie 自带的 MCP 工具（magpie mcp image，stdio），在 资源库 里添加给 Agent，也可以在 设置 › 模型 › 生图模型 里点 把 Magpie Image 添加给 Agent…。它有三个工具：

  • generate_image：按提示词生成图片，或用 reference_images 编辑、合成图片。可选 size（如 1024x1024 或 16:9）、n（1 到 4 张）、quality、background。
  • generate_video：按提示词生成 1 到 15 秒的短视频，可以给一张图作为第一帧，或给参考图。
  • generation_result：图片或视频还没做完时，用返回的 id 等它完成，拿到保存位置。

图片默认保存在项目的 generated-images 文件夹，视频在 generated-videos，也可以用 path 指定，已有的文件不会被覆盖。生图用 生图模型 里选的模型（自动 时由 magpie 挑），视频用 magpie 找到的第一个视频模型。

很多 Agent 的工具调用只等 30 到 60 秒，生图常常要一分钟以上。所以每次调用最多等 20 秒：没做完就先返回 id，任务在后台继续，做完照样保存。

图片 API

网关本身也提供 OpenAI 格式的图片接口，会转换成所选模型自己的图片 API：

终端
/v1/images/generations
/v1/images/edits

OpenRouter、火山方舟等供应商的不同接口由 magpie 处理。ChatGPT 账号的 GPT Image、Grok 订阅的 Grok Imagine 和 WorkBuddy 计划的图片模型，不受账号模型列表的限制。名称指向路由分组时，按分组的顺序逐个尝试，一个失败就换下一个。

生图超时

设置 › 模型 › 生图超时：给供应商画图并返回的时间，1 到 60 分钟，默认 5 分钟。图片接口很慢时可以调长。

常见问题

DeepSeek 能看图吗？

DeepSeek 的模型本身不能看图。通过 magpie 用它时，识图模型会先描述图片，描述代替图片交给 DeepSeek，所以 Claude Code 里的截图照样能用。

识图要另外花钱吗？

描述图片用的是识图模型的额度或费用。每张图只描述一次，结果会缓存。

怎么让 Claude Code 生成图片？

在资源库里把 Magpie Image 添加给 Claude Code，它就有 generate_image 工具，用 设置 › 模型 › 生图模型 里的模型画图，图片保存在项目的 generated-images 文件夹。

Cursor 能用 magpie 识图吗？

能。把 /mcp/magpie/vision 作为 MCP 服务器（Streamable HTTP）添加到 Cursor，就有 analyze_image 工具。
