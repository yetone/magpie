美团 LongCat 接入 Claude Code 和 Codex

LongCat 是美团的大模型开放平台，在 api.longcat.chat 提供自家的 LongCat 模型。longcat.chat 和 longcat.ai 的账号用同一个地址，Chat Completions 和 Responses 在 /openai/v1，Anthropic Messages 在 /anthropic。在 magpie 里添加 LongCat，Claude Code、Codex、Gemini CLI、OpenCode 的请求都能原样转过去，magpie 的本地网关 127.0.0.1:3425 只负责路由和 Key。

添加 LongCat

  1. 添加供应商在 供应商 页点 ＋ 添加供应商，选 LongCat，Key 在 longcat.chat/platform/api_keys 创建，粘贴 Key 并保存。
  2. 给工具选上在 Agent 页给某个工具选 LongCat-2.0 这类模型。
终端
magpie claude longcat/LongCat-2.0
magpie codex longcat/LongCat-2.0
magpie opencode longcat/LongCat-2.5-Preview

接口地址

接口地址
Chat Completionshttps://api.longcat.chat/openai/v1
Responseshttps://api.longcat.chat/openai/v1
Anthropic Messageshttps://api.longcat.chat/anthropic
/modelshttps://api.longcat.chat/openai/v1/models

两种接口都用 Authorization: Bearer 传 Key；只给 x-api-key 时 LongCat 回 missing_api_key，magpie 发给 Anthropic 接口的请求默认同时带 x-api-key 和 Bearer，所以照样能通过。其他应用里已经指向这些地址的条目，导入时会认作 LongCat。

模型

magpie 先给出 LongCat-2.0 和 LongCat-2.5-Preview，再从 /openai/v1/models 读 LongCat 的模型列表，以列表为准。模型名区分大小写，照列表写。

在各个工具里用

  • Claude Code 说的是 Anthropic Messages。LongCat 有 Anthropic 接口，请求原样转过去。见 Claude Code 接入国产模型。
  • Codex 只说 OpenAI Responses。LongCat 提供 Responses，Codex 的请求原样转过去。模型会出现在 Codex 的 /model 里。见 Codex 接入第三方模型。
  • Gemini CLI 说 Gemini 的 API，magpie 把它指向本地网关并做转换。见 Gemini CLI 接入其他模型。
  • OpenCode：magpie 把模型写进 opencode.json。见 OpenCode 接入其他模型。

常见问题

LongCat 怎么接入 Claude Code？

在 magpie 里添加 LongCat，粘贴 longcat.chat 平台的 API Key，然后在 Claude Code 那一行选 LongCat-2.0，或运行 magpie claude longcat/LongCat-2.0。请求走 https://api.longcat.chat/anthropic。

LongCat 能在 Codex 里用吗？

能。LongCat 在 /openai/v1 提供 Responses，magpie 把 Codex 的请求原样转过去。运行 magpie codex longcat/LongCat-2.0。

为什么 Claude Code 直连 LongCat 报 missing_api_key？

LongCat 只认 Authorization: Bearer 传的 Key，只发 x-api-key 会被拒。通过 magpie 用时，Key 默认同时放在 x-api-key 和 Bearer 里。

longcat.ai 的账号也能用吗？

能。longcat.chat 和 longcat.ai 的账号用同一个 api.longcat.chat，在 magpie 里都添加 LongCat 即可。

同一套方法用在其他国产模型：阶跃星辰、小米 MiMo、DeepSeek、GLM 编程套餐、Kimi、DeepSeek、通义千问。遇到报错？见 常见错误排查，或到 Discord 提问。
