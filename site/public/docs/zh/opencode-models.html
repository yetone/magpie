OpenCode 接入 DeepSeek、Kimi、GLM，或用 Claude、ChatGPT 订阅

OpenCode 通过配置里的供应商（provider）来调用模型。magpie 会加一个名为 magpie 的供应商，指向你电脑上的本地网关。你在 magpie 里有的模型都列在它下面：DeepSeek、Kimi、GLM、Qwen 的 Key，以及 Claude、ChatGPT、Copilot 订阅里的模型。

网关运行在 127.0.0.1:3425。OpenCode 用 OpenAI Chat Completions 协议发请求，magpie 再按各供应商自己的协议转发；协议不同时，请求和回复都会转换，流式输出和工具调用都不受影响。OpenCode 自己的供应商保持原样，和 magpie 的并列。

国产模型

DeepSeek、Kimi 与 Kimi Code、智谱 GLM（按量付费或 Coding Plan）、Z.ai、MiniMax、通义千问。

订阅

Claude Pro/Max、ChatGPT Plus/Pro、GitHub Copilot，在 magpie 里登录一次即可。

其他

任何 OpenAI 或 Anthropic 兼容的地址和 Key，以及 Ollama、LM Studio。

配置步骤

  1. 添加供应商在 magpie 的 供应商 页点 ＋ 添加供应商，选 DeepSeek、Kimi、智谱 GLM、MiniMax 或通义千问，粘贴 API Key 后保存。magpie 会向厂商查询可用的模型。
  2. 给 OpenCode 选模型在 Agent 页点 OpenCode 那一行的模型，选一个，比如 deepseek/deepseek-v4-pro。magpie 会在 OpenCode 的配置里写入 "model": "magpie/deepseek/deepseek-v4-pro"，并加上 magpie 供应商。
  3. 或者在 OpenCode 里切换供应商加好之后，magpie 的模型会出现在 OpenCode 自己的 /models 列表里的 magpie 下面，也可以直接在那里切。

用命令行也一样：

终端
magpie provider add deepseek sk-…
magpie models                                    # 所有模型（供应商/模型）
magpie opencode deepseek/deepseek-v4-pro         # OpenCode 的主模型
magpie opencode small deepseek/deepseek-v4-flash # 它的 small_model

OpenCode 的 small_model 在那一行里单独可选，可以给它配一个比主模型便宜的模型。

智谱 GLM Coding Plan。添加智谱 GLM 或 Z.ai 时，要选和 Key 对应的套餐。Coding Plan 的 Key 有专用接口，发到按量付费的接口会提示余额不足。

订阅

在 magpie 里登录一次（＋ 添加供应商 或命令行），订阅里的模型就会和其他模型一样列在 OpenCode 的 magpie 下面，不需要 API Key。

订阅模型名命令行
Claude（Pro、Max、Team）claude/…magpie accounts add claude
magpie opencode claude/claude-opus-5-5
ChatGPT（Plus、Pro、Business）codex/…magpie accounts add codex
magpie opencode codex/gpt-5.5
GitHub Copilotcopilot/…magpie accounts add copilot

Claude 订阅的请求经由你电脑上安装的 Claude Code 发出，请保留它。Copilot 登录时会给你一个验证码，在 GitHub 页面输入即可。同一订阅的多个账号可以分摊请求、自动切换，见 订阅用于任意 Agent。

opencode.json 里改了什么

magpie 写的是 OpenCode 从配置目录读取的配置文件。配置目录是 $OPENCODE_CONFIG_DIR（如果设置了），否则是 ~/.config/opencode；文件是 opencode.jsonc、opencode.json、config.json 中第一个存在的，都没有就新建 opencode.json。只改下面这些键，其他设置不动。

键值
modelmagpie/<供应商>/<模型>
small_model同样的格式，设置了才写
provider.magpie.npm@ai-sdk/openai-compatible
provider.magpie.options.baseURLhttp://127.0.0.1:3425/v1
provider.magpie.options.apiKey网关的 Key
provider.magpie.modelsmagpie 给 OpenCode 列出的所有模型

每个模型都带上下文窗口和输出上限（OpenCode 据此判断何时压缩），是否支持图片、推理档位和价格。你添加供应商或账号后，magpie 会同步更新这份列表。如果文件里在 providers 下也有这个供应商（OpenCode 2 的写法），magpie 会一并写入。Windows 上 WSL 发行版里的 OpenCode 也同样配置，写在该发行版的 ~/.config/opencode。

推理档位与费用

  • 推理档位。模型支持的推理强度会写成它在 OpenCode 里的变体（variant），每个变体请求对应的 reasoningEffort。支持快速处理的模型（比如 ChatGPT 订阅里的 GPT 模型）每个档位还会多一个 fast 变体。
  • 费用。magpie 会写入每个模型每百万 Token 的价格（输入、输出、缓存读取、缓存写入），OpenCode 的会话费用才能算出来；不写的话所有模型都显示 0。
  • 提示缓存。magpie 会为它的供应商打开 OpenCode 的 prompt cache key，按这个键做缓存的供应商就能在多轮对话间命中缓存。

精简模型列表

默认情况下，OpenCode 能看到你在 magpie 里的全部模型。只想给它看部分供应商或分组：

终端
magpie visible opencode deepseek,claude   # 只显示这些供应商
magpie visible opencode all               # 恢复显示全部

没列出来的模型，OpenCode 按名字请求时依然可用。

恢复原样

magpie 里 OpenCode 那一行的模型选择器也会列出 OpenCode 自己的供应商（它 auth.json 里已登录的那些）。选其中一个，或者运行：

终端
magpie opencode default

它会恢复接入 magpie 之前的 model 和 small_model，并把 magpie 供应商从文件里删掉。

按供应商：DeepSeek · Kimi 与 Kimi Code · GLM 编程套餐 · 通义千问 · MiniMax

常见问题

OpenCode 怎么用 DeepSeek？

在 magpie 里用 API Key 添加 DeepSeek，然后在 Agent 页给 OpenCode 选一个 DeepSeek 模型，或运行 magpie opencode deepseek/deepseek-v4-pro。magpie 会在 opencode.json 里加上 magpie 供应商并设好模型。

OpenCode 能用 Kimi 或智谱 GLM 吗？

能。在 magpie 里添加 Kimi 或智谱 GLM，给 OpenCode 选它的模型即可。GLM Coding Plan 的 Key 有专用接口，添加时记得选 Coding Plan。

OpenCode 能用 Claude Pro/Max 订阅吗？

能。在 magpie 里登录 Claude（magpie accounts add claude），给 OpenCode 选一个 claude/… 模型。Claude 订阅的请求经由你电脑上安装的 Claude Code 发出，请保留它。

OpenCode 能用 ChatGPT Plus/Pro 订阅吗？

能。在 magpie 里登录 ChatGPT（magpie accounts add codex），选一个 codex/… 模型，比如 codex/gpt-5.5。它的推理档位会显示为 OpenCode 里的模型变体。

magpie 改的是哪个文件？

OpenCode 在 ~/.config/opencode（或 $OPENCODE_CONFIG_DIR）下的配置：opencode.jsonc、opencode.json、config.json 中第一个存在的，都没有就新建 opencode.json。它设置 model 和 small_model，加上 provider.magpie，其他设置不动。

怎么换回 OpenCode 自己的模型？

在 magpie 里 OpenCode 那一行选回它自己的模型，或运行 magpie opencode default。之前的 model 和 small_model 会恢复，magpie 的供应商会被删掉。
