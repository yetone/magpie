Kimi K2 和 Kimi Code 套餐接入 Claude Code、Codex、Gemini CLI 和 OpenCode

月之暗面的 Kimi 有两种用法：按量付费的 Kimi API，和 Kimi Code 会员套餐，各有国际版和国内版接口。magpie 给这四种都做了预设。添加一次 Key，Claude Code、Codex、Gemini CLI、OpenCode 和其他工具就都能通过 magpie 的本地网关 127.0.0.1:3425 用上 Kimi 的模型。

添加 Kimi

  1. 拿到 KeyKimi API 的 Key 在 Kimi 开放平台的 API Key 页面；Kimi Code 的在 Kimi Code 控制台。下表有各自的链接。
  2. 添加供应商在 供应商 页点 ＋ 添加供应商，选发这个 Key 的预设：Kimi、Kimi（国内）、Kimi Code 或 Kimi Code（国内）。粘贴 Key 并保存，magpie 会向 Kimi 查询可用的模型。
  3. 给工具选上在 Agent 页给某个工具选 Kimi 模型：API 上比如 kimi-k2.6，Kimi Code 上比如 kimi-for-coding。
终端
magpie provider add moonshot sk-…        # Kimi API（platform.kimi.ai）
magpie provider add moonshot-cn sk-…     # Kimi API 国内版（platform.kimi.com）
magpie provider add kimi-code sk-…       # Kimi Code 会员
magpie provider add kimi-code-cn sk-…    # Kimi Code 会员，国内版

模型 ID 是 provider/model，比如 moonshot/kimi-k2.6、kimi-code/kimi-for-coding。列出的模型就是 Kimi 当时给你的 Key 提供的。

在各个工具里用

在 Agent 页里点某个工具那一行的模型来选，或者在终端里选。每篇指南都写了 magpie 在那个工具的配置里改了什么、怎么换回去。

终端
magpie claude moonshot/kimi-k2.6
magpie codex moonshot/kimi-k2.6
magpie gemini model moonshot/kimi-k2.6
magpie opencode kimi-code/kimi-for-coding
  • Claude Code 说的是 Anthropic Messages，Kimi 的 Anthropic 接口也说这种协议，所以请求原样转过去。opus、sonnet、haiku 三档默认都用你选的模型，也可以给某一档单独指定。Claude Code 接入其他模型。
  • Codex 只说 OpenAI Responses。Kimi 提供 Chat Completions 和 Anthropic Messages，不提供 Responses，所以 magpie 会转换请求和回复，流式输出和工具调用都保留。模型会出现在 Codex 的 /model 里，带着推理强度。Codex 接入其他模型。
  • Gemini CLI 说 Gemini 的 API。magpie 把它指向本地网关并做转换。Gemini CLI 接入其他模型。
  • OpenCode：magpie 把模型写进 opencode.json，带上推理档位和价格。OpenCode 接入其他模型。

思考

有的 Kimi 模型一直在思考：Kimi Code（国内）的 K3.1 不接受关掉思考的请求。工具要求关掉思考而模型拒绝时，magpie 会保持思考开启再问一次，工具拿到的是回答而不是报错。

余额、用量窗口和搜索

  • Kimi API。那一行显示余额：Kimi（国内）用人民币，Kimi 用美元。
  • Kimi Code。那一行显示从 Kimi 读到的会员用量窗口：每周额度、5 小时这类更短的窗口、每月额度，以及加油包余额。
  • 费用。Kimi Code 的模型标价是 $0，magpie 的 用量 页按 Kimi API 上同一模型的价格来算。
  • 联网搜索。Kimi Code 的 Key 可以用会员自带的搜索接口，magpie 会把它提供给自己不能搜索的 Kimi Code 模型。

常见问题

Kimi Code 套餐能在 Codex 里用吗？

能。在 magpie 里添加 Kimi Code（或 Kimi Code（国内））预设，填上 Kimi Code 控制台里的 Key，然后在 Codex 那一行选模型，比如 kimi-for-coding。Kimi 不提供 Codex 说的 Responses 接口，magpie 会转换请求和回复，流式输出和工具调用都保留。

Kimi K2 怎么接入 Codex？

添加 Kimi 的 API Key，然后在 Codex 那一行选 kimi-k2.6 这类模型，或者运行 magpie codex moonshot/kimi-k2.6。magpie 把 Codex 的 Responses 请求转换成 Kimi 的接口。

Kimi 和 Kimi（国内）选哪个？

看 Key 是哪里发的。platform.kimi.ai 的 Key 用 Kimi（api.moonshot.ai），platform.kimi.com 的用 Kimi（国内）（api.moonshot.cn）。Kimi Code 也一样分 kimi.ai 和 kimi.com 两个。

Kimi Code 是包月的，为什么用量里还有费用？

Kimi Code 的模型列表把价格写成 $0，magpie 就按 Kimi API 上同一个模型的价格来算每次调用。这个数字表示同样的活在 API 上要花多少，并不会扣费。

Kimi Code 能帮工具联网搜索吗？

能。Kimi Code 的 Key 可以用会员自带的搜索接口联网搜索，magpie 会把这个搜索提供给自己不能搜索的 Kimi Code 模型。

各个工具的指南：Claude Code 接入其他模型、Codex 接入其他模型、Gemini CLI 接入其他模型、OpenCode 接入其他模型。遇到问题可以在 Discord 提问。
