GLM 编程套餐接入 Claude Code、Codex、Gemini CLI 和 OpenCode

智谱的 GLM 模型有两个入口：open.bigmodel.cn 的智谱 GLM 和 api.z.ai 的 Z.ai，每个都有两种套餐：按量付费和 GLM Coding Plan（编程套餐）。在 magpie 里添加 Key 并选好套餐，Claude Code、Codex、Gemini CLI、OpenCode 和其他工具就都能通过 magpie 的本地网关 127.0.0.1:3425 用 GLM。

添加 GLM

  1. 拿到 Key智谱 GLM 在 open.bigmodel.cn，Z.ai 在 z.ai。
  2. 添加供应商并选套餐在 供应商 页点 ＋ 添加供应商，选智谱 GLM 或 Z.ai，选 Key 对应的套餐（按量付费 或 Coding Plan），粘贴 Key 并保存。
  3. 给工具选上在 Agent 页给某个工具选 glm-5.3 这类 GLM 模型。
终端
magpie provider add zhipu sk-… plan=coding   # GLM 编程套餐（open.bigmodel.cn）
magpie provider add zai sk-… plan=coding     # GLM Coding Plan（z.ai）
magpie provider add zhipu sk-… plan=api      # 按量付费
选 Key 对应的套餐。编程套餐的 Key 有自己的接口地址，发到按量付费的接口会提示余额不足（429，错误码 1113）。遇到这种情况，magpie 会改用编程套餐的接口再试，能用就把供应商切到套餐的接口；两边都拒绝时，报错会写清两边各说了什么、该改哪里。

套餐与接口地址

预设套餐OpenAI Chat CompletionsOpenAI ResponsesAnthropic Messages
智谱 GLM按量付费https://open.bigmodel.cn/api/paas/v4—https://open.bigmodel.cn/api/anthropic
智谱 GLMCoding Plan（编程套餐）https://open.bigmodel.cn/api/coding/paas/v4https://open.bigmodel.cn/api/v1https://open.bigmodel.cn/api/anthropic
Z.ai按量付费https://api.z.ai/api/paas/v4—https://api.z.ai/api/anthropic
Z.aiCoding Plan（编程套餐）https://api.z.ai/api/coding/paas/v4https://api.z.ai/api/v1https://api.z.ai/api/anthropic

两种套餐共用 Anthropic 接口，账号有编程套餐时按套餐计费。供应商里的每个 Key 都标明自己的套餐，所以一个供应商可以同时放按量付费和编程套餐的 Key，每个 Key 的请求、模型列表和用量窗口都按它自己的套餐来。

在各个工具里用

在 Agent 页里点某个工具那一行的模型来选，或者在终端里选。每篇指南都写了 magpie 在那个工具的配置里改了什么、怎么换回去。

终端
magpie claude zhipu/glm-5.3
magpie codex zhipu/glm-5.3
magpie gemini model zhipu/glm-5.3
magpie opencode zhipu/glm-5.3
  • Claude Code 说的是 Anthropic Messages，GLM 的 Anthropic 接口也说这种协议，所以请求原样转过去。opus、sonnet、haiku 三档默认都用你选的模型，也可以给某一档单独指定。Claude Code 接入其他模型。
  • Codex 只说 OpenAI Responses。编程套餐自己就提供 Responses 接口，Codex 的请求原样转过去；按量付费时，magpie 把它转成 Chat Completions。模型会出现在 Codex 的 /model 里，带着推理强度。Codex 接入其他模型。
  • Gemini CLI 说 Gemini 的 API。magpie 把它指向本地网关并做转换。Gemini CLI 接入其他模型。
  • OpenCode：magpie 把模型写进 opencode.json，带上推理档位和价格。OpenCode 接入其他模型。

思考与推理强度

  • GLM-5.3 一直在思考。它不接受关掉思考的请求。magpie 会保持思考开启再问一次，工具拿到的是回答而不是报错。
  • 推理强度。GLM-5.2 和 GLM-5.3 的推理档位写在 output_config.effort 里，magpie 把工具要的档位放在那里。

用量窗口与搜索

  • 编程套餐的窗口。那一行显示从智谱或 Z.ai 读到的套餐窗口：按小时和按周的额度，以及本月的 MCP 工具调用次数。
  • 联网搜索。有编程套餐的 Key、且设置里没指定搜索服务时，magpie 用套餐自带的搜索服务给 GLM 模型联网搜索。

常见问题

GLM 编程套餐怎么接入 Claude Code？

在 magpie 里添加智谱 GLM（open.bigmodel.cn）或 Z.ai（api.z.ai），把 Key 的套餐选成 Coding Plan，然后在 Claude Code 那一行选 glm-5.3 这类模型，或者运行 magpie claude zhipu/glm-5.3。Claude Code 的请求走 Anthropic 接口，账号有编程套餐时按套餐计费。

GLM 能在 Codex 里用吗？

能。GLM Coding Plan 自己就提供 Codex 说的 OpenAI Responses 接口，magpie 原样转过去；按量付费的话，magpie 把 Codex 的请求转成 Chat Completions。运行 magpie codex zhipu/glm-5.3，或在 Codex 那一行选上。

GLM 编程套餐的 Key 为什么提示余额不足（1113）？

编程套餐的 Key 发到按量付费的接口 https://open.bigmodel.cn/api/paas/v4，会收到 429、错误码 1113。magpie 会改用编程套餐的接口 https://open.bigmodel.cn/api/coding/paas/v4 再试，能用的话就把这个供应商切到套餐的接口。添加 Key 时选对 Coding Plan 就不会遇到。

编程套餐的 Key 和按量付费的 Key 能同时用吗？

能。智谱 GLM 或 Z.ai 供应商里的每个 Key 都可以标明自己属于哪个套餐，请求发到那个套餐的接口，模型列表和用量窗口也按那个套餐来。

智谱 GLM 和 Z.ai 选哪个？

看 Key 是哪里发的：open.bigmodel.cn 的 Key 选智谱 GLM，z.ai 的 Key 选 Z.ai。

GLM-5.3 能关掉思考吗？

GLM-5.3 一直在思考，不接受关掉思考的请求。magpie 会保持思考开启再问一次，工具拿到的是回答。

各个工具的指南：Claude Code 接入其他模型、Codex 接入其他模型、Gemini CLI 接入其他模型、OpenCode 接入其他模型。遇到问题可以在 Discord 提问。
