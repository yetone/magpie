文档 · 指南

查看 Agent 的 Token 用量和费用

经过 magpie 的每次请求都会记下来：哪个 Agent、问的哪个模型、实际由哪个模型回答、哪个账号、多少 Token、估算多少钱、用时和状态。用量 页按 Agent、模型和订阅账号汇总，请求 页列出每一条。用 Claude Code、Codex 等时，不用另装统计工具就能知道钱花在哪里。

命令行查看

同样的数字在命令行里也能看，默认是最近 30 天：

终端
magpie usage                      # the last 30 days: tokens and cost per agent, model and account
magpie usage today                # or 7d, 30d, all
magpie usage --last 24h           # a window ending now (90m, 1.5 days…)
magpie usage --csv 7d             # every request as CSV
magpie usage --csv --account  30d

--last 和 --days 统计截至现在的一段时间，而不是从某天零点算起。CSV 里每一行是一个请求：请求的模型、发出的模型和实际回答的模型、Token、费用、时间、状态和账号。

每个会话花了多少

会话 页和 magpie sessions 列出 Claude Code、Codex、OpenCode、Pi 等 Agent 最近的会话，以及每个会话的花费，可以按模型或项目文件夹筛选：

终端
magpie sessions                   # the latest sessions, with what each cost
magpie sessions --days 7          # what every session spent, day by day
magpie sessions --model  --folder  --json
magpie sessions read              # which agents' history magpie may read

Agent 自己的会话文件，要你允许该 Agent 后 magpie 才会读取，默认一个都不读。允许后，没经过 magpie 的请求（比如 Claude Code 直接登录 claude.ai 时）也能从这些文件计入用量。

价格从哪来

每次请求按“实际价格”计费：你给该供应商和模型设了价格就用你的；没设就用供应商自己目录里的价格；再没有就用 models.dev 上模型厂商的价格。

中转站打折或按倍率卖时，厂商的价格就不对了。告诉 magpie 它实际收多少，用量和会话的合计就会按这个算：

终端
magpie model price relay-a/gpt-5.5                        # what it is counted at, and where that came from
magpie model price relay-a/gpt-5.5 0.12,0.60,0.01,0.15   # input,output,cache read,cache write
magpie model price relay-a/gpt-5.5 --reset
magpie model prices                                       # every model you priced
  • 四个数字依次是输入、输出、缓存读取、缓存写入，单位是美元每百万 Token，四个都要填。0 表示免费，也算一个价格。
  • 也可以在供应商编辑器里该模型下面填。
  • 可以加第五个数字，表示 1 小时缓存写入的价格。Claude 模型不填时按 Anthropic 的规则算，即输入价的 2 倍。
  • 供应商实际换了模型回答时，按回答的那个模型计费，因为供应商按它收费。

没有价格的请求

找不到价格的请求不计入合计费用，也不会当成免费。用量 页会在合计旁写明有几次请求没定价（比如“3 个没有价格”），magpie usage 也会在合计后说明。magpie 不会按相似的名字猜价格：-auto、-max、-fast 等变体价格可能不同，请用 magpie model price 设置。

Claude Code 状态栏

magpie statusline 给 Claude Code 的状态栏输出一行：本会话最近一轮用的模型，以及每个订阅账号各个窗口的用量，星号标出最近回答的账号。在 Agent 页 Claude Code 那一行打开状态栏，或者运行：

终端
magpie claude statusline on
# → claude/claude-opus-5-5 | claude a@example.com* 5h 62% 7d 41% | claude B 5h 8% 7d 30%

你自己的状态栏（claude-hud 或脚本）不会被覆盖。不论 Claude Code 怎么登录网关都能用。

从其他程序读取

用量页的汇总和请求列表也能通过网关读取，只读，不含对话内容：

终端
GET /v1/magpie/usage
GET /v1/magpie/usage/requests

从其他电脑读取需要网关密钥。限定了预算、模型或账号的密钥读不到汇总，请求列表只含它自己的请求。

常见问题

怎么看 Claude Code 花了多少钱？

通过 magpie 用 Claude Code 时，每次请求都会记下 Token 和估算费用。在用量页按 Agent 查看，或运行 magpie usage；每个会话的花费在会话页或 magpie sessions。

中转站的价格和官方不一样，怎么算准？

用 magpie model price <供应商>/<模型> 输入,输出,缓存读取,缓存写入 设置它实际收的价格（美元每百万 Token），用量和会话合计就按这个算。

能导出每条请求吗？

能。magpie usage --csv 导出每个请求，含模型、Token、费用、时间、状态和账号；加 --account 只导出一个账号的。

为什么有的请求没有费用？

找不到价格的请求不计入合计，用量页会写明有几次未定价。给它设个价格就会计入。
