通义千问 Qwen 接入 Claude Code、Codex、Gemini CLI 和 OpenCode

阿里通过 DashScope 提供通义千问，有阿里云百炼、Model Studio 国际站和 Qwen Cloud，按量付费或 Token Plan 套餐。它们都提供 OpenAI Chat Completions 和 Anthropic Messages 接口。在 magpie 里添加一次 Key，Claude Code、Codex、Gemini CLI、OpenCode 以及你接入的其他工具都能通过 magpie 的本地网关 127.0.0.1:3425 用上千问。

添加千问

  1. 拿到 Key按量付费：国内在 百炼控制台，国际站在 Model Studio。Token Plan 的 Key 在各自套餐页里创建。
  2. 添加供应商在 magpie 的 供应商 页点 ＋ 添加供应商，选 Key 所属的 Qwen 预设（见下表），粘贴 Key 并保存。magpie 会向接口查询它提供哪些模型。
  3. 给工具选上在 Agent 页点工具那一行的模型，选一个千问模型，比如 qwen3.8-max。
终端
magpie provider add qwen-cn sk-…                  # 百炼，国内
magpie provider add bailian-token-plan sk-sp-…    # 百炼 Token Plan
magpie provider add qwen-token-plan sk-sp-…       # 千问 AI 开放平台 Token Plan
magpie provider add qwencloud sk-ws-… region=us-east-1
每种 Key 只能用在自己的地址。Token Plan 的 Key（sk-sp-…）在按量付费接口和别的 Token Plan 上都会被拒绝，Qwen Cloud 的 Key 出了自己的地域也会被拒绝。请求返回 401 时，先看看 Key 是不是放在了它所属的预设下。

在各个工具里用

在 Agent 页里点某个工具那一行的模型来选，或者在终端里选。每篇指南都写了 magpie 在那个工具的配置里改了什么、怎么换回去。

终端
magpie claude qwen-cn/qwen3.8-max
magpie codex qwen-cn/qwen3.8-max
magpie gemini model qwen-cn/qwen3.7-plus
magpie opencode qwen-cn/qwen3.8-max
  • Claude Code 说的是 Anthropic Messages，千问 的 Anthropic 接口也说这种协议，所以请求原样转过去。opus、sonnet、haiku 三档默认都用你选的模型，也可以给某一档单独指定。Claude Code 接入其他模型。
  • Codex 只说 OpenAI Responses。DashScope 提供 Chat Completions 和 Anthropic Messages，不提供 Responses，所以 magpie 会转换请求和回复，流式输出和工具调用都保留。模型会出现在 Codex 的 /model 里，带着推理强度。Codex 接入其他模型。
  • Gemini CLI 说 Gemini 的 API。magpie 把它指向本地网关并做转换。Gemini CLI 接入其他模型。
  • OpenCode：magpie 把模型写进 opencode.json，带上推理档位和价格。OpenCode 接入其他模型。

Qwen Code 也是 magpie 支持的工具：它那一行可以选千问的模型，也可以选其他厂商的。

思考与图片

  • 一次性返回的回复。会思考的千问模型在 DashScope 上只能流式返回，要求一次性返回整个回复的请求会被拒绝。工具或路由分组的分类器要一次性回复时，magpie 向 DashScope 要流式回复，再把完整回复（含思考）交给工具。
  • 一直思考的模型。DashScope 上有的模型不允许关掉思考，比如它的 glm-5.3。工具要求关掉思考而模型拒绝时，magpie 会保持思考开启再问一次。
  • 图片。Qwen-Image 和 wan2.7-image 模型通过 DashScope 自己的图片接口生成图片，六个预设都可以。在 magpie 的 设置 → 模型 → 图像 里选用。尺寸写成 宽x高，最大 2048×2048。

余额与用量

magpie 不显示千问的余额或套餐卡片：DashScope 没有查 Key 余额的 API，两个 Token Plan 也没有查额度的 API，额度在阿里云控制台的套餐订阅页里看。用量 页会统计经过 magpie 的每个工具和模型的 token、缓存命中和费用。

常见问题

通义千问怎么接入 Claude Code？

在 magpie 里添加 Key（供应商 → 添加供应商 → Key 所属的 Qwen 预设），然后在 Claude Code 那一行选一个千问模型，比如 qwen3.8-max，或者运行 magpie claude qwen-cn/qwen3.8-max。magpie 会写好 Claude Code 的 settings.json，把请求转给 DashScope 的 Anthropic 接口。

百炼的编程套餐怎么接入？

百炼的订阅套餐在 magpie 里是 Bailian Token Plan 预设：添加供应商时选它，填 sk-sp- 开头的套餐 Key。千问 AI 开放平台的套餐选 Qwen Token Plan，Qwen Cloud 的套餐选 Qwen Cloud Token Plan。

Codex 能用千问吗？Qwen3 Coder 也行吗？

能。magpie 会列出 DashScope 给这个 Key 的所有模型，包括 Coder 模型，Codex 都能用：magpie 把 Codex 的 Responses 请求转成 Chat Completions，再把回复转回去。在 Codex 那一行选模型，或运行 magpie codex qwen-cn/qwen3.8-max，模型会出现在 Codex 的 /model 里。

我的 Key 该选哪个预设？

Key 是在哪个平台创建的就选哪个。Token Plan 的 Key（sk-sp- 开头）只能用在自己套餐的地址，Qwen Cloud 按量付费的 Key（sk-ws- 开头）只能用在自己的地域，放到别的预设下会被 401 拒绝。

Qwen Code 能用其他模型吗？

能。Qwen Code 是 magpie 支持的工具之一，在 Agent 页它那一行可以选你添加的任何模型，千问的或其他厂商的都行。

magpie 能显示 Token Plan 的额度吗？

不能。两个 Token Plan 都没有查额度的 API，额度在阿里云控制台的套餐订阅页里看。magpie 的用量页仍会统计每个工具用掉的 token。

各个工具的指南：Claude Code 接入其他模型、Codex 接入其他模型、Gemini CLI 接入其他模型、OpenCode 接入其他模型。遇到问题可以在 Discord 提问。
