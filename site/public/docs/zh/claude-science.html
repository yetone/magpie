Claude Science

文档 · 指南

让 Claude Science 用任意模型

Claude Science 是 Anthropic 的研究应用：一个叫 claude-science 的守护进程在本机提供界面，窗口（Mac 上是 Swift 启动器，Windows 上是 Electron，Linux 上是浏览器）连上正在运行的守护进程，没有就自己启动一个。守护进程向环境变量 ANTHROPIC_BASE_URL 指定的地址请求 Anthropic 的 Messages API，应用里没有可以改这个地址的设置。所以 magpie 用指向网关的 ANTHROPIC_BASE_URL 启动守护进程，Claude Science 就能用 DeepSeek、GLM、Kimi、Qwen 或 ChatGPT 订阅等 magpie 里的任意模型。

接入 Claude Science

  1. 在 magpie 里添加供应商在 供应商 页添加 API Key，或登录一个订阅。
  2. 在 Agent 页把 Claude Science 的供应商选成 magpiemagpie 会重启它的守护进程，正在运行的会话会被中断。
  3. 重新打开 Claude Science窗口开着的话就重新加载，然后在它的模型菜单里选一个 magpie 的模型。

守护进程

magpie 只做一件事：先 stop，再在原来的端口上以 serve --detached --no-browser 启动守护进程，并给它设上 ANTHROPIC_BASE_URL。不给你设置任何环境变量，也不写 Claude Science 的任何文件。自己在终端里启动时，等价的命令是：

终端
claude-science stop; ANTHROPIC_BASE_URL=http://127.0.0.1:3425 claude-science serve --detached

Claude Science 只接受 https 地址，或者回环地址上的 http，所以本机网关的 http://127.0.0.1 可以直接用。magpie 在 Mac 应用包、Windows 的用户 Programs 文件夹、安装程序链接到的 ~/.local/bin（Linux 上只有这里）或 PATH 上找 claude-science。

Claude 账号登录

Claude Science 仍然要用你的 Claude 账号登录，不支持 API Key；没登录时它不会发出任何请求。登录后它把这个凭据当作请求的 Bearer 发出，magpie 网关不会把它转发给任何供应商。网关通过它每次请求都带的 X-Anthropic-Surface: operon 头认出 Claude Science 的请求。

模型菜单

Claude Science 的模型菜单只列出 ID 以 claude- 开头的模型，所以 magpie 把每个模型以别名 claude-magpie-<数字> 列给它，显示的名字和 Agent 页的一样。在没有你选的模型时（比如还没选之前的默认模型，或者它做小任务用的 haiku），它会按 Claude 自己的模型 ID 请求；magpie 不提供的模型，就交给它上一轮用的那个模型。

保持接入

守护进程一直运行到被停止或电脑重启。接入期间，magpie 在它没运行时把它再启动起来。Claude Science 的窗口在没有守护进程时会自己启动一个不带这个变量的；应用更新后也可能提出用自己的守护进程代替。magpie 会在没有会话运行时换回自己的守护进程，但不会动由 launchd 或 systemd 这类服务管理器启动的守护进程（停掉它会马上被拉起来）；这期间 Agent 页会说明情况。如果你一小时里反复换回自己的，magpie 就不再替换。

WSL

Claude Science 装在 WSL 发行版里时，Windows 上的 magpie 通过 wsl.exe 在发行版里启动它的守护进程，同样设上 ANTHROPIC_BASE_URL，并在发行版运行期间保持接入，但不会去启动一个已停止的发行版。镜像网络下，发行版的 127.0.0.1 就是 Windows 的，直接用网关地址；NAT 网络下，magpie 在发行版里启动一个 socat 中转，监听 127.0.0.1 上网关的端口，转到 Windows 在 WSL 网络上的地址。

切回

在 Agent 页取消 magpie 后，magpie 会在守护进程运行时不带这个变量重启它，Claude Science 就回到 Anthropic 的 API。

常见问题

Claude Science 能用 DeepSeek、GLM 或 ChatGPT 订阅吗？

能。在 magpie 的 Agent 页把 Claude Science 的供应商选成 magpie，再在它的模型菜单里选 magpie 的模型。

magpie 会改 Claude Science 的文件或我的环境变量吗？

不会。magpie 只用 ANTHROPIC_BASE_URL 重启它的守护进程，不写任何文件，也不给你设置变量。

还需要登录 Claude 账号吗？

需要。Claude Science 不支持 API Key，必须登录 Claude 账号；它发出的这个凭据 magpie 不会转发给任何供应商。

为什么模型菜单里是 claude-magpie 开头的名字？

Claude Science 只列出以 claude- 开头的模型 ID，所以 magpie 用 claude-magpie-<数字> 的别名列出每个模型，显示名和 Agent 页一样。

更多 Agent 用同样的模型：让 Claude Desktop 用任意模型、让 mu 用任意模型、让 Mister Morph 用任意模型、让 VS Code 用任意模型。遇到报错？见 常见错误排查，或到 Discord 提问。
