文档 · 指南

让 DS Bot 用任意模型

DS Bot（原名 DeepSeek Bot）是基于 DSH 的 Electron 桌面应用，自带一份 DSH，用自己的数据目录运行 ds-bot 这个 profile。它的模型就是这份 DSH 的 llm-pi-ai 路由。magpie 在这里加一条自己的路由，DS Bot 就能用 GLM、Kimi、Qwen、Claude、GPT 或 ChatGPT 订阅等 magpie 里的任意模型，也能继续用 DeepSeek。

接入 DS Bot

  1. 在 magpie 里添加供应商在 供应商 页添加 API Key，或登录一个订阅。
  2. 在 Agent 页给 DS Bot 选模型选一个 via magpie 的模型，magpie 把路由和 Key 写进 DS Bot 的数据目录。
  3. 在 DS Bot 里新建 Bot新 Bot 从这个模型开始，见下文。
终端
magpie ds-bot deepseek/deepseek-v4-pro

这里说的是 DS Bot 桌面应用。DS Bot 也是一个 DSH 插件：在 DSH Desktop 或 dsh web 里用它时，它运行在 ~/.dsh 上，模型跟着 magpie 的 DSH 那一行走。

数据目录在哪

magpie 按 DS Bot 自己的顺序找数据目录：

  1. DS_BOT_HOME设置了就用它，适合临时目录。
  2. locations.json 里的 dataDir在 Electron 的 userData 下：DS_BOT_SHELL_DATA，否则是 <配置目录>/DS Bot。如果旧的 <配置目录>/DeepSeek Bot 存在，而 DS Bot 的目录里没有 locations.json，就用旧目录。
  3. ~/.ds-bot没有 locations.json 时用它，这是第一次运行的默认位置。

locations.json 读不出来，或者里面没有 dataDir，magpie 就当作不知道在哪，不碰任何目录。

写了哪些内容

终端
<数据目录>/
  .env                              ← magpie 给 DS Bot 的 Key
  profiles/ds-bot/cordis.patch.yml  ← magpie 的 llm-pi-ai 路由
  （DSH 的密钥库）                 ← 同一个 Key
  agent-default-model               ← 你选的模型

和 DSH 一样：magpie 在 profile 的补丁列表 profiles/ds-bot/cordis.patch.yml 里加自己的路由，把 Key 写进 .env 和 DSH 的密钥库，再设置 agent-default-model。你自己的路由保持原样。

新 Bot 和旧 Bot

DS Bot 的新 Bot 从 DSH 的 agent-default-model 开始，所以新建的 Bot 会用你在 magpie 选的模型。如果你在 DS Bot 里设了 Bot 的默认模型，就以那个为准。之前建的 Bot 保留自己的模型，直到你给它另选一个。magpie 会在 Agent 页这样提示。

网页搜索

DS Bot 的网页搜索也经过 magpie。如果 magpie 还没有能搜索的东西，它会提示你添加一个自带搜索的供应商（DeepSeek、Claude、Codex 等），或者在 设置 › 网页搜索 里配置一个搜索 API。

还没打开过 DS Bot

装了还没打开过也可以先接入，magpie 会提示 DS Bot 第一次打开时就从这个模型开始。DS Bot 首次打开时只补写缺少的 profile 文件，所以 magpie 先建好的补丁列表会保留。

切回

切回默认时，magpie 去掉自己的路由。如果 DS Bot 一直没打开过，magpie 会删掉它为 DS Bot 建的文件。

终端
magpie ds-bot default

常见问题

DS Bot 能用 DeepSeek 以外的模型吗？

能。在 magpie 的 Agent 页给 DS Bot 选一个 via magpie 的模型，magpie 在 DS Bot 自带的 DSH 里加一条路由，GLM、Kimi、Qwen、Claude、GPT 或 ChatGPT 订阅都能用。

为什么我原来的 Bot 还是旧模型？

之前建的 Bot 保留自己的模型。新建的 Bot 才从 magpie 设的默认模型开始；旧 Bot 要在 DS Bot 里给它另选模型。

我改过 DS Bot 的数据目录，magpie 找得到吗？

找得到。magpie 读 DS Bot 的 locations.json 里的 dataDir。读不出来时 magpie 不改动任何目录。

在 DSH Desktop 里用 DS Bot 插件呢？

插件运行在 ~/.dsh 上，模型跟 magpie 的 DSH 那一行走，在 Agent 页给 DSH 选模型即可。

更多桌面应用用同样的模型：让团结 Cowork 用任意模型、让 OpenBot 用任意模型、让 miniQ 用任意模型、让 OpenHanako 用任意模型。遇到报错？见 常见错误排查，或到 Discord 提问。
