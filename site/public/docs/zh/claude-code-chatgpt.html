Claude Code 用 ChatGPT

原理 登录 ChatGPT 选 GPT 模型 Opus、Sonnet、Haiku 推理强度 额度与用量 多账号 切回去 反过来用 常见问题

文档 · 指南

在 Claude Code 中使用 ChatGPT Plus/Pro 订阅

Claude Code 可以跑在你 ChatGPT Plus 或 Pro 套餐的 GPT 模型上。在 magpie 里登录 ChatGPT，给 Claude Code 选一个 codex/… 模型，照常使用即可。不需要 OpenAI API Key。

Claude Code 说的是 Anthropic 的 Messages API。magpie 在你电脑上运行一个网关，地址 127.0.0.1:3425，把 Claude Code 的每个请求翻译给 GPT 模型，再把回复翻译回来，流式输出和工具调用都包括在内。magpie 把网关的地址和密钥写进 Claude Code 的 settings.json，你的 ChatGPT 登录只保存在 magpie 里。

登录 ChatGPT

  1. 打开添加供应商在 magpie 的 供应商 页，点 ＋ 添加供应商。
  2. 点 ChatGPT 卡片magpie 会在浏览器里打开 OpenAI 自己的登录页，登录完成后账号马上出现。

也可以在终端里：

终端
magpie accounts add codex      # 登录一个 ChatGPT 账号

这个账号的模型 id 是 codex/…。

给 Claude Code 选 GPT 模型

在 Agent 页，点 Claude Code 那一行的模型，选一个 codex/… 模型。终端里：

终端
magpie models                  # 列出所有模型，格式 provider/model
magpie claude codex/gpt-5.5

在 Claude Code 里，/model 也会列出 magpie 的模型，标着 “via magpie”，可以直接在那里切换。

只想部分会话用 GPT？不在 magpie 里接入 Claude Code，需要时运行 claude-magpie。它用 magpie 的设置启动同一个 claude，只对这次会话生效，不改写 settings.json。

Opus、Sonnet、Haiku 怎么对应

Claude Code 按分档请求模型：opus、sonnet、haiku 和 fable。它自己的小任务，比如会话标题和 Explore 子代理，走 haiku 档。主模型是 GPT 模型时：

分档env 里的变量默认
opusANTHROPIC_DEFAULT_OPUS_MODEL你选的 GPT 模型
sonnetANTHROPIC_DEFAULT_SONNET_MODEL你选的 GPT 模型
haikuANTHROPIC_DEFAULT_HAIKU_MODEL、ANTHROPIC_SMALL_FAST_MODEL你选的 GPT 模型
fableANTHROPIC_DEFAULT_FABLE_MODEL不设置

想让某一档用单独的模型，比如 haiku 用小一点的，在 magpie 里 Claude Code 那一行设置，或者在终端里：

终端
magpie claude haiku codex/…    # 某一档单独用一个模型
magpie claude haiku ""         # 回到主模型

推理强度

Claude Code 开启 thinking 的请求里，它要的推理强度会作为 GPT 模型的推理强度发过去。magpie 也会告诉 Claude Code 每个模型支持哪些档位。

想不管 Claude Code 要什么都固定一个强度，在 Claude Code 那一行设置 推理强度。opus 推理强度 等按分档设置，子代理推理强度 管子代理。默认都是 跟随 Claude Code 请求的推理强度。已打开的 Claude Code 会话仍用启动时的推理强度，重开后生效。

额度与用量

请求用的是你的 ChatGPT 账号，所以和 Codex 自己的请求一样，计入套餐的用量限制。

  • 看用了多少。打开 Claude Code 那一行的 状态栏：Claude Code 输入框下方会显示 magpie 所用账号的 5 小时和 7 天用量。magpie accounts 列出每个账号用掉了多少额度。用量 页有历史记录。
  • 账号用完时。magpie 会暂停这个账号，直到 OpenAI 拒绝时给出的重置时间；没有给出时等它的整个窗口刷新；都不知道时暂停 5 小时。期间请求转给你的下一个账号，或供应商的 备用。窗口刷新后账号自动回来。

多账号与自动切换

  • 再加一个账号。再点一次 ChatGPT 卡片，或再运行一次 magpie accounts add codex。每个账号都列在这个供应商下面。
  • 在账号间分配请求。打开供应商那一行，勾上要用的账号。默认的 智能 路由会把请求发给还有额度、且额度最早刷新的账号。
  • 用完时换模型。供应商的 备用 列出所有账号用完、被限流或出错时要用的模型，可以是另一个订阅或 API Key 的模型。

各种路由方式见 快速上手。

切回去

在 Claude Code 那一行选回 Claude Code 自己的模型，或者运行：

终端
magpie claude default

这会撤掉 magpie 对 Claude Code 的接入，恢复原来的配置。Claude Code 那一行的 断开 效果相同。

你的 claude.ai 登录。用 magpie 的模型时，Claude Code 的 登录方式 默认是 magpie 的密钥：Claude Code 会退出 claude.ai，/usage 的套餐额度、connectors、语音和 /teleport 都不可用。设为 claude.ai 可以保留它们。

反过来：在 Codex 里用 Claude

Claude Pro 或 Max 订阅也能这样用在 Codex 里。在 magpie 里登录 Claude，给 Codex 选一个 claude/… 模型。Claude 订阅的请求经由你电脑上安装的 Claude Code 发出，所以请保留它。

终端
magpie accounts add claude
magpie codex claude/claude-opus-5-5

见 Codex 接入其他模型 和 订阅用于任意 Agent。

常见问题

能在 Claude Code 里用 ChatGPT Plus 或 Pro 订阅吗？

可以。在 magpie 里登录 ChatGPT，在 Claude Code 那一行选一个 codex/… 模型，或运行 magpie claude codex/gpt-5.5。magpie 把 Claude Code 的请求翻译给 GPT 模型，再把回复翻译回来，工具调用也包括在内。

需要 OpenAI API Key 吗？

不需要。magpie 在 OpenAI 自己的页面登录，Claude Code 拿到的是网关的密钥。你的登录只保存在 magpie 里。

会占用 ChatGPT 套餐的额度吗？

会。请求用的是你的 ChatGPT 账号，计入它的用量限制。magpie 的状态栏会在 Claude Code 输入框下方显示每个账号的 5 小时和 7 天用量。

Claude Code 的 Haiku 请求用哪个模型？

默认用你选的 GPT 模型，除非你用 magpie claude haiku <model> 给 haiku 档单独设一个。

怎么切回 Claude 自己的模型？

运行 magpie claude default，或在 magpie 里 Claude Code 那一行选回 Claude Code 自己的模型。

请求会经过 magpie 的服务器吗？

不会。网关运行在你自己的电脑上，请求从这里直接发给 OpenAI，中间没有 magpie 的服务器。

用的是 API Key？见 Claude Code 接入其他模型。遇到报错？见 常见错误排查，或到 Discord 提问。
