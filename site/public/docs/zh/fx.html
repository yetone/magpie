fx

工作原理 接入 fx settings.json 模型列表 你自己的设置 重启 fx 切回

文档 · 指南

让 fx 用任意模型

fx（fx.sh，Vercel Labs 出品，不是同名的 JSON 查看器）把设置放在 ~/.fx/settings.json：provider 是它在用的供应商（gateway、codex、grok 或你自己加的），models 是每个供应商用的模型，providers 是你自己加的供应商。magpie 在这里加一个叫 magpie 的供应商，fx 就能用 DeepSeek、GLM、Kimi、Qwen、Claude 或 ChatGPT 订阅等 magpie 里的任意模型。

接入 fx

  1. 在 magpie 里添加供应商在 供应商 页添加 API Key，或登录一个订阅。
  2. 在 Agent 页给 fx 选模型选一个 via magpie 的模型。magpie 通过 ~/.fx 文件夹认出 fx，不看 fx 命令，因为这个名字很常见。
  3. 重启 fxfx 只在启动时读设置。
终端
magpie fx deepseek/deepseek-v4-pro

settings.json

选了 magpie 的模型后，magpie 把 provider 设成 magpie，把 models.magpie 设成模型，比如 deepseek/deepseek-v4-pro，并写入 providers.magpie：协议是 openai-chat-completions，base_url 是网关的 /v1，auth 是 none，不需要 Key。在 fx 里，这个模型显示为 magpie/deepseek/deepseek-v4-pro。

终端
// ~/.fx/settings.json
{
  "provider": "magpie",
  "models": { "magpie": "deepseek/deepseek-v4-pro" },
  "providers": {
    "magpie": {
      "protocol": "openai-chat-completions",
      "base_url": "http://127.0.0.1:3425/v1",
      "auth": { "type": "none" },
      "tool_choice_mode": "send",
      "model_metadata": {
        "deepseek/deepseek-v4-pro": { "supports_tool_use": true, "supports_vision": …, "context_window": …, "max_output_tokens": … }
      }
    }
  }
}

fx 不给你自己加的供应商发思考强度，所以 fx 没有思考强度可选。在 WSL 里装的 fx 也一样，base_url 用的是这个发行版里访问网关的地址。

模型列表

fx 的模型选择器列出的就是 model_metadata：magpie 目录里的模型，每个都标明支持工具调用，并带上是否支持图片、上下文长度和输出上限。fx 不接受不小于上下文长度的输出上限，这种情况 magpie 就不写输出上限。fx 最多接受 256 个模型，超过就拒绝整个设置文件，所以 magpie 最多写 256 个，并把正在用的模型排在最前，保证它不会被截掉。目录变了，magpie 会在 fx 接入时更新这个列表。

你自己的设置

fx 的供应商可以有 reviewer_model（auto 权限模式拿来审查的模型），magpie 不写它，你设了会一直保留。tool_choice_mode magpie 写 send，你改成 omit 后也会保留。协议、地址、auth 和 model_metadata 由 magpie 管；auth 整个重写，因为 fx 不接受 type 为 none 时旁边还有 env。

重启 fx

fx 只在启动时读设置。改了模型时如果有 fx 正在运行，magpie 会提示你重启打开着的 fx 会话。

切回

选回 fx 自己的模型时，magpie 删掉 providers.magpie 和 models.magpie；provider 是 magpie 时也一并删掉，fx 就回到不用 magpie 时的供应商，没设过就是 Vercel 的 AI Gateway。选的模型写进那个供应商的 models；选 default 则删掉它，让 fx 用自己的默认模型。

终端
magpie fx default

常见问题

这里说的 fx 是哪个？

Vercel Labs 的编程 Agent fx（fx.sh），设置在 ~/.fx。同名的 JSON 查看器 fx 与此无关。

fx 接入 magpie 需要 API Key 吗？

不需要。magpie 在 fx 里的供应商是 auth none，直接连本机网关。

为什么 fx 里最多只有 256 个 magpie 模型？

fx 的 model_metadata 超过 256 个就会拒绝整个设置文件，所以 magpie 最多写 256 个，并且正在用的模型排在最前。

切回后 fx 用哪个供应商？

用不经过 magpie 时的那个供应商；没设过就是 Vercel 的 AI Gateway。

更多 Agent 用同样的模型：让 Aside 用任意模型、让 Ante 用任意模型、让 omp 用任意模型、让 Grok App 用任意模型。遇到报错？见 常见错误排查，或到 Discord 提问。
