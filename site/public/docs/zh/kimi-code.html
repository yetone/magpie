文档 · 指南

让 Kimi Code 用任意模型

Kimi Code 是月之暗面的编程 Agent kimi，可以在配置里添加你自己的供应商和模型。magpie 把它的模型加进去，于是 kimi 不只能用 Kimi，还能用你在 magpie 里的任何模型：DeepSeek、GLM、Qwen、OpenAI 或 Anthropic Key，或 ChatGPT、Copilot 订阅，不用往 kimi 里贴 Key。想在其他 Agent 里用 Kimi 模型，见 Kimi 接入 Claude Code、Codex 等。

Kimi Code 的设置在 ~/.kimi-code/config.toml（$KIMI_CODE_HOME）。magpie 添加一个名为 magpie 的供应商，类型是 Kimi 自己的，写入网关地址和一个专用 Key，再为每个模型写一张 [models."magpie/<provider>/<model>"] 表，于是 magpie 的模型出现在 kimi 的 /model 选择器里，然后把 default_model 设为你选的模型。思考内容以 reasoning_content 双向传递，网关把每个请求翻译给该模型的供应商。旧版 Python kimi-cli 只在没有 Kimi Code 文件夹时写入 ~/.kimi（$KIMI_SHARE_DIR），因为 Kimi Code 接手后只读 ~/.kimi-code。WSL 里的 Kimi Code 也一样设置。

接入 Kimi Code

  1. 在 magpie 里添加供应商在 供应商 页添加 API Key，或登录一个订阅。
  2. 在 Kimi Code 那一行选模型在 Agent 页，选 magpie 下的一个模型。
  3. 在 kimi 里使用Kimi Code 运行中就会读到改动，magpie 的每个模型也都在 /model 里。
终端
magpie kimi deepseek/deepseek-v4-pro    # Kimi Code 用 DeepSeek
magpie kimi                             # 查看 Kimi Code 当前的模型

每个模型写了什么

  • 名称和上下文kimi 选择器和状态栏显示的名称，以及 max_context_size，让 kimi 及时压缩上下文。
  • 思考档位有档位的模型写入 thinking，并带上 support_efforts 和 default_effort，供 Kimi Code 的思考选择器使用。总在思考的模型写入 always_thinking。
  • 图片和工具支持图片的模型写入 image_in，Kimi Code 上写入 tool_use，magpie 知道回复上限的模型写入 max_output_size。

你在 magpie 的模型表里亲手设的值，比如 default_effort，下次同步时会保留。

何时生效

Kimi Code 2.x 会监视配置文件，所以已打开的会话立即就有新模型。在它的网页版或桌面版里，重新打开 Settings › Providers 或刷新页面，选择器里才会出现。旧版 kimi-cli 在启动时读取配置：要重启已打开的 kimi 会话。

你自己的设置

你的 Kimi Code 登录、你自己的供应商和模型都原样保留，并和 magpie 的模型一起列在 Kimi Code 那一行。你在 magpie 供应商表里加的键，比如 custom_headers 或 env，也会保留。你原来的 default_model 会先存起来，之后放回。

切回

在这一行选你自己的模型、把这一行从 magpie 移除，或运行 magpie kimi default。magpie 会放回你原来的默认模型（如果 Kimi 里还有它），再删掉它的模型表和供应商。

常见问题

Kimi Code 能用 Kimi 以外的模型吗？

能。你在 magpie 里的任何模型都在 kimi 的 /model 列表里：DeepSeek、GLM、Qwen、GPT、Claude 等等。

Kimi Code 能用我的 ChatGPT 订阅吗？

能。在 magpie 里登录 ChatGPT，在 Kimi Code 那一行选 magpie 下的一个 GPT 模型。kimi 把请求发给 magpie，由 magpie 使用订阅。

旧版 Python kimi-cli 能用吗？

能。没有 ~/.kimi-code 时，magpie 写入 kimi-cli 的 ~/.kimi，不写只有 Kimi Code 才认的键。改动后要重启已打开的会话。

WSL 里的 Kimi Code 能用吗？

能。magpie 也会设置 WSL 发行版里的 Kimi Code，供应商指向发行版能访问到的网关地址。

更多 Agent 用同样的模型：OpenCode 接入其他模型、Claude Code 接入其他模型、让 Qwen Code 用任意模型、让 Pi 用任意模型。遇到报错？见 常见错误排查，或到 Discord 提问。
