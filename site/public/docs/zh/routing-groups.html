Routing groups

两层路由 一个供应商的多个账号或 Key 路由方式 会话保持 路由组 命令行 现成的组

文档 · 指南

多个账号、Key 和供应商轮询与故障切换

一个 Claude 订阅不够用、一个 API Key 老被限流，或者想让 DeepSeek 挂了时自动换到别家？magpie 在两层上路由请求：一个供应商的多个账号或 Key 之间，以及多个供应商、多个模型组成的路由组之间。回复还没开始发给 Agent 时上游出错，magpie 就换下一个候选，Agent 不会察觉。

一个供应商的多个账号或 Key

给同一个供应商加上第二个账号或第二个 Key 并打开后，它的编辑页会多出 路由 和 会话保持 两项，决定请求在这些账号或 Key 之间怎么分。

被限流（429）但还有额度的那个怎么办，也可以选：保持原位：休息到供应商要求的时间，再回到原来的位置；排到最后：排到所有没被限流的后面，让负载轮转起来，而不是每次都回到第一个。

路由方式

  • 智能（默认）：第一个在额度充足时接请求，额度快用完时由剩得最多的接手。没余额的歇半小时，额度用完的歇到重置，被限流的歇到供应商要求的时间，出错的歇一分钟，再错就更久。
  • 按顺序：请求都发给第一个，它额度用完、被限流或出错时由下一个接手。
  • 轮流：会话的每一轮交给下一个，均摊负载；一轮之内的请求留在开始的地方，提示缓存不失效。
  • 用量少的优先：订阅按已用额度的比例，Key 按最近几小时用掉的 token。
  • 重置前用完：交给本周剩余额度按小时算最多的订阅，让每周重置时浪费得最少；用到 90% 以上的，等别的都答不了才用。
  • 按权重：按每个 Key 旁边设的权重分，权重 3 的接 3 个请求，权重 1 的接 1 个。只有 Key 能用，账号不行。
  • 免费优先：先用不占额度、不花钱的模型，它们答不了时才用花钱的。

会话保持

会话保持 决定一段对话是否留在答过它的那个账号或 Key 上：

  • 自动（默认）：在供应商为它缓存的内容还值得保留时留下，一轮之内总是留下。
  • 整个会话：整个会话都留在那里，只要它还能答。
  • 一轮之内：Agent 发回工具结果时不动，你再说话时重新路由。
  • 关闭：每个请求都重新路由。
  • 严格：永远不换，哪怕它被限流或额度用完，错误直接交给 Agent。新会话照常路由。

路由组

路由组把不同供应商的模型放在一起，比如官方 Claude 订阅里的 Opus 和 Copilot 里的 Opus，或者几个免费模型。Agent 选 group/<id> 作为模型，magpie 按组的路由方式和规则决定每个请求交给谁。组在 路由 页的 路由组 里，用 新建组 创建。

  1. magpie 自己会找组两个及以上供应商都提供的模型，自动成为一个组（auto-<模型>），不用设置。不想要可以关掉 自动创建路由组。
  2. 组里放什么任意模型，用 provider/model 写；也可以放另一个组（最多 8 层），或者用通配符：openrouter/*:free 会把以后新出的免费模型也加进来。
  3. 组的路由方式除了上面几种，组还有 按权重（按每个模型的权重）和 手动（只用你选的那个，不切换）。
  4. 规则可以按一轮的长度、是否带图、要求的推理强度或 Agent，决定一轮先交给哪个模型。

组还能定推理强度：每个成员可以写死 :high 这类强度；或者让分类模型在每轮开始时判断难度，再决定 low 到 xhigh。

命令行

终端
magpie groups                       # yours, then those magpie found
magpie group add "Opus anywhere" models=claude/claude-opus-5-5,copilot/claude-opus-5.5 routing=order
magpie group set opus-anywhere stays=session models+=openrouter/anthropic/claude-opus-5.5
magpie group set opus-anywhere routing=weight weight=claude/claude-opus-5-5=3
magpie group add my-free-pool models='openrouter/*:free,opencode-zen/*-free' routing=order
magpie group pick opus-anywhere copilot/claude-opus-5.5
magpie claude group/opus-anywhere

路由方式写法：smart、order、rotate、usage、pace、weight、manual；会话保持写法：auto、session、turn、off、strict。magpie group help 列出全部字段。

现成的组

magpie group template 用你自己的模型一次建好常用的组：

  • smart：难的一轮给最强的模型，简单的给便宜的，由分类模型区分。
  • thrifty：先用便宜模型，要高推理或便宜的都失败时才用最强的。
  • steady：最多三个供应商各自最强的模型，一个接一个兜底。
终端
magpie group template            # lists smart, thrifty, steady and the models each would take
magpie group template steady

想在用完前看到每个账号还剩多少，见 查看 Claude、Codex 等订阅的剩余额度。

常见问题

多个 Claude 账号能轮流用吗？

能。把账号都加到同一个 Claude 订阅里，编辑页出现 路由 后选 轮流 或 用量少的优先；一个额度用完时请求自动交给下一个。

API Key 被限流（429）时会怎样？

被限流的 Key 休息到供应商要求的时间，请求交给同一供应商的其他 Key；选 排到最后 则让它排到队尾，负载轮转。

DeepSeek 挂了能自动换别的模型吗？

能。建一个路由组，把 DeepSeek 和备用模型按顺序放进去，路由方式选 按顺序，Agent 选 group/。回复开始前上游出错就换下一个。

切换账号会让提示缓存失效吗？

会话保持 默认 自动：缓存还值得保留时对话留在原账号，一轮之内总是留下，所以轮转不会每个请求都丢缓存。
