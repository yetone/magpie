magpie、CC Switch 与 Claude Code Router 对比

magpie、CC Switch 和 Claude Code Router（CCR）都能让 AI 编程工具用上你选的服务商和模型。三者有重叠，也各有所长。本页把它们放在一起比较：另外两个工具的信息只取自它们自己的 README，magpie 的信息取自它的源码。

CC Switch

基于 Tauri 2 的桌面应用，管理 Claude Code、Codex、Gemini CLI、OpenCode、OpenClaw、Hermes、Pi、Kimi Code 等十二个工具。切换服务商时只改写配置里的关键字段，首次写入前先备份；各工具的 MCP、Skills 和提示词也在同一处管理。可选的本地路由模式会转换 API 格式，并按队列故障转移。内置 90 多个服务商预设。

Claude Code Router

本地模型网关和控制台，地址 127.0.0.1:3456。Claude Code、Codex、Kimi CLI、Kilo Code、OpenCode、Pi 等通过 Agent 配置接入同一个稳定端点，再由路由规则决定每个请求的去向：按请求头和请求体的条件、改写、重试、凭据池和有序的备用模型。它还能给模型加上视觉、联网搜索、MCP、浏览器自动化等能力，并记录每个请求及其费用。有桌面应用、带网页界面的 npm 命令行和 Docker 三种形式。

magpie

菜单栏（托盘）应用，带主窗口、TUI 和命令行。它让每个工具连到本机 127.0.0.1:3425 的网关，网关支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Gemini 并双向转换，所以任何工具都能用任何模型，包括 Claude、ChatGPT、GitHub Copilot 或 Gemini 的订阅登录。一个模型背后可以放多个密钥和账号，在工具看到报错前就切到下一个。

怎么选

  • CC Switch 适合主要手动给每个工具切换服务商、希望配置保持自己写的样子的人，也适合想在一个应用里管理所有工具的 MCP、Skills 和提示词的人。它的服务商预设是三者里最多的，还支持另外两个没列出的 Claude Desktop、OpenClaw 和 Oh My Pi。
  • Claude Code Router 适合想要一个可编程网关的人：按请求头和请求体的规则、改写请求、凭据池、带独立额度的客户端密钥，以及每个请求的日志和费用。它还能给缺少能力的模型加上联网搜索、浏览器自动化等工具，并可通过 npm 或 Docker 无界面运行。
  • magpie 适合同时用多个工具、想让每个工具用不同模型的人，比如 Codex 用 DeepSeek、Claude Code 用 Kimi，或者在别的工具里用 Claude、ChatGPT 订阅。所有工具都走同一个会转换协议的网关，一个模型可以由多个账号轮流服务并自动转移。

它们也可以同时使用。magpie 的网关是兼容 OpenAI、Anthropic 和 Gemini 的端点，支持自定义 Base URL 的工具都能把它当作一个服务商。

常见问题

CC Switch 有什么替代？

magpie 和 Claude Code Router 都覆盖了 CC Switch 的一部分功能。magpie 给每个工具切换模型，让所有工具走同一个会转换协议的网关，并支持订阅登录和故障转移；Claude Code Router 是可编程的本地网关，有路由规则和请求日志。

claude-code-router 有什么替代？

如果主要想给每个工具切换服务商、保持配置原样，可以用 CC Switch；如果想要一个服务多个工具、支持 Claude、ChatGPT、Copilot 或 Gemini 登录且账号能自动转移的转换网关，可以用 magpie。

CC Switch 和 claude-code-router 有什么区别？

据它们的 README，CC Switch 是桌面管理工具，改写每个工具的配置，并提供可选的本地路由代理；Claude Code Router 是位于 127.0.0.1:3456 的本地网关，工具通过 Agent 配置接入，按规则路由每个请求。

magpie 会像 CC Switch 一样改写工具的配置吗？

它只改每个工具配置文件里需要改的那一项，保留注释和顺序，让工具指向 127.0.0.1:3425 的网关。重新选回工具自己的模型，原来的值就会恢复。

magpie 是像 claude-code-router 那样的代理吗？

是的，magpie 也运行本地网关。它支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Gemini 并在它们之间转换，所以只支持 Responses 的 Codex 和只支持 Messages 的 Claude Code 都能用任何服务商的模型。

三个都是免费开源的吗？

是的。magpie、CC Switch 和 Claude Code Router 都以 MIT 许可证发布。
