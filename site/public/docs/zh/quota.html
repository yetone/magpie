Quota

一次看全部 magpie quota 给脚本和 Agent 用 用量提醒 等额度恢复 历史 Codex 账号的重置

文档 · 指南

查看 Claude、Codex 等订阅的剩余额度

Claude 的 5 小时窗口还剩多少？Codex 这周的额度什么时候重置？DeepSeek 的余额够不够？magpie 向各家供应商查询，把每个订阅、计划的每个窗口的用量和重置时间，以及每个 Key 的余额放在一起。在 用量 页能看到，命令行和本地接口也能读。

magpie quota

magpie quota 列出 magpie 里每个订阅、计划和 Key 剩下的部分：每个窗口用了多少、什么时候重新开始，以及每个 Key 的余额。数据是当场向供应商查询的（或不到一分钟前查过的）。后面跟供应商名只看那几个。

终端
magpie quota                       # every subscription, plan and key
magpie quota codex claude --json   # for scripts and agents
magpie quota refresh claude        # read one card again
magpie quota history --days 7 --json
  • --json 给脚本和 Agent 用，每一项带 lastServedAt（它最后一次通过网关应答的时间），最近应答过的那一项标 last: true。
  • magpie quota refresh 重新查询一张卡片，和 用量 页上卡片的刷新按钮一样。30 秒内查过的不会再查。
  • Claude 账号的用量由 Claude Code 在应答或运行 /usage 时告诉 magpie；refresh 会在该账号自己的目录里运行 Claude Code 的 /usage 来读，普通的 magpie quota 不会这样做。

给脚本和 Agent 用

网关在本地接口上返回同样的内容（端口以 设置 里的网关地址为准）。只有在 magpie 开着局域网共享时，其他电脑才能访问，并以网关密钥作为 API Key（Authorization: Bearer 或 x-api-key）。

终端
curl http://127.0.0.1:3425/v1/magpie/quotas
curl 'http://127.0.0.1:3425/v1/magpie/quotas/history?days=7&provider=codex'

magpie 的官方技能 magpie-quota 让 Agent 读 magpie quota --json，并用 magpie quota wait 等待额度恢复。它在 资源库 的技能市场里排在最前面。

用量提醒

让 magpie 应用在任意订阅或计划的某个窗口用到指定比例时发通知，每个窗口每次只提醒一次；或者在余额降到某个数以下时提醒，以它自己的货币或 credits 计，充值超过之前只提醒一次。两项默认都关闭，off 关掉。

终端
magpie quota alert 80              # notify at 80% used, once per window
magpie quota alert --balance 5     # notify when a balance falls to 5 or under
magpie quota alert                 # what is set

等额度恢复

magpie quota wait codex 等到 magpie 里任意一个已打开的 Codex 账号重新有额度时返回；写账号的邮箱或登录名，或 <provider>/<account>，只等那一个。它自己向供应商查询，网关没运行也行，在最近一次重置后不久再查（每 1 到 10 分钟），并在 stderr 上说明在等什么。脚本可以这样在额度用完后接着干：

终端
magpie quota wait codex --timeout 6h
until codex exec …; do magpie quota wait codex || break; done

退出码：有额度时 0，--timeout（如 30m、6h）先到时 1，名字不认识时 2，Ctrl+C 时 130。

历史

magpie quota history 是 magpie 读到的每个订阅和计划窗口随时间的记录，保留 45 天（UTC 时间，只在变化时记一次，每个窗口按重置时间分段）。不加参数显示每个窗口最近的读数，加 --json 则给出 --days 天以来的全部读数，和 /v1/magpie/quotas/history 的返回一样。

Codex 账号的重置

持有限额重置次数的 Codex 账号会显示有几次。

终端
magpie quota reset                 # spends one held reset; asks first
magpie quota auto-reset on
magpie quota credits off
  • magpie quota reset 用掉一次，让账号当前的窗口重新开始。不能撤销，所以会先问；--yes 不问。
  • magpie quota auto-reset on：每周窗口用完、又没有别的账号能接请求时，让账号自己用掉一次，每周最多一次（5 小时窗口用完从不会触发）；快过期的那次会在过期前约半小时用掉（如果账号的窗口用过）。默认关闭。
  • magpie quota credits off：窗口用完后不让 Codex 账号花 credits，路由把它当作用完，请求交给其他账号、组和备用。默认 on，任务能继续。

常见问题

怎么查看 Claude Code 剩余的 5 小时和每周额度？

运行 magpie quota，或打开 magpie 的 用量 页。Claude 账号的用量在 Claude Code 应答或运行 /usage 时更新；magpie quota refresh claude 会运行 /usage 重新读取。

Codex 额度用完后能自动继续吗？

能。脚本里用 until codex exec …; do magpie quota wait codex || break; done，额度恢复后 magpie quota wait 返回，命令接着跑。

用量快满时能提醒吗？

magpie quota alert 80 会在任意窗口用到 80% 时由 magpie 应用发通知；--balance 5 在余额降到 5 以下时提醒。默认都关闭。

Agent 能自己读额度吗？

能。magpie quota --json 或 GET http://127.0.0.1:3425/v1/magpie/quotas 返回同样的数据；官方技能 magpie-quota 教 Agent 读它并等待额度恢复。
