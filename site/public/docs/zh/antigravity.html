让 Antigravity 用任意模型

Antigravity 是 Google 的 Agent 应用，可以通过 Enterprise Gateway 设置把请求发给你自己的网关，而不是 Google。magpie 就是这样的网关，于是 Antigravity 和它的 CLI agy 能用你在 magpie 里的任何模型：DeepSeek、GLM、Qwen、OpenAI 或 Anthropic Key，或 ChatGPT、Copilot 订阅。

Antigravity 2.15 及以后从设置文件读取 gateway 配置：2.29 及以前是 ~/.antigravity/settings.json，2.30 起是 ~/.gemini/config/config.json。magpie 写入并启用这段配置，填上网关地址、一个标明该应用的 Key 和 openai 协议，再把 models.defaultModelId 设为你选的模型。之后应用在选择器里列出网关的模型，把对话发给 magpie，magpie 再翻译给该模型的供应商。你自己的网关、默认模型、模型列表和目录都会另存，magpie 退出时还原。

接入应用

  1. 在 magpie 里添加供应商在 供应商 页添加 API Key，或登录一个订阅。
  2. 在 Antigravity 那一行选模型在 Agent 页，选 magpie 下的一个模型。
  3. 重启 Antigravity它在启动时读取网关，之后 magpie 的模型就在它的模型选择器里。
终端
magpie antigravity deepseek/deepseek-v4-pro    # 应用用 DeepSeek
magpie agy deepseek/deepseek-v4-pro            # agy 用 DeepSeek

它的模型

选择器列出网关的模型，即应用的 Key 能看到的那些，名称来自 magpie 的目录。应用自己会给不认识的模型一律设 200K 窗口。magpie 把它的 models.listSource 指向网关的目录，为每个模型给出真实的上下文窗口，长会话会在该压缩时压缩。

推理强度

目录按每个推理档位列出模型，所以应用自己的选择器能选档位，选中的档位随请求发出。magpie 那一行的强度是应用启动时的档位，也是选择器里没有档位的模型所用的强度。保持默认时，请求按应用发出的原样转发。

你的 Google 登录

走网关时，Antigravity 不使用 Google 登录，它的后端也不再请求 Google。Google 为你的账号开启的功能，包括实验功能和 /boost、/teamwork、/plugin、/generative_ui 等命令，在接入 magpie 期间不可用。把那一行从 magpie 取消即可恢复。

agy CLI

除非在自己那一行接入，agy 会跟随应用的网关。在自己那一行接入时，它通过 Gemini API 使用 magpie：magpie 把它的模型放在 magpie-settings.json，与 agy 自己的 ~/.gemini/antigravity-cli/settings.json 并排，并在启动 agy 时为这次会话带上该文件、GOOGLE_GEMINI_BASE_URL、GEMINI_API_KEY 和 --model。为了让直接输入 agy 就能用，agy 使用 magpie 模型期间，magpie 会在每个 shell 的配置文件里添加一个名为 agy 的函数。之前已打开的终端，请用那一行给出的命令。你的 settings.json 保持不变，所以 agy remote-control 仍然用你的 Google 登录。

优先的设置

组织安装的 admin_settings.json 和 AGY_LLM_GATEWAY_* 环境变量会逐项覆盖设置文件。如果其中任何一个设了自己的网关，Antigravity 就到不了 magpie，那一行会提示。

切回

在那一行选你自己的模型，或把那一行从 magpie 取消。magpie 会还原你自己的网关、默认模型、模型列表和目录；对 agy 还会移除 shell 函数。然后重启 Antigravity。

常见问题

Antigravity 能用 Gemini 以外的模型吗？

能。你在 magpie 里的任何模型都在它的选择器里：DeepSeek、GLM、Qwen、GPT、Claude 等。

还需要登录 Google 吗？

不需要。走网关时 Antigravity 不使用 Google 登录。Google 为你账号开启的 /boost、/teamwork 等功能，在接入 magpie 期间不可用。

为什么每个模型都显示 200K 上下文？

这是应用对不认识的模型的默认值。magpie 把它的目录指向网关，为每个模型给出真实窗口。接入后请重启 Antigravity。

agy CLI 也能用吗？

能。agy 跟随应用的网关，或在自己那一行通过 Gemini API 接入，并有一个 agy shell 函数让命令直接可用。

更多 Agent 用同样的模型：OpenCode 接入其他模型、Gemini CLI 接入其他模型、让 Cursor Private Inference 用任意模型、让 Snow CLI 用任意模型。遇到报错？见 常见错误排查，或到 Discord 提问。
