Fireworks

是什么 Fireworks 按量付费 Fireworks Nexus 在 Nexus 里用 Claude 和 GPT 几点说明

文档 · 指南

Fireworks 与 Fireworks Nexus 接入 Claude Code、Codex 等 Agent

Fireworks 托管开源模型，按量付费；Fireworks Nexus 是它单独的账号和套餐，在 nexus.fireworks.ai 开通，由 Nexus Auto 替你选模型。magpie 两个都有预设：fireworks 和 fireworks-nexus。

Fireworks 按量付费

  1. 拿一把 Key。在 app.fireworks.ai 的 Settings → Users → API Keys 里生成。
  2. 添加。在应用里选 Fireworks，把 Key 填进 API 密钥，或者在命令行：
终端
magpie provider add fireworks fw_…
magpie provider test fireworks
magpie claude fireworks/

预设只走 Chat Completions，地址是 https://api.fireworks.ai/inference/v1，模型列表和价格来自 models.dev 的 fireworks-ai。Claude Code 的 Anthropic 请求和 Codex 的 Responses 请求由 magpie 转成 Chat 发给 Fireworks。

Fireworks Nexus

Nexus 的 Key 要在 nexus.fireworks.ai 生成，和 Fireworks 平台的 Key 不是一回事。它的 /inference 接口同时说 Chat Completions、Responses 和 Anthropic Messages，所以 Codex 和 Claude Code 的请求按各自的协议直接发过去。

终端
magpie provider add fireworks-nexus fw_…
magpie codex fireworks-nexus/auto
magpie claude fireworks-nexus/auto

Pro 和 Team 套餐只接受 auto，也就是 Nexus Auto；直接点名一个开源模型会被 403 拒绝。所以这个预设的模型列表就只有 auto。Enterprise 账号能用的开源模型，要在供应商的模型里自己填上 id。

在 Nexus 里用 Claude 和 GPT

Nexus Auto 要用到 Claude 和 GPT 时，用的是你自己的 Key：放在 x-anthropic-api-key 和 x-openai-api-key 两个请求头里，或者在 Nexus 账号上配置 Provider Keys。在 magpie 的供应商编辑器里，请求头 会直接提供这两个名字，值由你来填；命令行是：

终端
magpie provider set fireworks-nexus header.x-anthropic-api-key=sk-ant-…
magpie provider set fireworks-nexus header.x-openai-api-key=sk-…

自己加的请求头每次请求都会带上。值留空就是删掉这个请求头。

几点说明

  • Agent 只连 magpie，不拿 Fireworks 的 Key，也不知道它的地址。
  • Fireworks 可以和其他托管同一批开源模型的供应商放进同一个路由组，一个出错了，组里的下一个接着回答。
  • Nexus 的套餐和额度以 Fireworks 自己的页面为准，这一页只写 magpie 怎么接。

常见问题

magpie 支持 Fireworks AI 吗？

支持。fireworks 预设填一把 Fireworks 的 API Key，走 api.fireworks.ai/inference/v1 的 Chat Completions，模型 id 写成 fireworks/<模型>。

Fireworks Nexus 和 Fireworks 有什么不同？

Nexus 是单独的账号和套餐，Key 在 nexus.fireworks.ai 生成。它的接口同时支持 Chat、Responses 和 Messages，模型由 Nexus Auto 选，Pro 和 Team 只能用 auto。

为什么 Nexus 只列出 auto？

Pro 和 Team 套餐直接点名开源模型会被 403 拒绝，只接受 auto。Enterprise 账号可以在供应商的模型里自己填上开源模型的 id。

Nexus 里怎么用 Claude 和 GPT？

把你自己的 Anthropic 和 OpenAI Key 放进 x-anthropic-api-key 和 x-openai-api-key 两个请求头，或者在 Nexus 账号上配置 Provider Keys。
