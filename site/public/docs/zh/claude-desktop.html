让 Claude Desktop 用任意模型

Claude Desktop 有第三方网关模式：不用登录 Anthropic，Code 和 Cowork 在任何套餐下都能用。magpie 把 Desktop 设成这个模式并指向 magpie 的网关，于是 Desktop 能用你在 magpie 里的任何模型：DeepSeek、Kimi、GLM、Qwen、OpenAI Key，或 ChatGPT、Copilot 订阅。

网关模式下，Claude Desktop 把所有请求发到一个地址，而不是 Anthropic。magpie 在 Desktop 的配置目录里写入这个模式和一个名为 magpie 的配置，指向它的网关 http://127.0.0.1:3425。网关使用 Anthropic 的 Messages 接口，把每个请求翻译给你选的模型，流式输出、工具调用和推理都保留。macOS、Windows（含应用商店版）和 Linux 都支持。

开启

  1. 在 magpie 里添加供应商在 供应商 页添加 API Key，或登录一个订阅。
  2. 在 Claude Desktop 那一行选 magpie在 Agent 页，Claude Desktop 一行可以选 magpie：Desktop 的第三方网关，Code 和 Cowork 用 magpie 的模型，无需登录 Anthropic。
  3. 退出并重新打开 Claude DesktopDesktop 只在启动时读取这些设置。
终端
magpie claude-desktop magpie      # Desktop 走 magpie 网关
magpie claude-desktop default     # 切回 Anthropic 登录

选择模型

Desktop 启动时会读取网关的模型列表，所以它的模型选择器里就是你在 magpie 里的模型。上下文达到 1M 的模型只列一项，即它的 1M 版本。在 magpie 里新增供应商后，退出并重新打开 Desktop 才能看到它的模型。

Code 标签页的分档

Code 标签页运行的是 Claude Code，它按分档要模型：opus、sonnet、haiku。不设置时，分档用对话的模型。在 Claude Desktop 那一行或终端里为分档选模型，改动后重启 Desktop：

终端
magpie claude-desktop sonnet deepseek/deepseek-v4-pro
magpie claude-desktop haiku deepseek/deepseek-v4-flash

选中的模型会使用该分档对应 Claude 模型的提示词。这一行还有子代理模型，改了无需重启。

原来的对话和项目

Desktop 的网关模式用的是单独的配置目录，所以接入 magpie 时，看不到 Anthropic 登录下的对话和项目。什么都不会删除，切回后它们就回来了。想在 magpie 上继续用，可以在 Desktop 里打开 Settings → Import，它会复制你的 Claude.ai 对话和项目，原件保持不变。

独立的 Claude Magpie 应用（Mac）

在 Mac 上，magpie 可以让 Desktop 的网关模式运行在单独的目录里，由 ~/Applications/Claude Magpie.app 启动。你自己的 Claude Desktop 保持 Anthropic 登录，两者可以同时运行。默认关闭。

终端
magpie claude-desktop launcher add      # 创建 Claude Magpie.app
magpie claude-desktop launcher remove

切回

在 Claude Desktop 那一行取消 magpie，或运行 magpie claude-desktop default，然后退出并重新打开 Desktop。magpie 会把 Desktop 的文件恢复原样，之前的对话也会回来。

常见问题

用 Cowork 和 Code 需要 Claude 订阅吗？

不需要。网关模式下，Desktop 的 Code 和 Cowork 不用登录 Anthropic，使用 magpie 提供的任意模型。

能在 Claude Desktop 里用 ChatGPT 订阅吗？

能。在 magpie 里登录 ChatGPT，重启 Desktop 后，GPT 模型就会出现在它的模型选择器里。

为什么 Claude Desktop 里看不到新模型？

Desktop 只在启动时读取模型列表。退出并重新打开它。

为什么接入 magpie 后 Claude Desktop 变成了英文？

Desktop 网关模式的界面本身没有中文翻译。切回 Anthropic 登录后，中文就会回来。

原来的对话没了吗？

没有。它们留在 Desktop 原来的配置里，切回后就会回来；也可以用 Settings → Import 导入。

在终端里用同样的模型：Claude Code 接入其他模型、在 Claude Code 中使用 ChatGPT 订阅。遇到报错？见 常见错误排查，或到 Discord 提问。
