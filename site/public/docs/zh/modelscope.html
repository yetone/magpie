魔搭 ModelScope 接入 Claude Code 和 Codex

魔搭（ModelScope）的 API-Inference 用 ModelScope 账号的访问令牌（Access Token）作 Key，提供 Qwen、GLM 等模型，接口是 Chat Completions 和 Responses。在 magpie 里添加魔搭，Claude Code、Codex、Gemini CLI、OpenCode 就都能通过本地网关 127.0.0.1:3425 用上这些模型。

添加魔搭

  1. 添加供应商在 供应商 页点 ＋ 添加供应商，选 ModelScope，把 ModelScope 的访问令牌当 Key 粘贴 Key 并保存。
  2. 给工具选上在 Agent 页给某个工具选 Qwen/Qwen3-Coder-30B-A3B-Instruct 这类模型。
终端
magpie claude modelscope/Qwen/Qwen3-Coder-30B-A3B-Instruct
magpie codex modelscope/ZhipuAI/GLM-4.6
magpie opencode modelscope/Qwen/Qwen3-235B-A22B-Instruct-2507

接口与令牌

接口地址
Chat Completionshttps://api-inference.modelscope.cn/v1
Responseshttps://api-inference.modelscope.cn/v1

Key 是 ModelScope 账号的访问令牌，在 modelscope.cn/my/myaccesstoken 创建。魔搭不是阿里云百炼的 DashScope：百炼的 Key 用在 通义千问 供应商里，两者互不通用。手动添加、地址是 api-inference.modelscope.cn 的供应商，magpie 也认作魔搭。

模型

魔搭的模型名带组织前缀，原样写：Qwen/Qwen3-Coder-30B-A3B-Instruct、Qwen/Qwen3-235B-A22B-Instruct-2507、Qwen/Qwen3-235B-A22B-Thinking-2507、ZhipuAI/GLM-4.6、ZhipuAI/GLM-4.5 等。magpie 用 models.dev 的 modelscope 目录给出名字和上下文长度。命令行里写成 modelscope/ 加模型名。

在各个工具里用

  • Claude Code 说的是 Anthropic Messages，这家不提供这个接口。magpie 把每个请求转换成 Chat Completions，再把回复转换回来，思考内容也会显示在 Claude Code 里。Claude Code 接入国产模型。
  • Codex 说的是 OpenAI Responses。这家也提供 Responses，Codex 的请求原样转过去。Codex 接入第三方模型。
  • Gemini CLI 说 Gemini 的接口，magpie 转换成 Chat Completions。Gemini CLI 接入其他模型。
  • OpenCode 说 Chat Completions，请求原样发过去。OpenCode 接入其他模型。

画图

魔搭的画图接口是它自己的异步任务：先提交任务拿到 task_id，再查询到成功或失败。它每个用户同时只跑一个任务，突发请求会回 429，所以 magpie 一次只画一张，忙的时候稍等再试，再把结果变成工具能读的图片。

常见问题

魔搭 ModelScope 怎么接入 Claude Code？

在 magpie 里添加 ModelScope，把访问令牌当 Key 粘贴，在 Claude Code 那一行选 Qwen/Qwen3-Coder-30B-A3B-Instruct 这类模型，或运行 magpie claude modelscope/Qwen/Qwen3-Coder-30B-A3B-Instruct。魔搭没有 Anthropic 接口，magpie 把请求转换成 Chat Completions。

魔搭的 Key 在哪里拿？

魔搭用 ModelScope 账号的访问令牌，在 modelscope.cn/my/myaccesstoken 创建，粘贴到 magpie 的 ModelScope 供应商里。

魔搭和阿里云百炼 DashScope 是一回事吗？

不是。魔搭 API-Inference 在 api-inference.modelscope.cn，用 ModelScope 访问令牌；百炼 DashScope 用阿里云的 Key，在 magpie 里是通义千问供应商。

魔搭能在 Codex 里用吗？

能。魔搭提供 Responses，magpie 把 Codex 的请求原样转过去。运行 magpie codex modelscope/ZhipuAI/GLM-4.6。

同一套方法用在其他国产模型：硅基流动、火山方舟、GLM 编程套餐、Kimi、DeepSeek、通义千问。遇到报错？见 常见错误排查，或到 Discord 提问。
