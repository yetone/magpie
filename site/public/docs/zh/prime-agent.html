文档 · 指南

让 Prime Agent 用任意模型

Prime Agent 是 Prime Intellect 开源的 Rust 编程 Agent，命令是 prime-agent。它在自己的目录里保存和 Pi 一样的 settings.json 与 models.json，字段和类型也与 Pi 相同。magpie 像接入 Pi 一样接入它，Prime Agent 就能用 DeepSeek、GLM、Kimi、Qwen、Claude 或 ChatGPT 订阅等 magpie 里的任意模型。

接入 Prime Agent

  1. 在 magpie 里添加供应商在 供应商 页添加 API Key，或登录一个订阅。
  2. 在 Agent 页给 Prime Agent 选模型选一个 via magpie 的模型。
  3. 运行 prime-agent新会话从这个模型开始，magpie 的模型都在它的模型列表里。
终端
magpie prime-agent deepseek/deepseek-v4-pro

写了哪些内容

终端
~/.prime/agent/            （或 $PRIME_AGENT_CODING_AGENT_DIR）
  settings.json            defaultProvider: "magpie"
                           defaultModel:    "deepseek/deepseek-v4-pro"
                           defaultThinkingLevel
  models.json              providers.magpie: 网关的 /v1，
                           Key magpie-prime-agent，magpie 的模型

magpie 在 models.json 里加一个名为 magpie 的供应商，指向网关的 /v1，带上 magpie 的模型。在 settings.json 里设置 defaultProvider、defaultModel 和 defaultThinkingLevel。你自己的供应商和设置保持原样。

Prime Agent 的请求不带 User-Agent，所以 magpie 给它的 Key 是 magpie-prime-agent，网关靠这个 Key 把用量算到 Prime Agent 名下。

PRIME_AGENT_CODING_AGENT_DIR

Prime Agent 的目录默认是 ~/.prime/agent。设置了 PRIME_AGENT_CODING_AGENT_DIR 时用它，其中的 ~ 代表主目录。相对路径取决于 Prime Agent 的工作目录，magpie 无法知道，所以不采用，仍写 ~/.prime/agent。WSL 里的 Prime Agent 也能接入。

留给你的设置

magpie 只写全局的 settings.json，和 Pi 一样。这些都由你决定，magpie 不改：

  1. 项目里的 .prime/agent/settings.json项目级设置。
  2. allowedModels守护进程的允许列表；不在列表里的模型会直接报错。
  3. subagentDefaultModel子 Agent 的默认模型。

所以如果你设了 allowedModels，记得把 magpie 的模型加进去。

切回

在 Prime Agent 那一行选回你自己的模型，或运行下面的命令。magpie 在第一次写入前备份了这两个文件；如果之后没有改动，就原样恢复，否则只删掉 magpie 的供应商。

终端
magpie prime-agent default

常见问题

Prime Agent 能用 DeepSeek 或 GLM 吗？

能。在 magpie 的 Agent 页给 Prime Agent 选一个 via magpie 的模型，magpie 在 models.json 里加上 magpie 供应商，DeepSeek、GLM、Kimi、Qwen、Claude 都能用。

magpie 写在哪个目录？

默认 ~/.prime/agent；设置了 PRIME_AGENT_CODING_AGENT_DIR 就写在那里（~ 会展开）。相对路径不采用。

选了 magpie 的模型却报错不允许？

你的 allowedModels 里没有这个模型。magpie 不改这个列表，把模型加进去即可。

magpie 怎么认出 Prime Agent 的请求？

靠 magpie 给它的专用 Key magpie-prime-agent，因为它的请求不带 User-Agent。

更多 Agent 用同样的模型：让 Pi 用任意模型、让 Kimi Code 用任意模型、让 DS Bot 用任意模型。遇到报错？见 常见错误排查，或到 Discord 提问。
