PenguinHarness

工作原理 接入 PenguinHarness .project_config.toml 模型列表 不用重启 切回

文档 · 指南

让 PenguinHarness 用任意模型

PenguinHarness（Prism-Shadow/penguin-harness，penguin 命令，npm 包 @prismshadow/penguin-cli，也有桌面应用）把每个 Project 的模型存在一个 TOML 文件里。magpie 在里面加一个名为 magpie 的供应商和它的模型，PenguinHarness 就能用 DeepSeek、GLM、Kimi、Qwen、Claude 或 ChatGPT 订阅等 magpie 里的任意模型。CLI 和桌面应用读的是同一个文件。

接入 PenguinHarness

  1. 在 magpie 里添加供应商在 供应商 页添加 API Key，或登录一个订阅。
  2. 在 Agent 页给 PenguinHarness 选模型选一个 via magpie 的模型。正在运行的 PenguinHarness 立刻换过去，不用重启。
终端
magpie penguin deepseek/deepseek-v4-pro

.project_config.toml

文件在数据目录下：$PENGUIN_HOME，没有设置时是 ~/.penguin/data（所有系统都一样）。CLI 用的 Project 是 $PENGUIN_PROJECT_ID，没有设置时是 default_project，所以文件是 ~/.penguin/data/default_project/.project_config.toml。magpie 写入的内容：

终端
default_model = { provider = "magpie", model_id = "deepseek/deepseek-v4-pro" }

[providers.magpie]
base_url = "http://127.0.0.1:3425/v1"
client_type = "openai-responses"
api_key = ""

[[models]]
provider = "magpie"
model_id = "deepseek/deepseek-v4-pro"
display_name = "…"
context_window = …
vision = …
max_tokens = …

[models.pricing]
unit = "usd_per_mtok"
cache_read = …
cache_write = …
output = …

模型是供应商加 model_id 的一对，自己没写地址和 Key 的模型用所在供应商的。magpie 用 openai-responses 客户端：请求发到 base_url 加 /responses，思考强度作为 reasoning.effort 带上，openai-chat 客户端不带这个。你自己的供应商和模型原样保留。文件不存在时 magpie 新建一个，权限只给你自己（里面有 Key），和 PenguinHarness 自己建的一样。WSL 发行版里的 PenguinHarness 也一样设置，数据目录是那边的 ~/.penguin/data。

模型列表

magpie 的每个模型都写成一条 [[models]]，带上 PenguinHarness 自己的模型页会记录的信息：显示名、上下文窗口、单次回复上限、能不能读图片，以及按每百万 token 计的价格。vision 总是写明，因为 PenguinHarness 默认认为模型能读图片。PenguinHarness 不接受指向不存在条目的 default_model，所以 magpie 先写模型再设默认，切回时先改默认再删模型。

不用重启

PenguinHarness 的服务在文件修改时间变化时重新读取，所以改动不用重启。它自己的模型页和 penguin config model … 会把整个文件写回去，magpie 写的每一项都是它认得的，不会被丢掉。没有新内容的同步不会碰文件，也不会改它的修改时间。

切回

第一次接入时，magpie 记下你原来的 default_model。切回时，如果 PenguinHarness 里还有这个模型就换回去；在 PenguinHarness 里选过的 magpie 图片模型（vision_model）一起去掉；然后删掉 magpie 的模型和 [providers.magpie]。如果文件是 magpie 新建的、最后什么都没剩，就把文件也删掉。

终端
magpie penguin default

常见问题

PenguinHarness 能用 DeepSeek、GLM 或 ChatGPT 订阅吗？

能。在 magpie 的 Agent 页给 PenguinHarness 选一个 via magpie 的模型，CLI 和桌面应用都会用上。

magpie 改的是哪个文件？

数据目录（$PENGUIN_HOME，默认 ~/.penguin/data）下当前 Project 的 .project_config.toml，默认 Project 是 default_project。

要重启 PenguinHarness 吗？

不用。它在文件修改时间变化时重新读取设置。

切回后原来的模型会恢复吗？

会。magpie 记下了原来的 default_model，PenguinHarness 里还有它就换回去，并删掉 magpie 加的供应商和模型。

更多 Agent 用同样的模型：让 Paimon 用任意模型、让 Muse Code 用任意模型、让 Prime Agent 用任意模型、让 MothX 用任意模型。遇到报错？见 常见错误排查，或到 Discord 提问。
