硅基流动接入 Claude Code 和 Codex

硅基流动（SiliconFlow）用一个 API Key 提供 DeepSeek、GLM、Kimi、Qwen 等开源模型，接口是 OpenAI 的 Chat Completions。Claude Code 要 Anthropic Messages，Codex 要 Responses，硅基流动都不提供；magpie 的本地网关 127.0.0.1:3425 在中间做转换，所以这些工具都能直接用硅基流动的模型。

添加硅基流动

  1. 添加供应商在 供应商 页点 ＋ 添加供应商，选 SiliconFlow，给 Key 选 China 或 Global，粘贴 Key 并保存。
  2. 给工具选上在 Agent 页给某个工具选 deepseek-ai/DeepSeek-V4-Pro 这类模型。
终端
magpie claude siliconflow/deepseek-ai/DeepSeek-V4-Pro
magpie codex siliconflow/zai-org/GLM-5.3
magpie opencode siliconflow/moonshotai/Kimi-K3

国内站与国际站

站点Chat Completions控制台
国内站（China）https://api.siliconflow.cn/v1cloud.siliconflow.cn
国际站（Global）https://api.siliconflow.com/v1cloud.siliconflow.com

国际站是另一个账号，Key 和余额（美元）都和国内站分开，国内站的 Key 在国际站用不了。供应商里的每个 Key 都标明自己的站点，两边的 Key 可以放在同一个供应商里。

模型

硅基流动的模型名带厂商前缀，原样写在 magpie 和工具里，比如 deepseek-ai/DeepSeek-V4-Pro、deepseek-ai/DeepSeek-V4-Flash、zai-org/GLM-5.3、moonshotai/Kimi-K3、moonshotai/Kimi-K2.7-Code、Qwen/Qwen3-Coder-480B-A35B-Instruct、meituan-longcat/LongCat-2.0。magpie 用 models.dev 的 siliconflow 目录给出名字、上下文长度和价格。命令行里写成 siliconflow/ 加模型名。

在各个工具里用

  • Claude Code 说的是 Anthropic Messages，这家不提供这个接口。magpie 把每个请求转换成 Chat Completions，再把回复转换回来，思考内容也会显示在 Claude Code 里。Claude Code 接入国产模型。
  • Codex 说的是 OpenAI Responses。这家不提供 Responses，所以 magpie 把请求转换成 Chat Completions；apply_patch 这类自定义工具以函数交给模型，调用再以 Codex 能执行的形式还回去。Codex 接入第三方模型。
  • Gemini CLI 说 Gemini 的接口，magpie 转换成 Chat Completions。Gemini CLI 接入其他模型。
  • OpenCode 说 Chat Completions，请求原样发过去。OpenCode 接入其他模型。

余额

硅基流动在 2026-08-14 停掉了查询余额的 /v1/user/info（返回 410），目前还没有替代的接口，以前的赠送余额也改成了代金券。所以 magpie 的用量卡片不再显示金额，而是说明余额在哪里看，按钮直接打开对应站点的控制台。Key 本身被拒（401）时，卡片照原样显示错误。

常见问题

硅基流动怎么接入 Claude Code？

在 magpie 里添加 SiliconFlow 并粘贴 Key，在 Claude Code 那一行选 deepseek-ai/DeepSeek-V4-Pro 这类模型，或运行 magpie claude siliconflow/deepseek-ai/DeepSeek-V4-Pro。硅基流动没有 Anthropic 接口，magpie 把 Claude Code 的请求转换成 Chat Completions。

硅基流动能在 Codex 里用吗？

能。硅基流动只有 Chat Completions，magpie 把 Codex 的 Responses 请求转换过去，apply_patch 等自定义工具也照常能用。运行 magpie codex siliconflow/zai-org/GLM-5.3。

国内站的 Key 能用在国际站吗？

不能。国际站 cloud.siliconflow.com 是另一个账号，Key 和余额都分开。在 magpie 里给每个 Key 选对 China 或 Global 即可。

magpie 为什么不显示硅基流动的余额？

硅基流动在 2026-08-14 停掉了余额查询接口，还没有新的接口。magpie 的卡片会带你去控制台看余额和代金券。

同一套方法用在其他国产模型：魔搭 ModelScope、火山方舟、GLM 编程套餐、Kimi、DeepSeek、通义千问。遇到报错？见 常见错误排查，或到 Discord 提问。
