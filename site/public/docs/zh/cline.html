Cline

工作原理 接入 Cline 模型和推理强度 VS Code 插件 桌面版 切回 常见问题

文档 · 指南

让 Cline 用任意模型

Cline 使用设置里的供应商和模型。magpie 把 Cline 内置的 OpenAI 兼容供应商指向 magpie 的网关，于是 Cline 的 CLI、VS Code 插件和桌面版都能用你在 magpie 里的任何模型：DeepSeek、Kimi、GLM、Qwen、OpenAI Key，或 ChatGPT、Copilot 订阅，不用往 Cline 里贴 Key。

Cline 的供应商存在 ~/.cline/data/settings/providers.json（或 $CLINE_DIR 下）。magpie 把 Cline 自带的 openai-compatible 供应商设成网关地址和一个 Cline 专用的 Key，设为当前使用的供应商，并在 models.json 里列出 magpie 的模型，替代这个供应商自带的唯一一个模型。原来的内容和你在用的供应商会被记下，切回时恢复。网关把每个请求翻译给该模型的供应商，工具调用和推理都保留。

接入 Cline

  1. 在 magpie 里添加供应商在 供应商 页添加 API Key，或登录一个订阅。
  2. 在 Cline 那一行选模型在 Agent 页，给 Cline 一行选一个模型。
  3. 开一个新的 Cline 会话Cline 在会话开始时读取供应商：已打开的会话保留原模型，新会话用这个。
终端
magpie cline deepseek/deepseek-v4-pro    # Cline 用 DeepSeek
magpie cline                             # 查看 Cline 当前的模型

模型和推理强度

这一行还能设置 Cline 请求的推理强度：none、low、medium、high 或 xhigh。none 关闭思考，和 Cline 自己的选择器一样。

终端
magpie cline effort high
magpie cline effort default    # 恢复 Cline 的默认

VS Code 插件

Cline 的 VS Code 插件用同一个目录，但优先读取它自己状态里的供应商、模型、地址和 Key：Act 和 Plan 模式的供应商和模型，以及 OpenAI 兼容的 Key。magpie 也会设置这些，并记下原来的值。插件只在启动时读取一次，所以改动后要在 VS Code 里运行 Developer: Reload Window。

桌面版

Cline 桌面版把你在输入框里选的模型和推理强度存在自己那里，不从这些文件读取。它的选择器里，magpie 下面就有 magpie 的模型：在那里选。magpie 的那一行设置的是 CLI 和 VS Code 插件。

切回

在 Cline 那一行取消 magpie，或运行 magpie cline default。magpie 会恢复你原来的供应商、模型列表，以及插件原来的设置。

常见问题

Cline 能用 ChatGPT 订阅吗？

能。在 magpie 里登录 ChatGPT，在 Cline 一行选一个 GPT 模型。Cline 把请求发给 magpie，由 magpie 使用订阅。

改了模型，Cline 还在用旧的？

会话会保留开始时的模型。开一个新会话；VS Code 插件需要重新加载窗口。

为什么 magpie 不给 Cline 加一个自己的供应商？

Cline 在会话开始时会拒绝它不认识的供应商，所以 magpie 用 Cline 内置的 OpenAI 兼容供应商。

Cline 桌面版能用吗？

能。它的选择器在 magpie 下列出了 magpie 的模型；在那里选模型，因为桌面版不从 Cline 的文件读取。

更多 Agent 用同样的模型：OpenCode 接入其他模型、Claude Code 接入其他模型、让 Hermes Agent 用任意模型、让 Goose 用任意模型、让 Zoo Code 用任意模型。遇到报错？见 常见错误排查，或到 Discord 提问。
