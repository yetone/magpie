Sync

是什么 同步哪些内容 开启同步 三种存储 某台电脑保留自己的设置 一次性备份和恢复

文档 · 指南

多台电脑同步 magpie 配置：WebDAV、S3、GitHub

在公司和家里各有一台电脑，或者换了新电脑时，不用把供应商、Key 和每个 Agent 的模型再配一遍。magpie 把它们存成一个加密文件，放在你自己的 WebDAV、S3 或私有 GitHub 仓库里，每台电脑都跟它保持一致。

同步哪些内容

  • 供应商（连同 Key）和给它们选的图标。
  • 设置、配置档、每个 Agent 的模型。
  • 资料库：指令集、MCP 服务器、技能和它们的文件。
  • 从 npm 或 git 加的插件，会在另一台电脑上装好；插件的登录不会带过去。
  • 网关密钥，加密后和设置一起同步。

订阅（Claude、ChatGPT 等账号）不在里面，要在每台电脑上各自登录；它们的模型选择和设置会同步过来，登录后就能看到。同步状态会列出还没登录的订阅。

开启同步

  1. 打开同步。在 设置 → 同步与备份 → WebDAV / S3 / GitHub 同步 里选一种存储，或者在命令行：
终端
magpie webdav on https://dav.jianguoyun.com/dav/ user=me@example.com
magpie s3 on s3://my-bucket/magpie endpoint=https://.r2.cloudflarestorage.com access-key-id=…
magpie github on github://owner/private-backups/settings branch=main
magpie github                   # where it syncs to and how the last sync went
  1. 每台电脑用同一个口令。文件在本机用口令加密后才上传，服务器上只有密文。
  2. 等它同步。网关运行时每 3 分钟同步一次。每台电脑只覆盖它读到的那个版本，两台电脑之间的修改会合并，不会丢。

三种存储

  • WebDAV：坚果云、Nextcloud、群晖等 WebDAV 服务器上的一个文件夹。
  • S3：AWS S3、Cloudflare R2、Backblaze B2、MinIO、Garage、NAS 或任何兼容 S3 的服务器。桶要先建好；自己搭的服务器和 MinIO 一般要加 path-style=yes。不支持条件写入的服务器也能用（比如阿里云 OSS），两台电脑同时写时，后一台会在下次同步时把自己的修改再合并上去。
  • GitHub：一个已有的私有仓库，用只有 Contents 读写权限的细粒度 Token。公开仓库会被拒绝，因为它的历史会让任何人拿到每个加密版本。每次更新是一个提交，仓库历史就是加密备份的历史。
终端
magpie s3 on s3://backups endpoint=http://nas.local:9000 path-style=yes access-key-id=…

在三种之间切换时，另外两种的设置和凭据会保留，方便切回来；同一时间只用一种。

某台电脑保留自己的设置

在一台电脑上改了 Agent 的模型，其他电脑会跟着改。如果同步改了某台电脑上的值，你又在那台电脑上改了回去，那台电脑就保留自己的：别的电脑的选择不再改它，它的选择也只留在它自己这里，其他内容照常同步。仅本机保留 列出这些字段，点 跟随其他电脑 就重新用同步的值。

一次性备份和恢复

不想开同步，只是搬到新电脑，就用加密备份文件：

终端
magpie backup                               # writes magpie.magpie-backup, asks for a passphrase twice
magpie backup --no-keys ~/b.magpie-backup   # no API keys in it
magpie restore magpie.magpie-backup         # on the other machine
magpie restore --no-agents b.magpie-backup  # agents left as they are

备份用 AES-256-GCM 在本机加密，密钥由口令经 PBKDF2-SHA256 派生，没有口令谁也读不了。恢复时同 id 的供应商被替换，其余的加上；Agent 的模型只设给那台电脑上装了的 Agent。

常见问题

magpie 能用坚果云同步配置吗？

能。在设置 → 同步与备份里选 WebDAV，填坚果云的 WebDAV 地址和账号，或者运行 magpie webdav on https://dav.jianguoyun.com/dav/ user=<账号>。每台电脑用同一个口令。

同步到云上安全吗？

文件在本机用你的口令加密后才上传，服务器上只有密文。GitHub 同步只接受私有仓库。

Claude、ChatGPT 订阅会同步吗？

不会，订阅要在每台电脑上各自登录。它们的模型选择和设置会同步，登录后就能看到。

不想同步，只想换电脑怎么办？

用 magpie backup 导出加密备份文件，在新电脑上用 magpie restore 恢复。加 --no-keys 可以不带 API Key。
