腾讯云 Token Plan 接入 Claude Code 和 Codex

腾讯云的模型都在 TokenHub 上：Token Plan 订阅（个人版和企业版）和按量付费。两者用不同的 Key：套餐是 sk-tp- 开头的套餐 Key，按量付费是 TokenHub 自己的 API Key。在 magpie 里添加一个腾讯云供应商，给每个 Key 选好套餐，Claude Code、Codex、Gemini CLI、OpenCode 和其他工具就都能通过本地网关 127.0.0.1:3425 用上混元、GLM、Kimi、DeepSeek 和 MiniMax。

添加腾讯云

  1. 添加供应商并选套餐在 供应商 页点 ＋ 添加供应商，选 Tencent Cloud，给 Key 选 Plan · China、Pay as you go · China、Pay as you go · Global、Enterprise plan · Global，粘贴 Key 并保存。
  2. 给工具选上在 Agent 页给某个工具选 tc-code-latest 或 glm-5.3 这类模型。
终端
magpie claude tencent-cloud/tc-code-latest
magpie codex tencent-cloud/glm-5.3
magpie opencode tencent-cloud/kimi-k3

个人版和企业版用同一组接口，套餐由 Key 决定。中国站的个人版和企业版是同一个地域，所以那里的模型是两种套餐的合集；新加坡只卖企业版。供应商里的每个 Key 都标明自己的套餐，按量付费和套餐的 Key 可以放在同一个供应商里。

个人版以前在 api.lkeap.cloud.tencent.com，腾讯已把它迁到 TokenHub。存在旧地址上的供应商，magpie 会自动改到新地址。

套餐里的模型

套餐不返回自己的模型列表，公共目录也只列出套餐里的混元模型，所以 magpie 按腾讯云套餐文档给出模型：tc-code-latest, auto, glm-5.3, glm-5.3-flash, kimi-k3, kimi-k2.7-code, deepseek-v4-pro, deepseek-v4.1-flash, minimax-m3, hy4-preview, hy3, mimo-v2.6-pro 等。tc-code-latest 是控制台当前选定的模型。按量付费的 Key 读取 TokenHub 的 /v1/models，那里还有通义千问等其他厂商的模型。

在各个工具里用

  • Claude Code 说的是 Anthropic Messages。套餐和按量付费都有 Anthropic 接口，请求原样转过去。见 Claude Code 接入国产模型。
  • Codex 只说 OpenAI Responses。TokenHub 的套餐和按量付费都提供 Responses，Codex 的请求原样转过去。模型会出现在 Codex 的 /model 里。见 Codex 接入第三方模型。
  • Gemini CLI 说 Gemini 的 API，magpie 把它指向本地网关并做转换。见 Gemini CLI 接入其他模型。
  • OpenCode：magpie 把模型写进 opencode.json。见 OpenCode 接入其他模型。

企业版额度

企业版每个周期的额度（专业套餐按积分、轻享套餐按 token）只能通过腾讯云 API 查询，要用账号的 SecretId 和 SecretKey 签名，套餐 Key 查不到。所以在供应商的编辑页填上 SecretId 和 SecretKey 后，magpie 的用量页会为这个账号能看到的每个企业版套餐显示一张卡片：本周期已用多少、何时重置。个人版没有查询额度的 API，只能在控制台看；按量付费没有额度窗口。

常见问题

腾讯云 Token Plan 怎么接入 Claude Code？

在 magpie 里添加 Tencent Cloud，把 Key 的套餐选成 Plan · China，然后在 Claude Code 那一行选 tc-code-latest、glm-5.3 这类模型，或运行 magpie claude tencent-cloud/tc-code-latest。请求走套餐的 Anthropic 接口 https://tokenhub.tencentmaas.com/plan/anthropic。

Token Plan 的 Key 和 TokenHub 按量付费的 Key 有什么区别？

套餐 Key 以 sk-tp- 开头，只能用在 /plan 下的套餐接口；按量付费用 TokenHub 自己的 API Key，接口是 /v1。在 magpie 里给每个 Key 选对套餐即可，两种 Key 可以放在同一个供应商里。

个人版原来的地址 api.lkeap.cloud.tencent.com 还能用吗？

腾讯已把个人版迁到 tokenhub.tencentmaas.com。magpie 里存着旧地址的供应商会自动改到新地址，不用手动改。

能在 magpie 里看到腾讯云套餐的剩余额度吗？

企业版可以：在供应商编辑页填账号的 SecretId 和 SecretKey，用量页就显示本周期的用量和重置时间。个人版没有查询 API，只能在腾讯云控制台看。

同一套方法用在其他国产模型：火山方舟、GLM 编程套餐、Kimi、DeepSeek、通义千问。腾讯自家的编程 Agent：让 CodeBuddy 用任意模型。遇到报错？见 常见错误排查，或到 Discord 提问。
