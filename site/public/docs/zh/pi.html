让 Pi 用任意模型

Pi 是编程 Agent pi，可以在 models.json 里添加你自己的供应商。magpie 把自己加进去，于是 pi 能用你在 magpie 里的任何模型：DeepSeek、GLM、Qwen、OpenAI 或 Anthropic Key，或 ChatGPT、Copilot 订阅，不用往 pi 里贴 Key。

Pi 的设置在 ~/.pi/agent，或 $PI_CODING_AGENT_DIR 指定的文件夹。magpie 在 models.json 里添加一个名为 magpie 的供应商，写入网关地址、一个专用 Key 和你在 magpie 里的模型，于是它们出现在 pi 的模型选择器里，然后把 settings.json 的 defaultProvider 和 defaultModel 设为你选的模型。WSL 里的 Pi 也一样设置。

接入 Pi

  1. 在 magpie 里添加供应商在 供应商 页添加 API Key，或登录一个订阅。
  2. 在 Pi 那一行选模型在 Agent 页，选 magpie 下的一个模型。
  3. 运行 pi它用这个模型启动，magpie 的每个模型也都在它的模型选择器里。
终端
magpie pi deepseek/deepseek-v4-pro    # Pi 用 DeepSeek
magpie pi                             # 查看 Pi 当前的模型

每个模型写了什么

  • 它自己的 API每个模型走它供应商的原生 API：GPT 和 ChatGPT 模型走 Responses，Claude 走 Messages，其余走 Chat Completions。只支持自适应思考的 Claude 模型写入 forceAdaptiveThinking。
  • 名称、上下文和回复pi 显示的名称、会思考的模型写入 reasoning、contextWindow、支持图片的模型写入图片输入，以及 maxTokens。你亲手填的 maxTokens 会保留。
  • 思考档位你在 magpie 里选的档位写入 defaultThinkingLevel，限定在 Pi 提供的档位内。

Pi 的每个请求都带上它的会话（sendSessionAffinityHeaders），所以 magpie 的用量能按 pi 会话显示，记录网关对话 也能记下它们。你自己设过的值会保留。

Ctrl+P 列表

Pi 按 Ctrl+P 在 enabledModels 里轮换模型，这个列表由 /scoped-models 编辑。你有这个列表时，magpie 把你选的模型加进去；没有时，magpie 不会新建，所以 Ctrl+P 仍然轮换所有模型。

决策和图片模型

magpie 还在 Pi 的文件夹里放一个扩展 extensions/magpie.ts，为 codemode 添加 magpie 的决策模型和图片模型。magpie 供应商在，它就在；供应商移除，它也随之移除。

你自己的文件

第一次写入前，magpie 把 settings.json 和 models.json 复制为旁边的 .before-magpie 文件。你自己的供应商和设置保持原样，Pi 那一行会把你的模型和 magpie 的并列显示。

切回

在那一行选你自己的模型、把那一行从 magpie 取消，或运行 magpie pi default。如果之后你什么都没改，magpie 把两个文件逐字节还原；否则只移除它自己的供应商，保留你的改动。

常见问题

Pi 能用 DeepSeek 或 GLM 吗？

能。你在 magpie 里的任何模型都在 pi 的模型选择器里：DeepSeek、GLM、Qwen、GPT、Claude 等。

Pi 能用我的 ChatGPT 订阅吗？

能。在 magpie 里登录 ChatGPT，在 Pi 那一行选 magpie 下的 GPT 模型。pi 把请求发给 magpie，magpie 通过 Responses API 使用该订阅。

设置了 PI_CODING_AGENT_DIR，magpie 写到哪里？

写到那个文件夹，~ 会展开。相对路径会被忽略，此时 magpie 用 ~/.pi/agent。

WSL 里的 Pi 能用吗？

能。magpie 也会设置 WSL 发行版里的 Pi，供应商指向发行版能访问到的网关地址。

更多 Agent 用同样的模型：OpenCode 接入其他模型、Claude Code 接入其他模型、让 Kimi Code 用任意模型、让 Cursor Private Inference 用任意模型。遇到报错？见 常见错误排查，或到 Discord 提问。
