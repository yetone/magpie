OpenCode Go and ClinePass

是什么 添加 给 Agent 用 OpenCode Go ClinePass 几点说明

文档 · 指南

OpenCode Go 和 ClinePass 接入 Claude Code、Codex 等 Agent

OpenCode Go 和 ClinePass 都是按月付费的开源编程模型套餐：OpenCode Go 每月 10 美元，ClinePass 每月 9.99 美元。magpie 的 opencode-go 和 clinepass 预设把它们接到 Claude Code、Codex、OpenCode 等 Agent，不只限于各自的客户端。

添加

  1. 拿一把 Key。OpenCode Go 的 Key 在 opencode.ai/auth 创建，ClinePass 的 Key 在 app.cline.bot 创建。
  2. 添加。在应用里选 OpenCode Go 或 ClinePass，把 Key 填进 API 密钥，或者在命令行：
终端
magpie provider add opencode-go 
magpie provider add clinepass 
magpie models

接口地址都已在预设里配好。在 OpenCode 里配过的 OpenCode Go 或 ClinePass 供应商，导入时也会变成对应的预设。

给 Agent 用

模型 id 写成 供应商/模型：ClinePass 的模型 id 本身带 cline-pass/ 前缀。

终端
magpie claude opencode-go/
magpie codex clinepass/cline-pass/glm-5.3

Claude Code、Codex、Gemini CLI 说的协议和套餐的接口不同时，magpie 负责翻译。

OpenCode Go

  • OpenCode Go 每个模型只在三种协议中的一种上服务，另外两种会被拒绝（「Model does not support this protocol」）。magpie 按 OpenCode 的做法分发：GPT、Grok、Muse Spark 走 Responses，Claude、MiniMax 和部分 Qwen 走 Anthropic Messages，Gemini 走 Gemini 接口，其余走 Chat Completions。
  • Chat 和 Responses 在 https://opencode.ai/inference/go/openai/v1，Messages 在 https://opencode.ai/inference/go/anthropic，Gemini 在 https://opencode.ai/inference/go/google/v1beta，与 Go 文档给的一致。以前用旧地址保存的 OpenCode Go 供应商会自动换到新地址。
  • 额度页显示套餐的三个窗口：5 小时、7 天 和 本月，各用了多少、什么时候重置。

ClinePass

  • Chat Completions 在 https://api.cline.bot/api/v1。Cline 的接口只列它的付费模型，不列套餐的，所以 magpie 从 Cline 自家客户端用的推荐列表里取模型：套餐的模型，加上 Cline 的免费模型；付费模型不列。
  • Cline 的免费模型（cline-free/ 开头）不收费，也不占 ClinePass 的额度。它们只回应 Cline 自家的客户端，所以 magpie 发 Cline 桌面版发的请求头。
  • 推荐列表拿不到时，magpie 改问 Cline 接口自己的列表，免费模型按 Cline 桌面版上次列出的给。

几点说明

  • 套餐限速或用完时，把它和其他供应商放进同一个路由组，组里的下一个接着回答，详见 多个账号、Key 和供应商轮询与故障切换。
  • 价格、额度和模型以 OpenCode 和 Cline 自己的页面为准，会随时变化。

常见问题

Claude Code 能用 OpenCode Go 吗？

能。用 magpie provider add opencode-go 加上 Key，模型 id 写成 opencode-go/<模型>。magpie 按模型把请求发到 Go 对应的协议上，必要时翻译。

OpenCode Go 报 Model does not support this protocol 怎么办？

这是模型被发到了错误的协议上。magpie 按 OpenCode 的做法给每个模型选协议，用 opencode-go 预设添加即可，以前用旧地址保存的供应商会自动换到新地址。

ClinePass 能在 Cline 以外的 Agent 里用吗？

能。用 magpie provider add clinepass 加上 Cline 的 Key，套餐模型和 Cline 的免费模型都会出现在每个 Agent 的选择器里。

在哪里看 OpenCode Go 还剩多少额度？

magpie 的额度页显示 OpenCode Go 的 5 小时、7 天和本月三个窗口的用量和重置时间。
