Snow CLI

文档 · 指南

让 Snow CLI 用任意模型

Snow CLI（snow，npm 包 snow-ai）把每套 API 配置存为一个 profile。magpie 添加一个自己的 profile，把 Snow 指向 magpie 的网关，于是 Snow 能用你在 magpie 里的任何模型：DeepSeek、GLM、Qwen、OpenAI 或 Anthropic Key，或 ChatGPT、Copilot 订阅。

Snow 的设置在 ~/.snow（或 $SNOW_CONFIG_DIR）。每个 profile 是 profiles/ 下的一个文件，active-profile.json 指明当前用哪个，config.json 是它的副本。magpie 写入 profiles/magpie.json：复制你原来所用的 profile，把 base URL 设为 magpie 的网关，填上一个标明 Snow 的 Key，协议设为 Chat Completions，模型设为你选的模型。然后把它设为当前 profile 并复制到 config.json，和 Snow 自己切换 profile 的做法一样。网关再把每个请求发给该模型的供应商。

接入 Snow

  1. 在 magpie 里添加供应商在 供应商 页添加 API Key，或登录一个订阅。
  2. 在 Snow CLI 那一行选模型在 Agent 页，选 magpie 下的一个模型。
  3. 重启已打开的 snow 会话Snow 在启动时读取 profile。
终端
magpie snow deepseek/deepseek-v4-pro    # Snow 用 DeepSeek
magpie snow default                     # 回到你自己的 profile

Windows 上 WSL 发行版里的 Snow 也一样：那里的 profile 写的是发行版能访问到的网关地址。

你的 profile

你自己的 profile 不会被修改。magpie 的 profile 从你原来所用的那个复制其他设置，但不带上你的订阅登录（snowcfg.oauth）。如果你自己恰好有一个名为 magpie 的 profile，它会被另存并在之后还原。那一行也会列出你自己各个 profile 的模型：选其中一个，Snow 就切到那个 profile。

窗口与图片

magpie 按目录为你选的模型设置 maxContextTokens、maxTokens 和 supportsVision，让 Snow 知道它真实的窗口以及能否看图。magpie 不知道上限的模型，用 Snow 自己的默认值 200K 和 64K。你在 Snow 设置里改过的值会保持你设的样子。你自己的视觉模型，只有带着独立的地址和 Key 时才保留。不能看图的模型收到的图片，由 magpie 的 Vision 在网关上转成描述。

轻量模型

Snow 用轻量模型（basicModel）做摘要、压缩和文件搜索。在 magpie 的 profile 里，它跟随主模型，除非你在那一行的 small 字段另选一个 magpie 模型。换主模型时这个选择保持不变。

思考

那一行的 thinking 字段设置 magpie profile 的 chatThinking：选一个档位，每个请求都带上 reasoning_effort；关闭则是 Snow 的默认。只有列出推理档位的模型才提供这一项。

Snow App

Snow App 有自己的 API 配置。它的 Sync Snow CLI API config 按钮会把 Snow CLI 的 profile 复制过去，包括 magpie 的，所以应用也能用 magpie 的模型。

切回

在那一行选你自己的模型、运行 magpie snow default，或把那一行从 magpie 取消。Snow 回到你原来的 profile，profiles/magpie.json 被删除，config.json 重新成为你的 profile 的副本。

常见问题

Snow CLI 能用 DeepSeek、GLM 或 Qwen 吗？

能。你在 magpie 里的任何模型都能作为 Snow 的模型：DeepSeek、GLM、Qwen、GPT、Claude 等。

magpie 会改我自己的 Snow profile 吗？

不会。它添加一个自己的 profile，profiles/magpie.json，并设为当前 profile。切回时你的 profile 重新成为当前 profile。

为什么 Snow 显示的上下文大小不对？

magpie 按目录为你选的模型设置 maxContextTokens 和 maxTokens。你自己在 Snow 里改过的值会保持不变。

Snow 和 magpie 之间用什么协议？

Chat Completions（requestMethod 为 chat）。如果 magpie 的 profile 被设成别的协议，那一行会提示。

更多 Agent 用同样的模型：Gemini CLI 接入其他模型、让 Cursor Private Inference 用任意模型、让 Antigravity 用任意模型。遇到报错？见 常见错误排查，或到 Discord 提问。
