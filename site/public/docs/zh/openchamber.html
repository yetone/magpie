让 OpenChamber 用任意模型

OpenChamber 是 OpenCode 的桌面、网页和 VS Code 前端。它运行自己的 OpenCode（桌面版自带 OpenCode 2），读的是你的 OpenCode 配置。magpie 把 OpenChamber 的默认模型设成 magpie 的模型，并在 OpenCode 配置里放好 magpie 供应商，于是 OpenChamber 能用你在 magpie 里的任何模型：DeepSeek、GLM、Kimi、Qwen、OpenAI 或 Anthropic Key，或 ChatGPT、Copilot 订阅。

接入 OpenChamber

  1. 在 magpie 里添加供应商在 供应商 页添加 API Key，或登录一个订阅。
  2. 在 OpenChamber 那一行选模型在 Agent 页给 OpenChamber 选默认模型，也可以另选一个小模型。
  3. 开一个新会话OpenChamber 在新会话里用新模型。
终端
magpie openchamber deepseek/deepseek-v4-pro          # new sessions
magpie openchamber small deepseek/deepseek-v4-flash  # titles, commit messages

OpenChamber 的设置在 $OPENCHAMBER_DATA_DIR，默认是 ~/.config/openchamber（不随 XDG_CONFIG_HOME 改变）。magpie 写的是它的 profile，preferences.json；旧版只读 settings.json，所以那里有的副本也一起更新：

终端
// ~/.config/openchamber/preferences.json
{"version": 1, "fields": {
  "defaultModel": {"value": "magpie/deepseek/deepseek-v4-pro", "updatedAt": …},
  "smallModelUseDefault": {"value": false, …},
  "smallModelOverride": {"value": "magpie/deepseek/deepseek-v4-flash", …}
}}

模型的选择顺序

OpenChamber 给每个新会话发它选的模型，顺序是：项目自己的 defaultModel（settings.json 的 projects），profile 的 defaultModel，Agent 自己的模型，最后才是 OpenCode 配置里的 model。所以只改 OpenCode 的模型管不到 OpenChamber，magpie 改的是 profile 的 defaultModel。某个项目设了自己的默认模型时，那个项目里仍用它，magpie 会提示是哪个项目、哪个模型。换模型时，magpie 同时清掉旧模型的 defaultVariant，和 OpenChamber 自己的选择器一样。

小模型

OpenChamber 用小模型起会话标题、写提交信息。smallModelUseDefault 为 false 时用 smallModelOverride，否则用 OpenCode 的 small_model。在 magpie 里选小模型，就是写这两个键；切回时两个都拿掉，交还给 OpenCode。

OpenCode 配置

OpenChamber 的模型写成 OpenCode 的 provider/model，所以 magpie 的模型需要 OpenCode 配置里有 magpie 供应商。配置在 $OPENCODE_CONFIG_DIR，否则是 $XDG_CONFIG_HOME/opencode。如果你的配置里已经有一个指向 magpie 网关、列出这个模型的供应商，magpie 就用它，不再加第二份同样的模型列表。OpenCode 2 的配置用 OpenCode 2 的写法写。OpenChamber 不再用 magpie 后，如果 OpenCode 配置里没有别的地方用到 magpie 的模型，magpie 供应商也一起拿掉。请求算在 OpenCode 名下，因为它们就是 OpenChamber 里的 OpenCode 发出的。

新会话和已开的会话

OpenChamber 在新会话里用新模型，已经打开的会话保留原来的。OpenChamber 运行时 magpie 也会提示这一点。

切回

在 magpie 里把那一行切回默认，magpie 拿掉 profile 的 defaultModel 和 defaultVariant，OpenChamber 回到 OpenCode 配置的模型。

终端
magpie openchamber default

常见问题

OpenChamber 能用 DeepSeek、GLM、Kimi 或 Qwen 吗？

能。magpie 把 OpenChamber 的默认模型设成你在 magpie 里选的模型，并在 OpenCode 配置里放好 magpie 供应商。

我已经让 OpenCode 用 magpie 了，为什么 OpenChamber 还是原来的模型？

OpenChamber 先用项目和 profile 自己的 defaultModel，最后才看 OpenCode 的 model。在 magpie 里给 OpenChamber 那一行单独选模型。

某个项目里还是旧模型？

那个项目在 settings.json 里设了自己的默认模型，在那里优先。magpie 会提示是哪个项目。

会话标题和提交信息用哪个模型？

小模型：设了 smallModelOverride 且 smallModelUseDefault 为 false 时用它，否则用 OpenCode 的 small_model。

更多 Agent 用同样的模型：OpenCode 接入其他模型、让 T3 Code 用任意模型、让 Craft Agents 用任意模型。遇到报错？见 常见错误排查，或到 Discord 提问。
