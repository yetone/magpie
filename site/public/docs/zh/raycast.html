文档 · 指南

让 Raycast 用任意模型

Raycast AI 可以把你自己的模型作为自定义供应商使用（Raycast Pro，Mac 和 Windows 都支持）。magpie 把自己作为一个供应商加进 Raycast，于是 Quick AI、AI Chat 和 AI Commands 能用你在 magpie 里的任何模型：DeepSeek、Kimi、GLM、Qwen、OpenAI Key，或 ChatGPT、Copilot 订阅，不用往 Raycast 里贴 Key。

Raycast 从用户目录下的 ~/.config/raycast/ai/providers.yaml 读取自定义供应商，Mac 和 Windows 都是这个位置。magpie 在其中的 providers 列表里添加一项，id 为 magpie：网关的 OpenAI 兼容地址、一个 Raycast 专用的 Key 和 magpie 的模型。Raycast 会监视这个文件，所以模型不用重启就会出现。网关把每个请求翻译给该模型的供应商，工具调用和推理都保留。

接入 Raycast

  1. 在 magpie 里添加供应商在 供应商 页添加 API Key，或登录一个订阅。
  2. 在 Raycast 那一行选 magpie在 Agent 页，把 Raycast 的供应商设为 magpie。
  3. 在 Raycast 里选模型在 Quick AI、AI Chat 或某个 AI Command 里打开 Raycast 的模型选择器，magpie 的模型列在 magpie 下。
终端
magpie raycast magpie     # 把 magpie 的模型放进 Raycast AI 的选择器
magpie raycast            # 查看 Raycast 当前的设置

在 Windows 上，你在 Raycast 设置里打开 Reveal Providers Config 时，Raycast 会创建它的配置目录；magpie 就是通过这个目录找到 Raycast 的。

列出哪些模型

模型是在 Raycast 里选的，不在文件里，所以 Raycast 的选择器列出的是在 Agent 页为 Raycast 选中的模型。在那里隐藏一个，它就会从 Raycast 的列表里消失。每个模型都带上名称、上下文窗口和能力，并且全部写明，因为没写时 Raycast 会当作不支持工具和识图：

  • 工具：每个模型都开启，AI Extensions 才能用。
  • 识图：能看图片的模型开启。
  • 推理强度：有强度档位的模型开启。
  • 温度：不接受温度参数的模型关闭。

你的 providers.yaml

magpie 只写它自己那一项。你的其他供应商、顶层的 tools 配置和注释都保留。你自己加到 magpie 那一项里的字段也保留，比如 include_user_email、additional_parameters 或某个模型的 description。只有 magpie 那一项需要变化时才会写文件。

切回

把 Raycast 那一行从 magpie 移除，或运行 magpie raycast default。magpie 会删除它那一项；如果那是唯一一项，providers 列表也一起删除；文件里什么都不剩时，文件也会删除。

常见问题

需要 Raycast Pro 吗？

需要。自定义供应商是 Raycast Pro 的功能，所以订阅 Pro 后 magpie 的模型才会出现在 Raycast 的选择器里。

Raycast 能用我的 ChatGPT 订阅吗？

能。在 magpie 里登录 ChatGPT，把 Raycast 那一行设为 magpie，再在 Raycast 里选一个 GPT 模型。Raycast 把请求发给 magpie，由 magpie 使用订阅。

需要重启 Raycast 吗？

不需要。Raycast 会监视 providers.yaml，magpie 那一项一变就会生效。

AI Extensions 能用吗？

能。每个模型都开启了工具，网关会把工具调用带给各模型的供应商。

更多 Agent 用同样的模型：OpenCode 接入其他模型、Claude Code 接入其他模型、让 Obsidian 用任意模型、让 Crush 用任意模型、让 Copilot CLI 用任意模型。遇到报错？见 常见错误排查，或到 Discord 提问。
