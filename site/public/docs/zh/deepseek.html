DeepSeek 接入 Claude Code、Codex、Gemini CLI 和 OpenCode

DeepSeek 同时提供 OpenAI 兼容接口和 Anthropic 兼容接口。在 magpie 里添加一次 Key，Claude Code、Codex、Gemini CLI、OpenCode 以及你连接的其他工具，都能通过 magpie 的本地网关 127.0.0.1:3425 用上 DeepSeek 的模型。

添加 DeepSeek

  1. 拿到 API Key在 platform.deepseek.com/api_keys 创建。
  2. 添加供应商在 magpie 的 供应商 页点 ＋ 添加供应商，选 DeepSeek，粘贴 Key 并保存。magpie 会向 DeepSeek 查询它提供哪些模型，比如 deepseek-v4-pro 和 deepseek-v4-flash。
  3. 给工具选上在 Agent 页点某个工具那一行的模型，选一个 DeepSeek 模型。
终端
magpie provider add deepseek sk-…
magpie models        # 所有模型，格式是 provider/model

magpie 里的模型 ID 是 provider/model，DeepSeek 的就是 deepseek/…。再添加一次预设会多出第二个 DeepSeek 供应商，用另一个 Key；想让请求分到多个 Key 上，就把它们都加到同一个供应商里。

接口地址

DeepSeek 只有按量付费一种计费方式，magpie 用的接口是：

协议接口地址
OpenAI Chat Completions 和 Responseshttps://api.deepseek.com/v1
Anthropic Messageshttps://api.deepseek.com/anthropic

在各个工具里用

在 Agent 页里点某个工具那一行的模型来选，或者在终端里选。每篇指南都写了 magpie 在那个工具的配置里改了什么、怎么换回去。

终端
magpie claude deepseek/deepseek-v4-pro
magpie codex deepseek/deepseek-v4-pro
magpie gemini model deepseek/deepseek-v4-flash
magpie opencode deepseek/deepseek-v4-pro
  • Claude Code 说的是 Anthropic Messages，DeepSeek 的 Anthropic 接口也说这种协议，所以请求原样转过去。opus、sonnet、haiku 三档默认都用你选的模型，也可以给某一档单独指定。Claude Code 接入其他模型。
  • Codex 只说 OpenAI Responses。DeepSeek 自己就提供 Responses 接口，所以 Codex 的请求原样转过去。模型会出现在 Codex 的 /model 里，带着推理强度。Codex 接入其他模型。
  • Gemini CLI 说 Gemini 的 API。magpie 把它指向本地网关并做转换。Gemini CLI 接入其他模型。
  • OpenCode：magpie 把模型写进 opencode.json，带上推理档位和价格。OpenCode 接入其他模型。

思考、推理强度和缓存

  • 工具轮次的思考块。DeepSeek 的 Anthropic 接口要求每个调用工具的助手轮次、以及只回传工具结果的轮次都带思考块。工具的历史里没有时，magpie 会补一个，并把 Claude 的 redacted_thinking 转成可用的思考块。所以路由分组可以在对话中途从 Claude 切到 DeepSeek。
  • 推理强度。DeepSeek 只有 low、high、max 三档，写在 output_config.effort 里，不看 budget_tokens。工具给的 token 预算会对到这三档之一。
  • 缓存。有多个 Key 时，magpie 会在对话最后一轮之后的一小时内，让它一直留在同一个 DeepSeek Key 上，下一轮就能读到 DeepSeek 的缓存，而不是不带缓存地发给另一个 Key。
  • 图片。工具发给 DeepSeek API 的每张图，magpie 只上传一次，之后的轮次用文件 ID 指代。magpie provider set deepseek image-files=off 改成每轮都内联发送。

余额与用量

DeepSeek 那一行会显示从 DeepSeek 读到的余额：总额、赠送金额和充值金额。用量 页按工具和模型统计经过 magpie 的 token、缓存命中和费用。

常见问题

DeepSeek 怎么接入 Claude Code？

在 magpie 里添加 DeepSeek 的 API Key（供应商 → 添加供应商 → DeepSeek），然后在 Claude Code 那一行选一个 DeepSeek 模型，比如 deepseek-v4-pro，或者运行 magpie claude deepseek/deepseek-v4-pro。magpie 会写好 Claude Code 的 settings.json，把请求转给 DeepSeek 的 Anthropic 接口 https://api.deepseek.com/anthropic。

Codex 能用 DeepSeek 吗？

能。DeepSeek 自己就提供 Codex 说的 OpenAI Responses 接口，所以 magpie 把 Codex 的请求原样转过去。在 Codex 那一行选模型，或运行 magpie codex deepseek/deepseek-v4-pro，模型会出现在 Codex 的 /model 里。

要自己把 ANTHROPIC_BASE_URL 设成 DeepSeek 吗？

不用。magpie 把 Claude Code 指向本地网关 127.0.0.1:3425，DeepSeek 的 Key 留在 magpie 里。重新选回 Claude Code 自己的模型，原来的设置就回来了。

同一个对话里能在 Claude 和 DeepSeek 之间切换吗？

能。DeepSeek 的 Anthropic 接口要求调用工具的轮次带思考块，而在 Claude 上开始的对话没有它能读的思考块。magpie 会补上，所以路由分组可以在对话中途从 Claude 切到 DeepSeek。

DeepSeek 支持哪些推理强度？

DeepSeek 只有三档：low、high 和 max，写在 output_config.effort 里，不看 budget_tokens。工具要的档位或 token 预算，magpie 会对到这三档之一。

可以用多个 DeepSeek Key 吗？

可以。把它们都加到 DeepSeek 这个供应商里并勾选。magpie 把请求分到各个 Key 上，同一个对话留在同一个 Key 上以复用缓存，某个 Key 余额用完就换下一个。

各个工具的指南：Claude Code 接入其他模型、Codex 接入其他模型、Gemini CLI 接入其他模型、OpenCode 接入其他模型。遇到问题可以在 Discord 提问。
