百度千帆 Token Plan 接入 Claude Code 和 Codex

百度千帆有两种 Token Plan（个人版和企业版）和按量付费，各自有接口地址和 Key。在 magpie 里添加百度千帆并给每个 Key 选好套餐，Claude Code、Codex、Gemini CLI、OpenCode 和其他工具就都能通过本地网关 127.0.0.1:3425 用上千帆里的 DeepSeek 和 GLM。

添加百度千帆

  1. 添加供应商并选套餐在 供应商 页点 ＋ 添加供应商，选 Baidu Qianfan，给 Key 选 Token Plan Personal、Token Plan Enterprise、Pay as you go，粘贴 Key 并保存。
  2. 给工具选上在 Agent 页给某个工具选 qianfan-code-latest 或 deepseek-v4-pro 这类模型。
终端
magpie claude baidu-qianfan/qianfan-code-latest
magpie codex baidu-qianfan/deepseek-v4-pro
magpie opencode baidu-qianfan/glm-5.3

每个套餐的 Key 只用在自己的地址上。供应商里的每个 Key 都标明自己的套餐，所以个人版、企业版和按量付费的 Key 可以放在同一个供应商里，每个 Key 的请求发到它自己套餐的地址。

套餐里的模型

套餐的 /models 返回 404，所以 magpie 按千帆两个套餐的文档给出模型：qianfan-code-latest, deepseek-v4.1-flash, deepseek-v4-pro, deepseek-v4-pro-0813, deepseek-v4-flash-0731, glm-5.3, glm-5.3-flash, glm-5.2, glm-5.1 等。deepseek-v4-flash、deepseek-v3.2 和 glm-5 只在企业版里。qianfan-code-latest 是控制台当前选定的模型。按量付费的 Key 读取千帆的 /v2/models。

在各个工具里用

  • Claude Code 说的是 Anthropic Messages。千帆的套餐和按量付费都有 Anthropic 接口，请求原样转过去。见 Claude Code 接入国产模型。
  • Codex 只说 OpenAI Responses。千帆的套餐地址也提供 Responses，Codex 的请求原样转过去。模型会出现在 Codex 的 /model 里。见 Codex 接入第三方模型。
  • Gemini CLI 说 Gemini 的 API，magpie 把它指向本地网关并做转换。见 Gemini CLI 接入其他模型。
  • OpenCode：magpie 把模型写进 opencode.json。见 OpenCode 接入其他模型。

常见问题

百度千帆 Token Plan 怎么接入 Claude Code？

在 magpie 里添加 Baidu Qianfan，把 Key 的套餐选成 Token Plan Personal 或 Enterprise，然后在 Claude Code 那一行选 qianfan-code-latest 这类模型，或运行 magpie claude baidu-qianfan/qianfan-code-latest。请求走套餐的 Anthropic 接口，比如 https://qianfan.baidubce.com/anthropic/tokenplan/personal。

qianfan-code-latest 是哪个模型？

是你在千帆控制台为套餐选定的模型。换模型在控制台改，magpie 和工具里的名字不用变。

千帆个人版和企业版的模型一样吗？

大部分一样。deepseek-v4-flash、deepseek-v3.2 和 glm-5 只在企业版里，其他如 deepseek-v4-pro、glm-5.3 两个套餐都有。

百度千帆能在 Codex 里用吗？

能。千帆的套餐地址提供 OpenAI Responses，magpie 把 Codex 的请求原样转过去。运行 magpie codex baidu-qianfan/deepseek-v4-pro，或在 Codex 那一行选上。

同一套方法用在其他国产模型：火山方舟、腾讯云、GLM 编程套餐、Kimi、DeepSeek、通义千问。遇到报错？见 常见错误排查，或到 Discord 提问。
