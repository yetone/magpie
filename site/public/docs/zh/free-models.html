Free models

是什么 不要 Key 的免费模型 选择器里的免费标记 免费模型做备用 几点说明

文档 · 指南

免费模型接入 Claude Code、Codex 等 Agent

有些供应商提供免费模型，有的连 Key 都不要。magpie 把它们和其他模型放在同一个选择器里，Agent 写 供应商/模型 就能用；免费的会在旁边标出来。

不要 Key 的免费模型

  1. OpenCode Zen。免费模型（id 以 -free 结尾的，以及 big-pickle）不需要 Key。Zen 的免费档只给 OpenCode 用，magpie 按 OpenCode 发请求的方式去请求它们。
  2. Kilo Gateway。免费模型（标着免费、id 以 :free 结尾的）不需要 Key。没有 Key 时按匿名访问计，按 IP 每小时 200 次请求。
终端
magpie provider add opencode-zen
magpie provider add kilo
magpie models

加好之后，免费模型就出现在每个 Agent 的选择器里：

终端
magpie claude opencode-zen/big-pickle
magpie codex kilo/:free

想用这两家的付费模型，再补一把 Key 就行，免费模型照样能用：

终端
magpie provider key opencode-zen 
magpie provider key kilo

选择器里的免费标记

在某个供应商上四项价格（输入、输出、缓存读、缓存写）都标为 0 的模型，选择器里会在旁边标上 免费，比如 OpenRouter 的 :free 模型、OpenCode Zen 的 -free 模型、NVIDIA NIM 的免费模型。

  • 这只算这个供应商的价格：同一个模型在别的供应商那里照常计价。
  • 模型厂商自己免费给的（比如智谱的 glm-4.7-flash），不等于转卖它的供应商也免费，所以不标。
  • 套餐的价格表写的是会员按 token 付多少，不是模型本身的价格，所以也不算。
  • 你自己给模型设了价格时，以你设的为准：设成 0 就标免费，设成别的就不标。
终端
magpie model price relay-a/some-model 0,0,0,0

免费模型做备用

免费模型常有频率限制。把免费模型和付费模型放进同一个路由组，免费的放前面：免费的被限速或出错时，组里的下一个接着回答，详见 多个账号、Key 和供应商轮询与故障切换。

几点说明

  • 供应商回答说某个模型已经下线时（比如 Zen 的 410「Model exo-free has been deprecated.」），这个模型会从 magpie models、/v1/models 和每个 Agent 的列表里拿掉；有一次请求答上了，或者过了一周，它会回来。
  • 哪些模型免费、额度多少，以各家自己的页面为准，会随时变化。

常见问题

有没有不用 Key 就能在 Claude Code 里用的免费模型？

有。OpenCode Zen 的免费模型（-free 结尾和 big-pickle）和 Kilo Gateway 的免费模型（:free 结尾）都不需要 Key，用 magpie provider add opencode-zen 或 magpie provider add kilo 添加即可。

Kilo Gateway 没有 Key 有什么限制？

没有 Key 时按匿名访问计，按 IP 每小时 200 次请求。加一把 Kilo 的 Key 就能用它的付费模型。

选择器里的免费标记是怎么来的？

某个供应商把模型的四项价格都标为 0 时就标免费。这只是这个供应商的价格；模型厂商自己免费给的、套餐价格表里为 0 的都不算。

免费模型被限速了怎么办？

把它和付费模型放进同一个路由组，免费的放前面。被限速或出错时，组里的下一个接着回答。
